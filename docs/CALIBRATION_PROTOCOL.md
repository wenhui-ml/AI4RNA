# 判据标定协议 v1 —— 在没有公认判据的领域里造一把尺子

> **状态:预注册。写于 2026-08-03,在第三个领域开跑之前。**
> 前两个领域(假结、共转录折叠)是**归纳**出这份协议的材料,不是它的检验。
> **第三个领域是对这份协议的检验,不是对我们的检验。** 这两句话的区别,是"我们做成了三次"和"任何人照这个做都能成"之间的全部距离。

---

## 0. 这份文档为什么必须先于第三个领域存在

前两次每一步都是**做完之后**才知道该怎么做的:

```
假结      先做了标定,后来才被逼出留出集、精确区间、对抗零假设、外部裁判、拓扑路由
共转录    先做了外部验证,跑完才发现长度混杂,又跑完才发现 GC 钉死后效应未确立
```

这不是缺点 —— 科学就是这样啃出来的。**但它意味着"我们做成了两次"这句话里,有多少是方法、有多少是我们边做边补,分不出来。**

**一份写在前面的协议,把这件事变成可判定的**:第三个领域跑完之后,唯一要报的不是"成功了没有",而是:

> **这份协议在第三个领域里,哪一步没说清楚?**

那份"没说清楚"的清单,才是 v2。

---

## 1. 适用前提:先证明这个领域【真的】判据缺失

**不满足这一条就不要往下走。** 一个已经有公认判据的领域,造第二把尺子没有意义。

| 检查 | 判定 | 失败怎么办 |
|---|---|---|
| **P1** 至少 3 个**独立**可运行的预测器/模拟器 | 全部装好、能跑、有版本号 | 少于 3 个 → 不是"判据缺失",是"工具缺失",换领域 |
| **P2** 它们**互不一致** | 逐对一致性(Cohen's kappa 或等价量)**必须实测并公布**,并且**必须写明在哪个总体上测的**(见下) | kappa 普遍 >0.8 → 领域其实有共识,我们没有贡献空间 |
| **P3** 严格判据下这个领域**基本交付不了** | "全部预测器逐条精确一致"下的交付率 | 严格判据下就能交付 → 用严格判据即可,不需要标定 |

> **"独立"的口径,v1 漏写了,本文件写完当天就被自己绊倒 —— 补在这里。**
> **同一个软件包里的多个二进制,算【一个】源,直到 kappa 说不是。** 它们共用能量参数表、共用折叠核心,算法不同不等于证据独立。
> **最低门槛:面板里必须至少有两个不同的代码库 + 不同的参数集。**
>
> 这条不是事后聪明:v1 写完之后我给第三个领域勾 P1,勾的是 `RNAduplex` / `RNAcofold` / `RNAup` / `RNAplex` —— **四个 ViennaRNA 二进制,四个算法,一套能量模型。** 按 v1 的字面它通过了,按它的意图它没有。**这就是"协议在第三个领域里哪一步没说清楚"的第一条,而且是在第三个领域开跑之前发现的。**

> **v1 的第二个洞,由第三个领域的入场检查暴露 —— 这正是这份文档要的东西。**
> **P2 只说了"测它们一不一致",没说【在哪个总体上测】。** 而答案完全由总体决定:
> ```
> 总体 = 设计序列 + 其内部窗口的【完美反向互补】触发链(我们开关能力真正用的那个)
>        四家逐对 kappa 全部 >= 0.80,严格判据已能交付 45.8%   -> P2/P3 都不过
> ```
> 完美互补是这个领域**最容易的一档**;换成天然 sRNA–mRNA 那种部分互补,答案很可能相反。
> **所以 P2 的正确写法是:先声明总体,再测一致性;而总体必须是【判据将来要在上面签字】的那个总体。**
> 补进 v2:**入场检查的总体必须与部署总体一致,并在跑之前写下来。事后换一个更难的总体重测,是选择性报告。**

> **P2 是最容易被跳过、也最致命的一步。** 假结那次我们写了两个月的"三个独立预测器",直到实测才发现 ProbKnot~ShapeKnots 的 kappa 是 **0.74** —— 面板其实是**两个有效独立源**。这个数字改变了判据等级的全部含义。

**同时记录 P4:这个领域的需求有多大。** 不是为了立项,是为了在报告里能诚实回答"你为什么挑这个领域"。可用手段:外部工具的接口覆盖(有没有人供给)、文献计数(有没有人要)。

## 2. 六步

### 步骤 1 —— 判据家族与选点规则,**跑前声明**

写在对应 `*_suite.py` 的 docstring 里,在**任何数据产生之前**:

- 判据不是一个数,是一个**家族**(如 `k` 家预测器 × 复现率阈值 `τ`),整张格点最后要公布;
- 选点规则必须是**可执行的**(如"硬零假设误收 ≤1% 下灵敏度最高"),不能是"看着办";
- **同时写下三种会杀死这条要求的结局。**

> **判定失败的样子**:跑完之后才决定阈值。**阈值在看过两臂之后选,那个阈值就是全部结果。**

### 步骤 2 —— 留出集分割 + 精确区间

- 按**确定性规则**分割(如 id 排序取偶/奇),不用随机分割 —— 随机分割的种子也是一个自由度;
- **FIT 上选点,TEST 上报数**;
- 每一个率都带 **Clopper-Pearson 精确区间**,不报裸分数。

> **判定失败的样子**:`5/9` 这样的数字被裸报。它的区间是 **[21.2%, 86.3%]**,而裸报会让读者以为是 56%。

> **值得记的一次反向意外**:数据驱动选出的 τ=0.67 在 TEST 上误收 2.2%,而我们保守的出厂值 τ=1.0 是 0.0%。**留出集会保护你不被自己的选点规则伤到。**

### 步骤 3 —— **至少两种**对抗零假设,其中一种必须是"近似正确"的

这是整份协议里最花力气、也最不可省的一步。

| 零假设强度 | 例子(假结) | 例子(共转录) |
|---|---|---|
| 弱(几乎没用) | 等长均匀随机 ACGU | — |
| 中 | 二核苷酸保序洗牌 | — |
| **强:近似正确** | **嵌套诱饵**(为去假结骨架设计) | **同分异构体**(碱基多重集完全相同,只有排列不同) |
| **强:位置特异** | **移位诱饵**(真假结,错 1–2 nt) | (待定) |

> **"近似正确"那一档才是判据在部署中真正要区分的总体。** 弱零假设通过说明不了任何事 —— 随机串连嵌套骨架都折不出来。
>
> **构造纪律:诱饵必须先被验证它确实是我们想要的那个错误。** 设计失败的不算诱饵,算失败的设计;放进来会让一个空洞的检验看起来像满分。移位诱饵第一版在 12/12 个靶标上返回 `None`,**若未发现,这个基准会报出一个空的零假设,而它看起来会像一次干净的通过。**

### 步骤 4 —— 一个**从未进入回路**的外部裁判

- 不同算法、不同代码库,最好装在**独立环境**,出厂路径够不着它;
- **不能直接比接受率** —— 外部裁判自己也有灵敏度。参照系是**它在同类天然样本上的自身天花板**,同一次运行里测;
- 天然正样本不可得时(如共转录),退而求其次做**相对效度**:判据与一个机制无关的裁判是否看到同一件事。**必须明写这是相对效度,不是绝对灵敏度。**

> **跑之前先验裁判。** RNAPKplex 在有残留文件的工作目录里返回纯嵌套结构,天然假结上 0/3,换干净临时目录后 12/14。**照默认跑会得到"外部裁判完全不认可我们"这个完全相反的结论。**
> **正对照 + 负对照各跑一次,是这一步的入场券。**

### 步骤 5 —— **混杂控制**,而且要三种互相独立的

一个"通过"的数字在这一步之前**没有资格进报告**。

| 控制 | 它排除什么 |
|---|---|
| **同单元内配对** | 同一个靶标/母序列 = 长度、结构完全一致 |
| **分层** | 捡回配对必须扔掉的那些单元 |
| **聚类稳健回归** | 全部数据点都保留,协变量同时进模型,**标准误按事情真正重复的层级定价** |

> **伪重复是这一步最常见的死法。** 20 条轨迹/序列不是 20 个独立观测;12 条候选/靶标不是 12 条独立序列。
> 共转录那次,预注册的 +26.5 点通过了,**而两组均长是 47 vs 55 nt,固定模拟预算直接惩罚长度 —— 长度单独就能造出整个差距。** 三重控制之后是 +15.2。

> **零结果必须带检验力陈述。** "我们看了,不在那里" 和 "就算在那里我们也看不见" 是两回事。GC 钉死后 +6.0 [−1.6, +13.7],p=0.18,29 个层 —— 要 80% 检验力需要约 96 个。**报为"未确立",不报为"已否定"。**

### 步骤 6 —— **诚实的适用范围:找出它失效的子群并限制,而不是打补丁**

- 按可观测的属性分群(拓扑、长度、GC 段……),**逐群报外部同意率**;
- 有子群不通过时,**先试修,修不好就限制**;
- **限制要落到代码和测试里**,不能只写在文档里。

> **假结那次的取舍写在代码里,没有藏**:H-type 上标定规则发 187 张证书、外部背书 56 张;严格规则发 36 张、背书 35 张。**按绝对背书数标定规则反而多(56 > 35),我们仍然选严格。**
> 理由:证书是一个**主张**。发 187 张而独立裁判只认 56 张,正是本项目批评单 oracle 工具的那件事。**精度才是产品。**

> **两条修法都被否之后才限制,而不是一开始就限制。** k≥2:29.9% → 26.5%,没用。全局能量门槛:H-type 方向对、kissing 方向相反 —— **修好一个必然弄坏另一个。**

## 4. 第三个领域跑完之后要回答的唯一一个问题

**不是"成功了没有"。**

> **这份协议在第三个领域里,哪一步没说清楚?**

预期的候选(写在前面,免得事后合理化):

- **步骤 3** 没说清"近似正确"的诱饵该怎么构造 —— 假结用了嵌套骨架、共转录用了同分异构体,这两个都是**领域特有的巧思**,协议只说了要有,没说怎么找;
- **步骤 4** 在没有天然正样本时只说了"退到相对效度",没说**相对效度要多强才够**;
- **步骤 1** 的"三种会杀死它的结局"依赖写的人想得到 —— 想不到的那种结局不会被写下来。

**这三条都是已知的洞。跑完之后应该多出几条我们现在想不到的 —— 那才是 v2 的价值。**

## 5. 已选定的第三个领域及其前提检查

**RNA–RNA 相互作用结构。** 前提检查(P1–P3)在开跑前完成并落盘,不通过就换。

| | 状态 |
|---|---|
| **P1** ≥3 个**独立**预测器 | ⚠️ **第一次勾错了。** `RNAduplex` / `RNAcofold` / `RNAup` / `RNAplex` 是**四个算法、一套能量模型**(同属 ViennaRNA),按上面补写的口径只算**一个源**。<br>**改正后:ViennaRNA 侧四家 + RNAstructure 侧 `bifold` / `AccessFold` / `DuplexFold`(独立代码库、独立参数集,已装在 `rnastr` 环境)= 两个源。**<br>**两个源仍不满足"≥3 个独立"** —— 第三个必须另找(候选:IntaRNA、RIsearch2),**找不到就换领域,不放宽门槛。** |
| **P2** 互不一致 | ❌ **不过。** 总体 = 设计序列 + 其内部窗口的完美反向互补触发链(= 我们开关能力真正用的那个)。四家逐对 kappa **全部 ≥0.80**(0.804–0.955),逐对精确重合 Jaccard 0.77–0.95 |
| **P3** 严格判据下交付不了 | ❌ **不过。** 四家给出完全相同的相互作用:**55/120 = 45.8%** |

> **入场判定:不进入。门槛不放宽,换领域。** 这是跑之前就写死的规则,现在执行它。
>
> **同时这是个对产品有用的正面结论**:在我们开关能力实际使用的那个总体上,**RNA–RNA 相互作用不是判据缺失的领域** —— 四家一致,严格判据已经能交付近一半。**那里不需要标定过的尺子,直接用严格面板就行。**
>
> **两个 parser bug 在下结论之前被抓出来,记录在案:**(a) `RNAduplex` / `IntaRNA` 的括号配对我写成了"最后一个闭括号配最后一个开括号",产出的是**物理上不可能的平行双链**,并因此与 RNAcofold(正确的反平行)零重合 —— **它会伪造出一个"它们不一致"的 P2 通过**;(b) `bifold` 把 20 个次优结构写进同一个 ct,我把所有数字行都收了,推出的 linker 长度 1143,于是**每一对都返回空集**,而空集对所有人给出 kappa 恰好 0.000,读起来像"完全不一致"。**两个 bug 都会把 P2 从"不过"翻成"通过"。**
| **P4** 需求 | 正交集合 22 次 / 两态开关 36 次(1676 篇设计文献),两类**外部工具零供给** |

**选它的第三条理由,是它能补上第二把尺子缺的那样东西:天然正样本存在。** 细菌 sRNA–mRNA 配对的相互作用位点是实验测出来并发表的 —— 所以第三把尺子可以拿回**绝对灵敏度**。

> **第三把尺子有机会比第二把更强,这本身就是"协议在起作用"的一个可检验推论。**
