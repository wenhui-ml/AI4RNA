## 一、必须先撤回的两处

### 1.1 撤回:"带符号的差把共用项【精确】相消,而离散度只【部分】相消"

我当时的模型:`score_i = 真值 + 共用 + 独立_i`。

**错在:共用项对三家判官是【同一个数】,所以它在离散度里也被精确消掉了。**

```
std({t+c+e_1, t+c+e_2, t+c+e_3}) = std({e_1, e_2, e_3})      共用项 c 精确消失
(t+c+e_i) − (t+c+e_j)            = e_i − e_j                  共用项 c 精确消失
```

**两者都精确相消。我说"离散度只部分相消"是错的。**

**站得住的说法要弱得多,而且是【信息论】的、不是【相消】的:** 带符号的成对差**决定**离散度,反之不成立
——差保留了"**是哪一家**离群、**往哪个方向**",离散度把这两样都扔掉了。所以带符号结构**信息不少于**离散度,
**但这不是因为它消得更干净。**

**还有一条我当时没写的、更要紧的限制:** 那个加性分解本身是个**线性化**。共用误差是**能量模型里的偏差**,
它经过折叠算法**非线性**地传出来。**所以"相消"是一个启发式,不是定理。** 用它可以设计实验,不能用它下结论。

### 1.2 撤回:"未测的物理收缩成每类假结一个标量,于是判定就可算了"

**收缩是真的,判定可算是假的。** 漏掉的是:**竞争者里还有【带交叉的】竞争者。**

一条设计可能误折成**另一个假结**。而 `Z_交叉竞争者` 既不可算,也**不能**用嵌套世界去界
——带交叉结构的"嵌套部分"不是一个嵌套结构。**我上一次说"用精确的嵌套世界去界它",这句话是错的。**

**经过 review 活下来的是一个更弱、但形状清楚得多的东西:**

> 可精确算的比较是**靶标 vs 整个嵌套世界**。它是设计成功的**必要条件,不是充分条件**。
> 于是它给出的是一个**单侧检验**:能证明"这条设计输给嵌套世界",**不能**证明"它赢"。

**而单侧恰好对得上我们的处境**——因为它把一类**面板的错误变成可证的**:任何被 `knot_confirmed`
接受、却被这个精确检验判定输给嵌套世界的分子,**都是一次不需要湿实验就能确证的面板误收。**

## 二、问题定位:"假结问题无解"在这个项目里指过三件不同的事

| | 是什么 | 性质 | 可逼近性 |
|---|---|---|---|
| **(a)** 一般情形带交叉折叠 NP-hard | 复杂性事实,**最坏情况** | 数学定理 | **不能动** |
| **(b)** 没有可信的假结验证器 | 三家判官全是启发式、**共用 Turner 能量族**;`knot_confirmed` 实测试管失败率 **20.8%** | **经验事实** | **能,而且这是真正的堵点** |
| **(c)** 假结能量参数**从未在湿实验里测过** | pKiss 的 `--help` 自述 | **物理数据缺失** | **能缩小,不能凭空造** |

**我们长期把 (a) 当成挡路的那一个。挡路的是 (b) 和 (c)。**
而 (b)(c) 都不是复杂性问题 —— 它们是"**什么能被精确算、什么能被相消、未知量能被压到几维**"的问题。

**已量出来的余量(不是估计):**

```
出厂现在用的判据       净 R² 0.047
用现有材料就能到的       0.196     <- 已测,是出厂的 4 倍(ceiling_probe)
试管自身可靠度的上限     0.811     <- 天花板
```

**所以"逼近"这件事有数:我们站在试管上限的 6%,而有一条【已被量出来的】路通到 24%。**

## 三、分解:一个改变问题性质的不对称

**NP-hard 说的是"给定【任意】序列,判定它的结构"。我们不需要那个。**

我们要的是:**给定靶标,找到【一条】序列。** 而这件事有测量支撑:**DesiRNA 在 Eterna100 上 99/100
—— 搜索不是缺口,早已测掉。**

> **所以复杂性壁垒可以绕,绕法是逆问题本身给的:我们可以【挑】一条序列,让它的嵌套竞争格局精确可算
> 且被主导。最坏情况的定理管不到"我只需要一条好的"。**

**分解成三层,每层的性质不同:**

| 层 | 问题 | 现在的做法 | 性质 |
|---|---|---|---|
| L1 生成 | 找到候选 | DesiRNA,99/100 | **基本解决** |
| L2 判定 | 这条候选对不对 | 三家启发式判官投票,`k = 有几家同意` | **真正的堵点(b)** |
| L3 物理 | 判定所依据的能量对不对 | 假结罚项是猜的 | **数据缺失(c)** |

**L2 与 L3 是耦合的**:L2 之所以不可信,部分正因为 L3 未知。**而方法论对这两层各有一个动作。**

## 四、方法论的四个动作(诚实标注哪些是他们的、哪些是我的加工)

| | 动作 | 来源判定 |
|---|---|---|
| 一 | **换表示,让解析困难变成一个【离散指标集上的记账问题】**(连续动力学 → 对带标号碰撞历史图求和) | **是他们的。** 我把它讲成"不要塌缩分布"是我的加工,而那个讲法接近通用套话,要小心 |
| 二 | **按一个【不变量】切分指标集,不去界整个和,而是劈成"能精确算的主部"+"只需被界住的余部"**(树 vs 环) | **是他们的,而且是本文两个构造的来源** |
| 三 | **逐项估计失败时,说明你不该逐项估计 —— 去找抵消结构** | **是他们的技术核心。** 但我给出的转译(共用项在差里相消)**是初等代数**,而且只在加性模型下成立(§1.1)。方法论贡献的是"**在哪里用它**",不是它本身 |
| 四 | **长程结论 = 短程结论 + 误差传播的控制**,不是一个更大的全局论证 | **是他们的。** 我们对应的空白:R1 测了阶段【局部】的信息,**从没测阶段之间的误差【传播】** |

**而界线要写成一条会被执行的检查项,不是一段写完就放着的话** —— 8-20 上午我写下"我们这里没有小参数",
**当天下午就推了一条需要把罚项当小参数的定律**(详细版 §三之十三)。

> **可复用的界线:这个类比在【结构层】成立(嵌套=树图 / 交叉=环图,精确对应)、在【技术层】成立
> (问和稳不稳、找抵消),在【定量定律层】不成立 —— 因为我们没有一个渐近趋零的小参数。**

## 五、经 review 活下来的两个构造

### 构造一(主):临界假结罚项 γ* —— 把未测的物理压成"一个标量必须落在哪个区间"

**动作二的正确用法。** 靶标能量精确分解为:

```
E(靶标) = E(嵌套骨架)  +  ΔG_stack(交叉螺旋)  +  γ(假结初始化)
            ↑精确           ↑近似(见下)          ↑唯一的未知,每种假结类型一个标量
```

而**嵌套世界的全部配分函数 F_nested 是精确可算的**(O(L³),参数都是测过的)。于是"靶标能否胜过整个嵌套
世界"这个**必要条件**给出一个**每分子一个数**的量:

> **γ\* = F_nested − E_skeleton − ΔG_stack(交叉)**
> **靶标胜过嵌套世界 ⇔ 真实的 γ < γ\***

**γ\* 只用测过的参数,不含任何未知。** 未测的物理被压成一句话:**真实的 γ 落在哪里。**

整个构造是空壳)。

**两件立刻可读的事:**
1. **pKiss 猜的那个默认罚项 9,正好落在这个范围的中间。** 也就是说:在同一个能量框架下,
   **我们的靶标有一部分处在"这条设计成不成,取决于那个从未被测过的常数到底是多少"的位置上。**
   这是把 (c) 从一句借口变成一个**可定位的**陈述。
2. **P09 的 γ\* = −6.97 < 0** ⇒ 在**任何**正的假结罚项下,它都输给嵌套世界。**这是一次不需要湿实验的
   可证否决。** 而它在面板下是什么档位,是下一步第一个要查的。

#### 什么是精确的、什么是近似的、什么是未知的(必须写清)

| | 状态 |
|---|---|
| `F_nested`(嵌套世界配分函数) | **精确**,ViennaRNA `pf()`,参数测过 |
| `E_skeleton`(靶标去掉交叉后的能量) | **精确**,`energy_of_struct(s, round_only(target))` |
| `ΔG_stack`(交叉螺旋自身堆叠) | **近似**:我按相邻交叉配对贴测过的近邻堆叠项求和,**省掉了**(i) 交叉螺旋与其余部分的环熵耦合、(ii) 螺旋末端的悬挂/末端错配、(iii) 同轴堆叠。**误差未量化** |
| `γ`(假结初始化) | **未知**,每种假结类型一个标量 |

**所以诚实的表述是"一个未知标量 + 一个未量化的近似误差",不是"一个未知标量"。** 这比我 8-20 夜说的弱,
但它是能站住的那个版本。

#### 可被打死的预测(不需要拟合)

**γ\* 低的分子应当在试管里更容易失败。** 我们有 4,560 条带 OpenKnot 分数的分子。
**这个检验不需要拟合 γ,只需要 γ\* 的排序。** 若 γ\* 与试管分数无关 ⇒ 这个构造对现实无预测力,弃掉。

### 构造二(次):把面板的聚合从【计数】换成【差分】

`k = 有几家判官同意` 是逐项聚合,而判官共用误差路径 ⇒ 误差**相加,不相消**(动作三)。

**但按 §1.1 更正后,这条的地位下降了:** 相消论证只在加性模型下成立,而且离散度也精确相消。
**所以它现在的依据不是"相消",而是两条更弱的:**

1. **信息论**:带符号的成对差决定离散度,反之不成立(保留了"哪一家离群、往哪个方向")。
2. **已有的经验线索**:D3 的**对照臂**(非线性分歧列)越过了 `F2 ∪ f1c = 0.196` 的杆
   ——**+0.0040 [+0.0006, +0.0103]**,而我预注册的那个稳定性假设两批都跨 0。

**注意一个我必须自己提的反驳:** F2 已含三家全部 15 根列,**线性模型本来就能组出任何差**。
所以增量只可能来自**非线性**部分(离群者身份、符号模式)。**这使构造二成为一个小效应实验,
而不是一个方向性突破 —— 它的位置排在构造一之后。**
