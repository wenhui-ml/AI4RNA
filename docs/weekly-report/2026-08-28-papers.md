## 一、NM 论文:正向侧(本文档主体)

### 1.1 topic

> **Scoring RNA Structure Prediction on Interventions That Have Already Been Performed**

它要顶掉的那个东西写在摘要第一句:**常规结构基准已经没有分辨率了。** 在本语料上,
被比较的配对里 G--C 靶标有 `cvHitCG`、A--U 靶标有 `cvHitAU` 已经被恢复,
而**这个一致率随"哪些配对进入比较"变动 `cvSwing` 倍**。一个答案能被入选规则拨动几倍的指标,不是指标。

### 1.2 先划清一件事:这是 measurement advance,不是 thermodynamic discovery

我们确实测到 `R(GC) > R(AU) > R(GU)`,在 design / depth / crossing 控制后仍成立。
**但这一条不能当卖点。** 理由不是谦虚,是文献:GC 相关的偏好、末端配对效应、
以及 Eterna 早年的 GC placement 设计规则**都不是今天才知道的**。审稿人有权说:

> "You have experimentally recovered an expected thermodynamic preference."

**这句话我们接受,并且从摘要里主动让开。** 论文守的是另一句:

> **Compensatory mutagenesis resolves pair identity at the level of an experimentally interrogated
> base pair, without requiring a folding predictor.**

**新的不是"GC 更强",新的是"这件事可以在不引入任何参考结构、不引入任何预测结构的前提下被量出来"。**

### 1.3 正向发现(六条,按论文里的顺序)

#### 发现一:语料里躺着 **4317** 次已经做完并测过的受控双核苷酸干预

准入判据是**测量协议本身**,不是一个可以放松去凑数的过滤器:

```
同长 · 设计窗内恰好 2 处差异 · 这两个位点在声明的靶标结构里成对 ·
野生型配对是 A-U / C-G / G-U · 且 mut[i]==wt[j] 且 mut[j]==wt[i](取向翻转)
```

八条**具名排除理由逐条计数并报出**;歧义(多个野生型,或多个能解释的配对)**一律排除,不用规则去化解** ——
化解它就等于让语料自己挑要提供哪个干预。**置信度可以用来加权,但永远不参与准入。**

> `nAdmitted` 条从 `nConstructs` 条构建体中纳入,**逐条排除理由的计数与纳入数一起印在正文里**。
> 一个挖不出东西的语料就是挖不出,`MiningReport` 直接这么说,**不会悄悄降级**。

#### 发现二:结果量**不经过任何模型** —— 这是整篇论文的地基

```
R = 1 − ‖d_ij‖ / √(‖d_i‖² + ‖d_j‖²)      在设计窗上,d 是反应性剖面的变化
```

**`m26w` 从语料的原始反应性行独立重算了一遍这个量:n=4688,Pearson `1.0000`,Spearman `1.0000`,
最大差 `0.001426`,中位差 `8.1e-05`。**

> **这条检查是非循环性的全部证据。** 如果结果量里混进了任何折叠预测,
> 后面"给预测器打分"这件事就是拿模型去打模型的分。**它没有,而且是量出来的,不是声称的。**

#### 发现三:**两类模型都有真技能,而且它们不是同一根列**

| 预测器 | 层内技能斜率 | 置换 p | 标定 |
|---|---|---|---|
| ViennaRNA(McCaskill 配分函数) | **+0.12059** | 0.0020 | **单调**:rescue 随自身配对概率的 5 个箱从 `0.2994` 升到 `0.5038` |
| RibonanzaNet-SS(化学 mapping 上训练的 transformer) | **+0.20692** | 0.0020 | **非单调**(顶箱回落:−0.0743 / −0.0070 / +0.0164 / **+0.0355** / +0.0294) |

两者的 Pearson 只有 **+0.4879**(Spearman +0.5752)⇒ **不是同一个预测的两个版本**。

> **单调性我们照实报:热力学模型单调,神经模型不单调。** 论文不写"两个都单调"。
> 非单调意味着神经模型的**尺度**只能当序,不能当量 —— 这一句写在正文里,不在附录。

#### 发现四:神经打分头**确实在读配对**,不是在读别的

`m26c` P6:同一个模型、同一次前向,**靶标配对上的平均分 `0.7812`,非靶标位点对上 `0.0026` ⇒ 相差 `303×`**;
对称化后的不对称误差 `0.0`;取值域跑满 `[2.07e-11, 0.99999]`。

> **这是"打分头没有退化成常数、也没有在读长度/位置这类平凡量"的直接证据。**

#### 发现五:技能**不是背出来的** —— 四级泄漏审计

| | 数 |
|---|---|
| 神经模型自己的来源库(14 个 RMDB 沉积)去重序列 | **861,916** |
| 我们的构建体 | 14,416 |
| **全长精确命中** | **0 / 14416** |
| 设计窗精确命中 | 25 |
| 设计窗相似度 ≥ 0.8 / ≥ 0.9 | 6.37% / 3.84% |

切掉 158 个设计里被判泄漏的 **14 个(8.9%)**:

| | 全量 | **干净子集** | 泄漏子集 |
|---|---|---|---|
| RibonanzaNet | +0.20692 | **+0.21549** | +0.10022 |
| ViennaRNA | +0.12059 | **+0.12881** | −0.01761 (p=0.63) |

**两个模型的技能在干净子集上都不降反升。**

> **`m26d` 脚本自己写的裁定字段是 `memorisation_explains_skill`,而这个裁定是错的,两条理由都在数里:**
> **(1) ViennaRNA 根本没有训练集,它不可能记忆,而它的干净−泄漏落差 `0.14642` 比神经模型的 `0.11527` 还大
> ⇒ 泄漏子集只是更难、更吵;**
> **(2) 随机抽同样大小(n=324)子集的斜率区间是 `[+0.0374, +0.4417]`,含泄漏子集的 `+0.100`
> ⇒ 两者不可区分。**
> **产物按冻结那一行原样提交,不回头改;更正写在审计里,而这一段现在是论文正文的一节,不是附录。**

#### 发现六:仪器读出了**两类模型的分野**(这是摘要的落点)

在同一批 `resWeight` 个配平后的成对权重上:

| | 把 G--C 与 A--U 分开多少 | 区间 |
|---|---|---|
| **测量** | `resOut` | `resOutCi` |
| **神经模型自己的预测** | `resNeural` | `resNeuralCi`(**同方向,同量级**) |
| **热力学模型自己的预测** | `resVienna` | `resViennaCi`(**不脱离 0**) |

> **仪器分辨出了一类模型表示得了、另一类表示不了的东西 —— 而这件事发生在
> 被真正合成并探测过的分子上,比较里没有任何参考结构进入。**

补一条独立实现的对拍(`m26v`):三个量由两套独立实现算出,**逐位对到 `2e-17`**;
逐格 144 格里 91 格为负,符号检验 `p=0.00194`。

### 1.7 M28 的结果(第二语料库,已跑完并复查)

**正向:** M2SL5 是三个天然冠状病毒 5'UTR stem-loop,两个**独立化学探针**(DMS 读 A/C 的
Watson-Crick 面;2A3 读骨架柔性)。两个沉积**都不声明靶标结构**,所以「两个位点在声明结构里成对」
那条判据**去掉了** —— 而扫描是穷尽的,去掉它反而**更严**:模型必须说**哪些翻转会 rescue**。
**全程没有任何参考结构或预测结构进入。**

| 预测器 | 层内秩相关 DMS | 层内秩相关 2A3 | 两探针之差的 95% CI |
|---|---|---|---|
| ViennaRNA | **+0.3024** (p=0.0015) | **+0.2283** (p=0.0060) | [−0.0761, +0.2305] **含 0** |
| RibonanzaNet | **+0.2387** (p=0.0065) | **+0.1905** (p=0.0315) | [−0.0829, +0.2262] **含 0** |

**四个臂全部为正、全部 p ≤ 0.05,而且两个探针不可区分。** 预测量只依赖序列,跨探针**逐位相同**,
所以这是干净的配对比较。

**约束性表达(正文里各一段,不展开):**

1. **预注册的统计量是线性斜率**,在那个量上 ViennaRNA 的 2A3 臂 p=0.1894 不过线。**原样报**。
   但跨探针比较**不能**用它:两个结果量的离散度差 **2.04 倍**(0.4120 vs 0.2021,DMS 有 2 条 < −1)。
   「预注册的统计量可能是读错的那个」这句**归姊妹论文,NM 只留一句指过去**。
2. **M3SARS 不可用,一句话讲清**:3954 次穷尽翻转 → **0 条可用**,原因不在干预而在**参考** ——
   三条野生型剖面 SN 只有 0.029~0.779(M2SL5 是 4.324 以上),而野生型剖面在三个差向量里都要被减掉。
   **可写进论文的正向陈述:语料能否承载这台仪器,由它的参考测量决定,不由干预数量决定。**
3. **E 臂(身份对比)按声明预判功率不足**,区间只当功率的测量报,不当身份的证据。
   **M3SARS_2A3 那个 p=0.030 不进正文** —— 梯级阈值 0.2,按第 66 条无裁决力。

## 二、R1 论文:必须换对象,而不是"降级投稿"

### 2.1 先说硬话:R1 现在这个样子**投不了任何地方**

我此前说"R1 降级去投计算机顶会"。**那个说法是错的。** 把 1620 行摸过一遍之后:

```
摘要里的每一个头条数,都是留存或中介分数
  eRet                  ← 能量臂「一点没中介」
  mRet, mMed            ← 模型集成预测臂
  pRetLo/Hi, pMedLo/Hi  ← 四参数集面板
  medFrac               ← 放置臂「分解闭合到 73%」
```

**它们不是"偏了",是【与真值相关 −0.70】。** 这不是投稿层级问题,是**中心量已被自己的标定判掉**。

而且矛盾**原来就写在 M21 自己的产物里**:

```
m21_thermo_mediator.json
  B2.mediated_fraction               = 0.7311    ← 乘积路线

  B2.monotone                        = false
  staked.2_mediated_fraction_in_20_60 = false
```

**两条路线在同一批数据上差 75 个百分点,并排写在同一个 json 里,而 `verdict` 字段
把裁定交给了后来被证明不可读的那一条,没有给出任何采信它的理由。**

### 2.2 但**失败本身就是那篇论文**

> 而且各自失败于对方查不到的检查。这里给出揭示它的标定、和在发表前抓住它的诊断。**

**分析单位从"分子"换成"估计量"。不需要任何新实验。**

## 四、再往上一层:从 Nature Methods 到 Nature / Science 需要什么

两个刊问的**不是同一个问题**:

| | 问什么 |
|---|---|
| **Nature Methods** | 你有没有造出一个**别人能用**的新方法? |
| **Nature / Science** | 这个方法有没有让我们发现一个**以前不知道的重要原理**,并且证明它对真实功能有后果? |

**我们现在在第一格,而且只在第一格。** 要跨到第二格,缺的是链条的后三段:

```
语料观察  →  机制规则  →  【前瞻性干预】  →  【新的 RNA】  →  【新的生物功能】
  已有        部分有         没有              没有            没有
```

**必须诚实的一条:我们现在没有一条新的 RNA 折叠定律。**
GC 相关偏好、末端配对效应、局部序列效应、设计方法特有的启发式 —— **都不是今天才知道的**。
我们的新东西**不是**「GC is stronger」,而是:

> **design-induced positional structure changes the scientific measurement of pair formation.**

**这一条就是要守住的 novelty,守住它,也就同时说明了为什么现在不该往 Nature/Science 投。**
