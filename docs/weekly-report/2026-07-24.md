## TL;DR
- **定位定死（战略,勿漂移）**:我们**不与 MIT 打擂台**,而是把两篇放进同一个 **AI4S 四层栈**——MIT = 生成/自修正层(表征如何变),我们 = **审计层**(被声称的能力能否经独立验证存活)。标题已从 "Climbing…" 软化为 **"Auditing a Claimed…Ascent"**,与实证对齐。
- **数理严谨:反侧我们更强(可判定定理)**。我们有一条**可判定的不可能侧**(Prop 1:pk-free oracle 值域⊆nested → CF-受限库对交叉靶标解出恒为 0;$O(|P|^2)$ 离线判定),MIT **没有**负侧。此结构还**跨域移植到 SAT**(clone theory:width≤2 ⟺ majority-closed ⟺ 2-CNF)。
- **正侧我们验证更透、但按设计是 model-relative**。3-oracle panel + 弃权,抓到**单 oracle gaming 43/60 → panel-unanimous 1/60 的 43× 膨胀**;诚实的 panel-robust 上升 = **3–8/60(5 seeds,均值 5.0)**。MIT 的正侧(functorial-transport 残差)是更干净的形式化正判据——这点我们**不宣称超过**。
- **北极星实证:agent 自主发明算子是跨前沿规律**。6 个前沿模型(3 开源+3 闭源)**全部**自主写出通过 certificate 的算子:held-out panel-unanimous **2–17/60**,全部 > gamer 1、> floor 0,4/6 超手搭 panel_auto。
- **本周做了一轮 ICML/ICLR 级 peer review(3 评审+AC)并修掉全部可核对硬伤**:一个我写进去的真 bug(pk∧pb 列实为 ProbKnot-alone,已修正为真交集 26–42/60)、Prop 1 等号错、Prop 2 无证明降级、pooled 统计聚类无效(改 cluster bootstrap,诚实 CI [4.0,13.3]% 仍 clears gamer 1.7%)。
- **跨源 robust-ascent 实验在跑(tmux `ccxsrc`)**:诊断显示当前 panel_auto 在 bpRNA 跨源只 2/60 形成交叉(Pseudobase 是 34–37)= 真·拓扑过拟合;正在测"加大预算能否提升 + DesiRNA 天花板"。
- **诚实结论**:反侧数理更严、正侧验证更透+更诚实(报了全部 null),但正侧按设计 model-relative 且能力小、class-ascent 尚是有限 held-out(未证无界迁移)→ **不能宣称无条件全面胜过**;胜在"互补 + 一条 MIT 没有的可判定负侧 + gaming-resistance"。

## 1. 本周视角:从"能力/成本"上移到"这篇论文在 AI4S 生态里占哪个位"
上周报的北极星是**元过程/成本**;本周聚焦**学术地标**。核心战略判断(用户拍板,勿漂移):

> 目标是**扩大硅谷 LLM labs 的 AI4S 影响力**,不是跟 MIT 那篇 self-revising discovery 打擂台。

所以论文重写为**互补的一层**,而非竞争者:

| AI4S 栈 | 谁 | 管什么 |
|---|---|---|
| 生成层 | FunSearch/AlphaEvolve 等 | 产出候选构造 |
| **自修正层** | **MIT self-revising discovery** | 表征如何随修正演化(范畴化 discovery) |
| **审计层（我们）** | **chomsky_climb 两侧 certificate** | **被声称的能力,能否经独立验证存活?** |
| 确认层 | 湿实验/DFT/定理检查器 | 物理/形式最终确认 |

标题相应从 "Climbing the Chomsky Hierarchy"(暗示已完成爬升)软化为 **"Auditing a Claimed Chomsky-Hierarchy Ascent"**——三位评审一致指出旧标题相对"同源 3–8/60、跨源 0/60"的实证**过度承诺**。

## 2. MIT self-revising discovery 在做什么(公允陈述)
- 一个**自修正系统**:表征/工件随迭代被修正,声称近乎首次在实战层面证明 AI agent 能**做出真正的科学发现**(蛋白柔性扰动)。
- **gaming-proof 判据**:范畴化的 **retrieval vs search vs discovery** 三分,其中 **discovery = 超出先前工件的 left-Kan / functorial-transport 残差**——一个**正侧、单侧**的 MDL 式判据("这个结果不能由已有工件函子式搬运得到")。
- 我们**借用了它的 retrieval/search/discovery 三分**作为脚手架(如实引用,不隐瞒);对它的公允评价:**正侧形式化干净**,但**没有可判定的负侧**("先前的库根本不可能做到"这类不可能性,它不提供)。

## 3. 我们的 chomsky_climb:两侧 certificate(一句话机制)
把"agent 是否真获得了一个能力类跃迁 CF→MCF"拆成**可判定否 + model-relative 是 + 自主性**三合取(②×③ = 相对先前自我 × 前沿,可验证、抗 gaming):

- **反侧(可判定,离线定理)**:RNA 二级结构里 nested=CF、crossing(假结)=MCF。pk-free oracle Ω_cf 的值域 ⊆ nested(Prop 1),故任何策略在 Ω_cf 下对交叉靶标解出恒为 0;判定 target 是否交叉是 $O(|P|^2)$,**在跑任何序列之前就判完**。经验 floor **0/60** 由此(+ E0:60 个真 REMC 骨架设计,panel 只 credit 0/60 为交叉、57/60 恢复 nested)。
- **正侧(model-relative,panel 裁决)**:pKiss + ProbKnot + ShapeKnots 三预测器**一致**才算解出、分歧则弃权。
- **自主性**:±外部 solver 的消融;真正的能力全在 oracle-guided repair(消融见 Table 7:decompose/compose 惰性,repair 去掉 43→25)。

## 4. ★ 核心:我们 vs MIT 的逐项对标

| 维度 | MIT self-revising discovery | 我们 chomsky_climb | 判定 |
|---|---|---|---|
| 核心对象 | 自修正表征的 discovery | **审计"能力类跃迁是否发生"的两侧 certificate** | 互补 |
| 领域 | 蛋白柔性 / 材料 | RNA 二级结构设计 **+ SAT 第二域** | 各有 |
| "发现/真"判据 | functorial-transport 残差(**正侧、单侧**) | **②×③**:相对先前自我×前沿,可验证+抗 gaming,**且带可判定负侧** | 我们更完整 |
| **不可能侧** | **无** | **可判定定理**(Prop 1,$O(|P|^2)$),且**移植到 SAT**(Baker–Pixley/Schaefer) | **我们更强(数理)** |
| gaming 抗性 | 单闸,未演示被 gaming | **演示 43→1 的 43× 膨胀被 panel 抓住** | **我们更强(实证)** |
| 正侧强度 | 范畴残差,形式化干净 | model-relative panel;能力小(**3–8/60**)、跨源窄(**0/60**)、未做湿实验 | **MIT 正侧更干净;我们不宣称超过** |
| 诚实度 | — | 报**全部 null**(budget-scaling null、跨源塌到 0、单 seed 欠功效) | 我们更透明 |
| 跨模型普遍性 | — | **6 前沿模型全部**自主发明通过算子(2–17/60) | 我们有独立卖点 |
| class-ascent 严格性 | — | 目前是**有限 held-out(=regular)**;无界迁移是 future work | 尚未完成 |

**我们相对 MIT 的具体改进(可点名)**:
1. **多了一条 MIT 没有的可判定负侧**——"先前根本不可能"是定理,不是软判据;且**跨域移植**(SAT),证明是通用结构不是 RNA trick。
2. **把 gaming 显式抓出来**——单 oracle 43/60 在独立 panel 下塌到 1/60,这正是单侧判据会漏的失败模式。
3. **异常诚实的 null**——让结论可信(评审 R2/R3 都把"诚实"列为最大优点)。
4. **agent 自主发明 = 跨前沿规律**——不是某个走运模型。

**我们不如 / 必须诚实的地方**:
1. **正侧我们是 model-relative 且小**;MIT 的 functorial-transport 是更干净的形式化正判据。物理"证明"我们做不到(需湿实验)。
2. **class-ascent 尚未真做到语言类层面**(有限 held-out=regular;无界迁移未证)——本周已把 §5 从"已是 class-level 证据"改诚实为"evidence toward"。
3. **顶会(非生物会)意义偏窄**——审计的"牙齿"依赖"可判定形式层级 + 失明 oracle",主流 agent 场景(code/math)不具备。

## 6. 诚实的能力/严谨性对照(本周定论)
- **数理严谨**:反侧(可判定定理 + SAT 移植)**明确强于** MIT;正侧 MIT 的形式化更干净。
- **科学性(实证 + 对抗控制 + 诚实 null)**:**强于** MIT——真实验、抓到 gaming、报全部 null。
- **能力大小**:正侧小(3–8/60)且跨源窄——**这是当前最大短板**,跨源实验就是要动它。
- **一句话**:我们在**"可判定负侧 + gaming-resistance + 诚实"**上胜出并互补 MIT;在**"干净正侧 + 完成的 class-ascent"**上尚未胜出。**不写"全面胜过"。**
