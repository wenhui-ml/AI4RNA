# 学术周报（2026-07-24）：地标论文 chomsky_climb 对标 MIT self-revising discovery

> 对象:学术论文 `paper/chomsky_climb/`《Auditing a Claimed Chomsky-Hierarchy Ascent in RNA Design: A Two-Sided Capability Certificate》。
> 目标:与 **MIT self-revising discovery system**（Wang & Buehler, arXiv 2606.01444）做逐项对标,明确本论文的相对贡献与短板。
> 数据来源:`rna_harness/runs/cc_ascent/`,均可复现。定位:同一 AI4S 生态内的互补一层,不作零和比较;不作"全面胜过"的表述。

## TL;DR
- 本论文提出**两侧能力认证(two-sided certificate)**,用于审计"一个自我改进的 agent 是否真获得了 CF→MCF 的能力类跃迁",而非产出新构造本身。
- 相对 MIT 的确定性贡献有四:(1) 一条 MIT 不具备的**可判定"不可能侧"**,且其结构可移植到 SAT;(2) 用独立三预测器 panel **实测出单 oracle 的 43× 评分膨胀**;(3) 报告了全部零结果(null),证据可信度高;(4) **6 个前沿模型均能自主发明通过认证的算子**,是跨模型规律。
- 相对 MIT 的短板同样明确:正侧按设计是 model-relative、能力规模小(3–8/60)、跨源不泛化、语言类跃迁尚停留在有限 held-out。据此**只主张"互补且在特定维度更强"**。

## 1. 定位:AI4S 栈中的两层
两篇工作处于同一 self-improvement 生态的不同层次:

| 层 | 工作 | 职能 |
|---|---|---|
| 生成层 | FunSearch / AlphaEvolve 等 | 产出候选构造 |
| 自修正层 | **MIT self-revising discovery** | 表征如何随修正演化并"发现" |
| **审计层（本论文）** | **两侧 certificate** | 被声称的能力能否经独立验证存活 |
| 确认层 | 湿实验 / DFT / 定理检查器 | 物理或形式的最终确认 |

论文据此定位为审计层,与 MIT 的自修正层互补;标题、摘要与相关工作章节均按此改写,不含对 MIT 的贬抑表述。

## 2. 逐项对标（宏观）

| 维度 | MIT self-revising | 本论文 chomsky_climb | 评估 |
|---|---|---|---|
| 数理基础 | **范畴论**(functor / left-Kan extension) | **形式语言 / 文法论**(Chomsky 层级:SCFG → MCFG,pumping lemma) | 不同工具 |
| "发现/真"判据 | functorial-transport 残差(正侧、单侧) | 相对先前自我 × 前沿,可验证且抗 gaming,并附负侧 | 本论文更完整 |
| 不可能侧 | 无 | **可判定定理**(pk-free oracle 值域 ⊆ nested,$O(\lvert P\rvert^2)$ 离线判定),并移植到 SAT(Baker–Pixley / Schaefer) | **本论文更强** |
| gaming 抗性 | 未演示 | 实测单 oracle 43/60 → 独立 panel 一致仅 1/60 | **本论文更强** |
| 正侧形式化 | 干净的形式化正判据 | model-relative panel;能力小、跨源窄、无湿实验 | **MIT 更强(本论文不主张超过)** |
| 证据透明度 | — | 报告全部 null | 本论文更透明 |
| 已完成的类跃迁 | — | 有限 held-out(=regular);无界迁移为 future work | 尚未完成 |

**两套数理工具(对标的核心)**:MIT 以**范畴论**为基础——将 discovery 形式化为超出先前工件的 **left-Kan / functorial-transport 残差**(一个函子式的正判据)。本论文以**形式语言 / 文法论**为基础——nested 结构由随机上下文无关文法(SCFG)生成、假结需**维度-2 的多重上下文无关文法(MCFG)**,二者的 CF↔MCF 边界由 **pumping lemma**(计数语言 $a^n b^m c^n d^m$)严格区分;可判定的不可能侧(pk-free oracle 值域 ⊆ nested)正建立在这套文法层级之上。两者可衔接:本论文借用 MIT 的 retrieval/search/discovery 范畴化三分作为脚手架,而把"不可能侧"落到文法层级这一**可判定的地基**上。

**关键事实(支撑上表)**:
- **反侧(可判定)**:nested = CF、crossing(假结)= MCF;pk-free oracle 无法输出交叉配对,故 CF-受限库对交叉靶标解出恒为 0。经验 floor **0/60**,并由 E0 独立佐证(60 个真 REMC 骨架设计,panel 仅将 0/60 判为交叉、57/60 恢复 nested)。
- **正侧(model-relative)**:pKiss + ProbKnot + ShapeKnots 三者一致才计解出、分歧则弃权。panel-robust 上升 = **3–8/60(5 seeds,均值 5.0)**;target 层 cluster bootstrap 95% CI **[4.0, 13.3]%**,高于 gaming 基线 1.7%。
- **agent 自主发明**:6 个前沿模型(3 开源 + 3 闭源)均自主写出通过认证的算子,held-out panel-unanimous **2–17/60**,全部高于 gamer(1)与 floor(0)。

## 3. 本周进展
- **同行评审**:由独立评审(理论 / 实验-数据核对 / 新颖性)加一轮元评审,评级为 borderline、可修复至录用线。全部可核对错误已修复,论文的可复现性与 rebuttal 稳健性提升。
- **表述与证据对齐**:标题去除"已完成爬升"的暗示;正文将家族实验由"已构成类级证据"更正为"朝类级主张的证据",与"无界迁移属 future work"一致。
- **跨源能力实验(已完成 60/60,`ccxsrc`)**:在 60 个 bpRNA/RNAInvBench 跨源交叉靶标上比较 panel_auto(加大预算:REPAIR 240s / 2500 iters)与 DesiRNA(SOTA)。结果:两臂的跨源 **panel-unanimous 均为 0/60**;DesiRNA 在 pKiss 下形成 9/60 交叉、仅 3/60 经 ProbKnot 确认,panel-一致仍为 0;panel_auto 形成 1/60。加大搜索预算未改变结论。这表明跨源 panel-unanimous 是**当前 SOTA 亦未逾越的可设计性 / oracle-严格度边界**(尤其 de-novo ShapeKnots),而非本论文算子特有的过拟合缺陷——正侧同源 3–8/60 因此是其诚实上限。

## 4. 下一步
- 跨源实验完成后据结果二选一:若为普遍性边界,则在论文中把跨源 0 从"过拟合"改述为"SOTA 亦撞的可设计性墙";若可突破,则升级为真跨源 capability。
- 将 error-backed 的跨源 floor 以 top-level REMC 补测为经验值(现由定理保证,尚缺经验落实)。
- 提升顶会普适性的可选路径:在一个非-RNA 的自改进 agent 场景演示该审计能抓出 gaming。
- 补齐引用元数据(不虚构作者)。

## 小结
本周将该论文明确定位为 AI4S 生态中的审计层,并经一轮顶会级评审完成加固。相对 MIT self-revising 的确定贡献为:一条可判定的不可能侧(可跨域移植)、对 oracle-gaming 的实测、全面的 null 报告,以及 agent 自主发明算子的跨模型规律;短板为正侧规模小、跨源不泛化、类跃迁未完成。论文按互补而非竞争定位,不作"全面胜过"的主张。
