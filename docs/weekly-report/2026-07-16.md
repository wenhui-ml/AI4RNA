## 1. 视角转变 + 度量换轴（本周最重要的一步）
**旧问法**:我们的搜索能追上 SOTA 吗?→ 追不上、也不该追(DesiRNA 97/100、泛化好)。
**新问法**:求解器已商品化,稀缺的是**给定任意问题→判断它是什么/多难/边界在哪→调哪个工具→给多少预算→卡住怎么改→以最低成本解出**——这套**人类专家式元过程**才是通用、可跨领域迁移的能力。

| | 旧 | 新 |
|---|---|---|
| 单位 | 解出 / 未解 | **cost-to-solve（$）** |
| 求解器 | 墙钟 cap | **CPU-秒 = 核数 × 墙钟 → $** |
| LLM | — | **总 token → $** |
| 判死 | 设小时限 → "墙" | **跑到解出、记成本;绝不 cap-and-mislabel** |
| 价值判据 | 解得多不多 | **同等质量下总成本更低吗?(且能否泛化)** |

## 3. 搜索线与边界（走到头并精确定位）
- **检索记忆(AF1 式 warm-start)→ NULL**:冻结预算、公平公共子集 n=28,priors/memory/memory_clamp 三臂均值 bp **无法区分**(之前"clamp 完胜"是**截断偏差**);配对头对头 memory 净负 → **检索记忆不优于通用 GC-刚性先验**。
- **搜索重构 → 有界化成功、非银弹**:从零 bpp 引导失败;补丁式局部搜索大 n 失控(`inverse_fold` 无界曾挂 45min);换 **replica-exchange MC(并行回火)** 后**统一 fold-call+墙钟预算、再无挂死**,易题秒解(pid36:135 折叠);但残差没啃下(pid57 砸 40 万折叠仍 bp=1)。
- **残差分类 + 可设计性诊断(42 题)**:解出 13/42,bp median≈1.5;**尺寸不是墙**(337nt 的 pid51 仅 486 折叠解出),难度由**结构**决定。**仅用 sample 判定(绝不喂求解器):29 个残差里 28 个可证明可设计,仅 pid100 不可设计** → 丢分是**搜索+算力**问题,不是可设计性墙。
- **纠正"墙"(关键纠偏)**:`bp=1 未解 @ 小预算 ≠ 墙`。给 DesiRNA 10min,6 道"疑似墙"里 89/92/64 解出;给 30min,79 也解出,只剩 71/87;对齐 DesiRNA 分档(85@1min / 97@24h),**真墙 ≈ 3**。

## 6. RSSD 实验：从"认知核是不是壳"到"agent 能自发现方法"

> RSSD = 残差靶向的自修正技能蒸馏。围绕**能力(效果)、成本(效率)、agent 自写方法(北极星)**三条线,做了一组防自欺(留出集,训练/评估不相交)的实验。全部代码 `rna_harness/experiments/rssd_*.py`,数字可复现。

### 6.1 真门槛已过：学到的路由确实同质量降本(且泛化、且随时间复利)
- **留出集(假结 251,训练学→冻结→没见过的题评估)**:学到的"弃权"(预测这题连 SOTA 都解不出 → 不烧 SOTA)在**同等解出**下比 always-SOTA **便宜 8–13×、0 解丢失**,3 种数据划分都稳健。消融:降本几乎**全来自"弃权"**(只做便宜先试+重排仅 3.5×);完美预知上界 28.4×,学到的策略已捕获约一半。
- **在线冷启动(不切训练/测试,边到边学)**:cost-per-solve **跌 97%**、累计 **31.6× 便宜** → **时间维度上会复利**(越跑越省)。
- **跨域(Eterna100)**:同一套"便宜先试 + 弃权"在另一个数据集 **2.7× 便宜、0 丢失、同质量** → **成本论题跨数据集成立**(Eterna 几乎全可解,省钱主要来自便宜先试而非弃权——机制随域而变,但结论一致)。
- 结论:**认知核不是壳,"学习是否降本"这个真门槛已过。**

### 6.2 把"写方法"的方向盘交给 LLM agent —— 北极星的首个正信号
让 agent **只看训练集**,自己**写出**假结设计的"技能代码" + "何时该弃权的策略",自修正若干轮,冻结后到没见过的留出集评估:

| 谁写的方法 | 留出集技能解出 | vs always-SOTA | 是否发现关键招 |
|---|---|---|---|
| 人工基线(v1) | 96/125 同质量 | 13× 便宜 | 是(基准) |
| gpt-4o | ~3/125 | ~1×(没省) | ❌ 没发现 |
| **GLM-5.2** | **91/125** | **62× 便宜** | ✅ **独立发现"交叉茎强制互补"** |

- **GLM-5.2 的 agent 自己写出了 `fix_crossing`——把每个交叉碱基对设成 G-C**,这正是假结能否成形的命门,也是我们人工技能用的那一招。它没被告知,是自己发现的。
- 结论:**强模型的 agent 能自发现可迁移方法 A_θ**(北极星首个正信号);gpt-4o 做不到 → **方法发现是模型能力问题**。诚实说明:agent 的弃权比人工粗,会多丢几解;开/关推理这次单点无定论(不做多种子——LLM 多种子几乎一样,不浪费资源)。

### 6.3 能力天花板：诚实认证
- **假结**:71 个残差用 **5× 重搜索一个都救不回**,再加**真序列约束也救不回(0/71)** → **是可设计性墙,不是搜索/算力/约束问题**,PK 真天花板 = 180/251(认证)。
- **Eterna**:硬残差集逐级加预算 60s→10min→30min,解出 **7→10→12(共20题)** → **86→97 差距主要是预算**,剩下的尾巴需数小时(与 DesiRNA 公开的 #97/#100 需 24h 一致)。
- **验证器成本(附带)**:用便宜的 MFE 预筛再上贵的 pKiss,能砍约 30% 验证成本但会丢几解——弱杠杆,如实记录。

## 附录 A：北极星发现详解——agent 自己发现了假结设计的关键招

> 本附录展开 §6.2 的核心结果(正文保持简洁,细节放这里)。这是项目**第一个"agent 自己发现方法"的实证**。

### A.1 实验设定：什么叫"把写方法的方向盘交给 agent"
不是让 agent 去解某道题,而是让它**写出"怎么解这类题"的方法本身**。协议(防自欺):
- agent **只看训练集**:一批假结结构 + 每题"DesiRNA 能不能解" + 一套积木 API(`inverse_fold`、`pkiss_fold`、`pk_pairs`、`round_only`…)。**从不告诉它该用什么方法。**
- 它要写**两个函数**:`design_pk`(廉价设计技能)+ `should_call_sota`(何时该弃权、何时该烧贵的 DesiRNA)。
- **自修正若干轮**(看训练集反馈改代码)→ **冻结** → 到**从没见过的留出集**跑,我们**用 pKiss 亲自复验它的每条序列**(绝不信 agent 自报)。

### A.2 agent 要发现的"关键招"是什么
假结的难点:目标里有**交叉配对** `[]{}`(伪结茎)。**只有当交叉茎的两个碱基是 Watson–Crick 互补(G-C / A-U)时,pKiss 才会把它折出来**。而现有工具(DesiRNA、REMC)都在优化 MFE 能量,**从不直接管交叉茎的互补**——所以命门是:
> **把目标拆成"嵌套骨架 + 交叉对",然后主动把交叉对的碱基设成互补。**
这一步没人教 agent。谁能自己想到并写出来,就算"发现了方法"。

### A.3 GLM-5.2 写出了什么(这就是"发现")
它的 `design_pk` 里赫然有这段——正是那一招:
```python
nested = prim['round_only'](target)               # 拆出嵌套骨架
crossing_pairs = target_pairs - nested_pairs      # 拆出交叉对
seq, _ = prim['inverse_fold'](start, nested)      # 先廉价解嵌套骨架

def fix_crossing(s):
    s_list = list(s)
    for i, j in crossing_pairs:
        s_list[i] = 'G'; s_list[j] = 'C'           # ★ 把每个交叉对强制成 G-C 互补
    return ''.join(s_list)
```
然后它自己搭了完整的**分解→组合→pKiss 在环修复**循环:`fix_crossing`/突变交叉对 → 重解嵌套 → 30% 概率再 `fix_crossing` → 用 pKiss 复验、留更好的。而且它**正确使用了 oracle**(`pk_bp_distance(pkiss_fold(seq), target)` 传的是点括号串)。这套流程和我们**人工写的 v1 技能思路一模一样——但是 GLM 自己从积木里拼出来的**,所以留出集光靠这个技能就解了 91/125。

### A.4 gpt-4o 为什么不行(同样拿到积木,两个致命错)
```python
candidate_seq = ''.join(rng.choice('ACGU') for _ in range(len(target)))   # 每轮纯随机重来
candidate_seq, _ = inverse_fold(candidate_seq, nested_structure)          # 只解嵌套
best_dist = pk_bp_distance(pk_pairs(pkiss_fold(best_seq)), pk_pairs(target))  # ★ bug
```
- **概念错**:也拆了嵌套,但**从头到尾没有 `fix_crossing`**——从不让交叉对互补,交叉茎只能靠运气 → 假结基本折不出来。
- **实现错**:`pk_bp_distance` 本该吃两个点括号串(内部自己调 pk_pairs),gpt-4o 却喂了两个 pair 集合 → 距离恒为垃圾值 → "留更好的"失效 → 空转,等于返回一条随机的、只满足嵌套的序列。

两家都"看懂了要分解",但**只有 GLM 迈出了"强制交叉互补 + 正确用 oracle"这关键一步**。任一错误单独出现都足以让 gpt-4o 归零。

### A.5 结果 + 为什么算"发现"而不是"背答案"
| 方法作者 | 留出集技能解出 | 总解出 | 成本 | vs always-SOTA |
|---|---|---|---|---|
| always-SOTA(每题烧 DesiRNA) | — | 96/125 | $5.42 | 1× |
| gpt-4o | ~3 | ~73–94 | ~$4 | ~1×(没省) |
| **GLM-5.2** | **91** | **91/125** | **$0.087** | **62× 便宜** |

**为什么是"发现"而非记忆**:agent 从没见过留出集这 125 道题,也没被告知方法——它写的是一个**通用过程**,拿到没见过的题上照样有效(91/125)。这正是 gaming-proof 判据(MIT "discovery vs retrieval"):**可迁移的过程,不是背下来的答案**。

### A.6 为什么这是"北极星信号"
项目的北极星是 **meta-learning harness 能否自己发现可迁移的方法 A_θ**(而不是靠人手写技能)。这是**第一个真实正例**:一个 LLM agent,只给积木和训练反馈,**自己拼出了领域命门级的设计过程**。而且它是**模型能力问题**——GLM 行、gpt-4o 不行——不是碰运气:**随模型变强,这条自动化方法发现的路会越走越通**。这就是路线 A(正在 Eterna 上验证是否跨问题类型泛化)的立足点。

### A.7 必须诚实说的边界
- **单种子**(没做多种子——LLM 多种子结果几乎一样,不值得烧资源),所以说"信号"而非"定论"。
- agent 的**弃权比人工粗**:62× 省,但留出集解 **91 < always-SOTA 的 96**(弃权太激进,丢了 5 道本可解)。诚实讲是"**95% 的质量、1/62 的算力**"。
- **self-revise 几乎没起作用**:4 轮训练集数字基本不变——决定成败的是**第 0 轮的"一次性写对"**,不是迭代改。
- 开/关推理这次**开推理反而更弱**(41 vs 91),单点、不下结论。

> **一句话:给强模型积木和训练反馈,它能自己写出领域命门级的解题方法,并在没见过的题上以数量级更低的算力接近 SOTA——这是"agent 自动发现方法"的第一个硬信号。**
