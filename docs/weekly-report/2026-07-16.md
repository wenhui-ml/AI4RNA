## 1. 视角转变 + 度量换轴（本周最重要的一步）
**旧问法**:我们的搜索能追上 SOTA 吗?→ 追不上、也不该追(DesiRNA 97/100、泛化好)。
**新问法**:求解器已商品化,稀缺的是**给定任意问题→判断它是什么/多难/边界在哪→调哪个工具→给多少预算→卡住怎么改→以最低成本解出**——这套**人类专家式元过程**才是通用、可跨领域迁移的能力。

| | 旧 | 新 |
|---|---|---|
| 单位 | 解出 / 未解 | **cost-to-solve（$）** |
| 求解器 | 墙钟 cap | **CPU-秒 = 核数 × 墙钟 → $** |
| LLM | — | **总 token → $** |
| 判死 | 设小时限 → "墙" | **跑到解出、记成本;绝不 cap-and-mislabel** |
| 价值判据 | 解得多不多 | **同等质量下总成本更低吗?(且能否泛化)** |

## 2. 认知核:本周主要技术产出
DesiRNA / RE-MC / MFE-oracle / pKiss / decompose 都退为**工具**;harness 的认知核 = **元过程本身**(分析→难度/边界识别→工具+预算分配→调用→正确 oracle 复验→失败则自修正,全程记成本、喂路由学习)。

`rna_harness/cognitive/`,全程零生物、RNA 只在工具层:

| 模块 | 作用 | 领域无关? |
|---|---|---|
| `cost.py` | 统一经济单位 $:求解器=CPU-秒、LLM=token | ✅ |
| `features.py` | **机械**结构特征(长度/配对/环/假结/lonely/嵌套…),对假结鲁棒 | ✅ |
| `tools.py` | 统一 `Tool` 接口:RE-MC + DesiRNA 包成动作,**用正确 oracle 复验**(MFE/pKiss),每次带成本 | RNA 在此 |
| `router.py` | 冷启动(最便宜先试)+ **k-NN 学**(按成本/解出概率排序);学到的路由 = 可迁移过程 A_θ,可持久化 | ✅ |
| `core.py` | 认知循环 + `FixedPolicy` 基线,全程记成本 + 喂 router 学 | ✅ |
| `evaluate.py` | cost-at-quality:cognitive vs always_cheap vs always_sota | 加载数据 |

- **测试**:`test_cognitive.py` 9/9;全套 **24/24**(+retrieval 10、desirna 5);经逐条审查(修 2 问题、核清 5 处一致性风险、grep 验证核心零 RNA 导入)。
- **可证伪主张**:*同等解出数下,认知核总成本($)低于任何固定策略(永远-SOTA / 永远-便宜 / 随机),且优势泛化到没调过的开放问题。* 退化成"永远无脑调 SOTA 满预算"就是壳。

## 3. 搜索线与边界（走到头并精确定位）
- **检索记忆(AF1 式 warm-start)→ NULL**:冻结预算、公平公共子集 n=28,priors/memory/memory_clamp 三臂均值 bp **无法区分**(之前"clamp 完胜"是**截断偏差**);配对头对头 memory 净负 → **检索记忆不优于通用 GC-刚性先验**。
- **搜索重构 → 有界化成功、非银弹**:从零 bpp 引导失败;补丁式局部搜索大 n 失控(`inverse_fold` 无界曾挂 45min);换 **replica-exchange MC(并行回火)** 后**统一 fold-call+墙钟预算、再无挂死**,易题秒解(pid36:135 折叠);但残差没啃下(pid57 砸 40 万折叠仍 bp=1)。
- **残差分类 + 可设计性诊断(42 题)**:解出 13/42,bp median≈1.5;**尺寸不是墙**(337nt 的 pid51 仅 486 折叠解出),难度由**结构**决定。**仅用 sample 判定(绝不喂求解器):29 个残差里 28 个可证明可设计,仅 pid100 不可设计** → 丢分是**搜索+算力**问题,不是可设计性墙。
- **纠正"墙"(关键纠偏)**:`bp=1 未解 @ 小预算 ≠ 墙`。给 DesiRNA 10min,6 道"疑似墙"里 89/92/64 解出;给 30min,79 也解出,只剩 71/87;对齐 DesiRNA 分档(85@1min / 97@24h),**真墙 ≈ 3**。

## 4. 两个数据集的开放性解题能力

### 4.1 Eterna100-V2（nested,100 题）—— 验证充分
能力逐级 escalate(全部实测、可复现):

| 配置 | Solved/100 | 性质 |
|---|---|---|
| base agent(极简 1-pass) | 55–58 | 地板 |
| + 记忆 / REMC 30s | 65 | |
| 自我改进 meta-ladder | 76 | 学习 |
| 全成本记账编排 | 81–83 | 工程链路 |
| **+ DesiRNA-as-tool 收官(残差,每题分钟级)** | **86** | 当前天花板 |
| 公开 SOTA(V2, **24h/题**)= DesiRNA | 97 | 要打的数 |

**86 用的具体预算**(全部 R=10 replicas,逐级 escalate,均为分钟级/题):
- 主体残差:`min(180, 30+0.5·n)s`/题(约 **48–180s**)——`desirna_residual`(42 题);
- 更难的近失:**400–600s**/题——`a_class_solve`(pass1 -t=600、pass2 -t=400);
- 最硬几题:开到 **1800s(30min)**/题——`desirna_openbudget`,而且**大多仍失败**(如 pid 71/87 在 1800s 仍 bp=1)。

所以 86 是在**每题 ~1min–30min** 的预算下达到的;而 DesiRNA 公开的 97 用的是 **每题最多 24h**(85 题 <1min、95 题 <1h、最后 2 题 #97/#100 需 ~24h)。

**到 97 的路径已明确**:我们调用的就是拿 97 的 DesiRNA,86→97 的差距**纯是预算**——还没给最后 ~11 个残差题付"小时级→24h/题"。并发已就位(160 核让残差并跑),限制是**单题墙钟**(最后 1–2 题各 ~24h)。**"到 97"是继承 DesiRNA;真正 novel 是"更低总算力逼近 97"或"换新求解器超 97"。**

### 4.2 Pseudobase++（假结,251 题）—— 本周补齐
| 指标 | 值 |

**结论**:假结这条腿从"机制验证过(24 题,17)"升级到"**全量真验证 180/251**"。**纠正 07-14 的自我判断**:我最初判"DesiRNA 在假结上出盒子(只建骨架)"是**错的**——逐案 PK 位点互补 4/4、6/6、5/5,DesiRNA 真能设计假结(pKiss 确认)。**咬人的边界是 verifier 不是 solver**:MFE oracle 对假结假阳,`is_pseudoknot` 守卫必须拒绝任何含 `[]{}` 目标的 MFE"solved"。

## 5. 160 核高并发基建
- `run_pk_desirna.py` / `run_desirna_residual_parallel.py`:`max_workers` 个靶标并发,每个 DesiRNA 子进程 R 个 replica → 峰值核 ≈ **workers×replicas**;默认 16×10=**160(authorized)**;服务器 256 核。
- 全 251 假结基线实测:158 个 DesiRNA 进程、load ~152、~80min 出全量结果。
- 同一基建可用于 Eterna 残差冲 97(160 核让 ~14 个残差题同时跑)。

## 6. RSSD 实验：从"认知核是不是壳"到"agent 能自发现方法"

> RSSD = 残差靶向的自修正技能蒸馏。围绕**能力(效果)、成本(效率)、agent 自写方法(北极星)**三条线,做了一组防自欺(留出集,训练/评估不相交)的实验。全部代码 `rna_harness/experiments/rssd_*.py`,数字可复现。

### 6.1 真门槛已过：学到的路由确实同质量降本(且泛化、且随时间复利)
- **留出集(假结 251,训练学→冻结→没见过的题评估)**:学到的"弃权"(预测这题连 SOTA 都解不出 → 不烧 SOTA)在**同等解出**下比 always-SOTA **便宜 8–13×、0 解丢失**,3 种数据划分都稳健。消融:降本几乎**全来自"弃权"**(只做便宜先试+重排仅 3.5×);完美预知上界 28.4×,学到的策略已捕获约一半。
- **在线冷启动(不切训练/测试,边到边学)**:cost-per-solve **跌 97%**、累计 **31.6× 便宜** → **时间维度上会复利**(越跑越省)。
- **跨域(Eterna100)**:同一套"便宜先试 + 弃权"在另一个数据集 **2.7× 便宜、0 丢失、同质量** → **成本论题跨数据集成立**(Eterna 几乎全可解,省钱主要来自便宜先试而非弃权——机制随域而变,但结论一致)。
- 结论:**认知核不是壳,"学习是否降本"这个真门槛已过。**

### 6.2 把"写方法"的方向盘交给 LLM agent —— 北极星的首个正信号
让 agent **只看训练集**,自己**写出**假结设计的"技能代码" + "何时该弃权的策略",自修正若干轮,冻结后到没见过的留出集评估:

| 谁写的方法 | 留出集技能解出 | vs always-SOTA | 是否发现关键招 |
|---|---|---|---|
| 人工基线(v1) | 96/125 同质量 | 13× 便宜 | 是(基准) |
| gpt-4o | ~3/125 | ~1×(没省) | ❌ 没发现 |
| **GLM-5.2** | **91/125** | **62× 便宜** | ✅ **独立发现"交叉茎强制互补"** |

- **GLM-5.2 的 agent 自己写出了 `fix_crossing`——把每个交叉碱基对设成 G-C**,这正是假结能否成形的命门,也是我们人工技能用的那一招。它没被告知,是自己发现的。
- 结论:**强模型的 agent 能自发现可迁移方法 A_θ**(北极星首个正信号);gpt-4o 做不到 → **方法发现是模型能力问题**。诚实说明:agent 的弃权比人工粗,会多丢几解;开/关推理这次单点无定论(不做多种子——LLM 多种子几乎一样,不浪费资源)。

### 6.3 能力天花板：诚实认证
- **假结**:71 个残差用 **5× 重搜索一个都救不回**,再加**真序列约束也救不回(0/71)** → **是可设计性墙,不是搜索/算力/约束问题**,PK 真天花板 = 180/251(认证)。
- **Eterna**:硬残差集逐级加预算 60s→10min→30min,解出 **7→10→12(共20题)** → **86→97 差距主要是预算**,剩下的尾巴需数小时(与 DesiRNA 公开的 #97/#100 需 24h 一致)。
- **验证器成本(附带)**:用便宜的 MFE 预筛再上贵的 pKiss,能砍约 30% 验证成本但会丢几解——弱杠杆,如实记录。

## 7. 这些结果导向的路线与可能性
- **路线 A（北极星,最有前景）——agent 自动化的方法发现 + 成本编排**:既然 GLM agent 已能自己发现 A_θ,下一步是让它在**更多问题类型上自发现并累积一个技能库**,router 学会"按问题选技能 + 何时弃权"。终点是一个**领域无关、能自我扩展**的解题元系统,而不是靠人手写技能。
- **路线 B（效率,稳健可交付）——cost-first 编排**:"同质量下 8–62× 省算力、随时间复利、跨域成立"已是硬结果,可作为**用数量级更低算力逼近 SOTA**的方法主线(比"谁解得多"更 novel:比"谁更省")。
- **路线 C（边界诚实化）——可设计性认证**:我们能**认证哪些题根本无解**(省得白烧算力),这本身是"知道何时停"的有用能力。
- **合起来的可能性**:**一个能自发现方法、又学会最省算力调用它们的 agent**——在"接近 SOTA 质量、数量级更低总算力、且跨域"这个维度上做出可复现结果。既是项目能力提升,也天然是有故事的研究方向。
- **工程待办**:对标公开榜单前需 pin ViennaRNA 2.6.4(我们用 2.7.2)。
