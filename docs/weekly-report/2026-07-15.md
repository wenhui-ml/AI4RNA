## TL;DR

- **外部批评救场**：一轮联网对抗式 review 让我们 **retract 三个过强头条**（"首个确定性测量"、"Goodhart 首证"、"MFE→pKiss 严格阶梯"），改成**可防守**的版本（model-relative、ladder+branch、θ>½ 形式化）。评级 4/10 → ~6.5/10。
- **六个实验全部实测**（pilot 规模），**跨域双证**（RNA + SAT）成立，并把 C5 抬到**有定理**。
- **里程碑**：`paper/verifier_economics/` 8 页 PDF 编译通过（图/表/引用齐）。

## 1. 命题：verifier 是可判定谓词，有强度阶梯
同一目标，一族**可判定、严格嵌套**的接受谓词（真值靠算不靠判）：
- RNA（无假结，单一热力学模型）：`exact-match ⊇ uMFE ⊇ P(T)≥θ`，**θ>½ 时可证嵌套**（P(T)>½ ⇒ 唯一 MFE）。
- 假结是**分支**（pKiss），不是更高档——ViennaRNA 吐不出交叉对，前三档**不可用**而非更弱。
- SAT 镜像：`满足 φ ⊇ ρ≥θ`（ρ=单翻转存活率），难度 = 子句密度 α。

## 2. 外部批评 + 修正（诚实的转折）
联网 review 精准指出并被我们独立验证为**成立**：
- **撞车**：C2（Goodhart）几乎正面撞 `LLMs Gaming Verifiers`(2604.15149)；"确定性测量 reward hacking" 宽口径被 `Hack-Verifiable Environments`(2605.20744) 占。
- **形式硬伤**：单条 ladder 错（pKiss 是分支）；P(T)≥θ⊆uMFE 只在 θ>½ 成立；"computed truth" 过强 → 改 **model-relative**。
- **方法论**：单个 93% 只是 metric mismatch，非 reward hacking，必须受控优化才成立；exact-match 二元会饱和 → Goodhart 需**连续廉价代理**。
→ 全部采纳，写进 `paper/POSITIONING_D_verifier.md`（REV2，含 retraction + 逐篇防撞规则）。

## 3. 六个实验（全部实测，pilot）
| 实验 | 结果 | 
|---|---|
| **E1' RNA 前沿**(61 题) | 存活 match 100 → uMFE 90 → pfe **7%**；中位 P(T)=0.25–0.30；**0 nesting 违反**；fp 率 n≥50 跳 ~100% |

| **E6' SAT Goodhart** | 弱/域依赖（如实报，不吹）|

## 4. 把 C5 抬到"有定理"（E5' verifier routing）
- **定理（可证 + 实测）**：嵌套 ⇒ 便宜档拒必是 gold 拒 ⇒ 便宜优先级联**恒等 gold（ε=0）**。实测 correctness **100%、0 unsound**。
- **成本 workload 依赖（诚实）**：reject-heavy **+60.8%** / accept-heavy **−25.3%** → 它是"拒绝过滤器"，非免费午餐。
- **风险前沿**：便宜档 FP **98%**，Clopper-Pearson **min-ε=0.999** → **鲁棒认证近乎不可压缩，必须付强档**（有限样本保证）。

## 5. 跨域：不是 RNA 重包装
frontier + cost 在 **RNA 与 SAT 双域同构**（脆弱性随难度崩 + 域内成本阶梯）。Goodhart **域依赖**（RNA 强、SAT 弱）——诚实的边界发现，不是失败。

## 7. 家族防撞（六篇一族）
- **vs A3 Oracle Residue**：不撞——D **锐化** αf≈1"干净极"是"选对 verifier 的结果"，不重推残差。
- **vs B SAT Compounding**：opposite sides——B 钉死 verifier 不可 game 研究 compounding；D 拨动强度研究 gaming×成本。且 D 补上"exact ≠ robustness-ungameable"。
- **vs C green-zone**：cost≠capability，解集不变。

## 8. 诚实风险 / pilot
