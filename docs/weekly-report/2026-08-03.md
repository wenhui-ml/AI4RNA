### 1.1 本期这一格是怎么来的:先量,再修,而且量出来的是个真产品缺陷

上期新上线了 `set_switch` 与 `set_cotranscriptional` 两个原语。**"上线"和"用户能拿到"是两回事**,所以本期专门做了一个基准问:**用户用大白话说出这个需求时,agent 会不会自己选这个原语?**

纪律:**8 种措辞刻意不复用系统提示里的词** —— 否则测的是字符串匹配,不是理解。

第一次跑出来是 24/36 和 12/24。看着像"模型有时候会漏",**但拆到每种措辞上,它是二值的**:

```
12/12   "有互补 RNA 出现之前一直保持关闭"
12/12   "边转录边折叠,不能中途卡住"
 0/12   "被另一条链触发而改变构象 —— 像核糖开关"      ← 全灭
 0/12   "在体内表达,折叠路径上不能有陷阱中间体"        ← 全灭
```

**全灭的两种,每一次都是【拒绝】,而且拒绝发生在模型被调用之前。** 根因是 `functional_request()` —— 一个硬编码关键词守卫:"riboswitch" 命中开关词表,"表达" 命中表达词表。**模型从头到尾没看见过这两个请求。**

**守卫本身是对的,不能删。** 它防的是:用户说"我要一条抑制基因 X 的 RNA",我们凭空发明一个形状,然后发一张**关于错误靶标的、内容为真的证书**。那是这个项目最怕的失败类。

**但它的前提没了**:这两个请求都自带点括号,**没有任何东西需要我们发明**。所以例外按**结构**给,不按关键词给 —— 守卫对每一个原来的词照样开火,判别式换成"请求里到底有没有结构"。测试同时钉住两半,防止它退化成"把守卫删了"。

**通过不等于覆盖,这是第三部分而不是补充说明。** 功能主张仍然没被任何东西验证,现在这句话**印在结果行本身**上:

```
certified (shape only -- the functional claim [...] is NOT verified by anything here)
```

拒绝会让用户损失一个他本来拿得到的答案;**静默通过会让一张关于【形状】的证书被读成关于【功能】的主张** —— 正是守卫当初要防的那件事。

```
修之前   开关 24/36 = 66.7%    共转录 12/24 = 50.0%
修之后   开关 36/36 = 100% [90%,100%]    共转录 24/24 = 100% [86%,100%]
没变的   普通请求上误选 0/36;选中的要求全部在证书里守住,36/36 与 24/24
```

> **这件事对 ④ 一分不加,必须说清楚。** 缺口早就证明了,判据早就有三层验证。它修的是**可达性**。
> 而可达性恰好是这个项目的北极星里的第一个字:**便捷**。

> **一个我自己的计分 bug 一并记录。** 第一版从 `cert["detail"]` 里读要求的判决 —— 那里根本不存在这个字段 —— 于是报出 "6 条里 0 条选了但没守住" 和 "3 条里 0 条",**一个从未发生过的产品失败**。判决在 `design` 步的 observation 里。那些 run 全部以 `certified` 结束,而循环只在所有声明的要求都成立时才置这个值,**所以真值一直是 6/6 和 3/3。**

## 3. ③ 范围更大 + 开放推理 —— 9/12(本期 +1)

### 3.1 上期三条缺口,本期问的是"它们是不是抽签抽出来的"

上期两条新缺口(共转录折叠、两态开关)各自只跑过**一次**求解器。而这个项目已经为这件事付过一次学费:**假结交付率曾被引用为 51/55 = 92.7%,五个独立种子跑出来是 45–51,51 是分布的上端,真值 87.6%。**

**把这条已经买过单的教训,补到还没用上它的两个地方 —— 10 个独立求解器种子:**

| | 工具自己的答案 | 筛同一批池 | 关键控制 |
|---|---|---|---|
| **共转录折叠** | 中位 41.7%,极差 12.5%,σ 4.4% | 中位 87.5%,极差 12.5%,σ 3.5% | 带内配对:工具 31.7% 对我们 83.3% |
| **两态开关** | 中位 47.9%,极差 19.4%,σ 6.9% | 中位 80.6%,**极差 0.0%** | 逐条 GC 严配(容差 0):工具 59.5% 对我们 88.8% |

```
共转录缺口在 0/10 个种子上闭合
两态开关的【决定性控制】在 0/10 个种子上闭合
```

**读法**:极差小 = 这是要求的性质;极差大 = 之前那个单次数字是一次抽签。

- 我们这一臂两条都很稳(共转录 σ 3.5%,开关极差 **0.0%**)。
- **工具那一臂在开关上极差 19.4 个百分点** —— 所以上期引用的单次数字"35/58 = 60.3%"确实是一次抽签,**现在报的是中位数与分布**。
- 单次曾报的共转录"工具 8/24 = 33.3%",十种子中位 41.7%,**比单次那个数字对工具更有利** —— 修正的方向不总是对我们有利,这次不是。

### 3.2 本期新增的那一格:要求清单第一次不是我们写的

> **判别原则(不是关键词表):区分【搜索怎么跑】和【答案必须满足什么】。** 迭代次数、温度退火系数、种子数是前者(plumbing);GC 含量、禁止子序列、可及性是后者(requirement)。

```

其中 26/33 = 78.8% 我们已经实测过

### 4.1 本期的主事件:同一套方法,第二个领域

**为什么这件事比再给假结加一个检验重要。** ④ 的主张从来不是"我们解决了假结",而是:

> **"在一个没有公认判据的领域里,我们能造一把标定过的、经外部验证的、适用范围诚实的尺子。"**

只做过一次,它是一个结果 —— 换个说法就是一次成功的运气。做第二次,它才是方法。**这是论文和轶事之间的全部距离。**

**第二个领域选共转录折叠,因为它判据缺失的方式和假结当初一模一样:**

```
Kinfold      随机模拟
findpath     启发式
前缀 MFE     确定性近似
三者不一致,而且没人能低成本说清一条设计好的序列在被合成的过程中折得对不对
```

#### 4.1a 验证方式不能照抄,原因是个限制,不是偏好

假结那次,**天然序列**能当正样本 —— 野生型确实形成已发表的结构,所以灵敏度可测。

**这里不行。** ViennaRNA 复现天然序列**自身**结构的比例太低,拿它做灵敏度会变成在测**折叠模型**,不是在测**动力学判据**。

所以直接问那个真问题:

> **`trap_fraction` 能不能预测一个独立模拟器看到的东西?**

```
总体   DesiRNA 的设计,每一条都已验证折叠正确 —— 折叠这个变量被钉死,只剩动力学在变
分组   按早已声明的判据 trap_fraction <= 0.10(写在 kinetic_suite.py 里,远早于这次实验)
裁判   Kinfold --grow(边生长边折 = 共转录),20 条轨迹/序列,从未进过本项目任何筛选回路
```

**预注册:接受组减拒绝组的到达率 > 20 个百分点,且 95% 区间不重叠。**

**而"两组一样"会是我们能学到的最重要的事** —— 那意味着 `trap_fraction` 在动力学上什么也没量到,第二条缺口需要大幅加限定。

**裁判先验过再往上盖**(RNAPKplex 那次的教训:脏工作目录会让它返回纯嵌套结构,照默认跑会得到完全相反的结论):

```
正对照   20/20 到达
poly-A   0/20 到达
工具跑不起来返回 None,不返回 0   ——   "没跑起来" 和 "折不到" 是相反的发现
```

#### 4.1b 预注册通过了,而我不用那个数字

```
40 条自然结构,432 条【已验证折叠正确】的候选

判据【接受】的   2440/2700 = 90.4%  [89.2%, 91.5%]
判据【拒绝】的   3791/5940 = 63.8%  [62.6%, 65.0%]
差距 +26.5%,区间不重叠      ->  预注册判据通过
```

**这个数字有两个毛病,而且都是致命的:**

| 毛病 | 后果 |
|---|---|
| **长度不平衡**:接受组均长 47.1 nt,拒绝组 55.4 nt | Kinfold 在**固定模拟时间**里以固定速率生长链条 —— 链越长,转录完之后剩给它折叠的时间越少。**长度单独一个变量就足以造出整个 +26.5** |
| **伪重复**:20 条轨迹/序列、最多 12 条候选/靶标被当成独立观测 | Clopper-Pearson 区间被算在了错误的重复层级上 —— **这正是区间看着那么干净地分开的原因** |

**五个控制,每一个都能单独否掉结论。**

> **样本的性质本期被我说错过一次,改正在此。** 我原写"扩到 178 靶标,是首轮的 3.7 倍",读起来像把首轮 40 条加大。**实际两批靶标只重合 2 条** —— 加深 bpRNA 读取深度(400 → 1200)之后取前 178 条,得到的几乎是另一批靶标。
> **所以这不是"更多的同一批数据",而是一次近乎独立的复现,比我原来写的更强** —— 但必须按它真实的样子说。

| 控制 | 它排除什么 | 结果 |
|---|---|---|
| **同 target 内配对** | 同一个 target = **长度与结构完全一致**,差值不可能是长度效应 | **+16.1 点**,接受组更好 **58/69** 个 target,Wilcoxon **p=2.9e-11** |
| **长度分层** | 捡回配对必须扔掉的那些 target | +20.9 / +28.5 / +25.4 / +31.3,**四层全部同号**,p 全部 <1e-9 |
| **聚类稳健 OLS** | 长度与 GC 同时进模型,标准误按 **133** 个 target 聚类 | trap 系数 **−0.377,p≈0**;长度 −0.0086/nt;**GC 这次也显著(p=4.2e-07)** |
| **GC 逐条钉死** | 同 target **且组分完全相同**(四位小数)—— 直接检验"塌回 GC" | **+13.6 点 [+8.2, +18.9],p=2.0e-06,79 个层** |
| **同分异构体** | 组分**构造上**完全相同(见 §4.1c) | **+10.7 点 [+7.1, +14.3],p=5.4e-07,59 个家族 / 881 条** |

> **前四行同一个总体,第五行不是。** 前四个控制都在同一批 DesiRNA 候选上做;同分异构体是**另造的一批序列**、另一个实验。把它并进这张表是为了让读者一眼看全,**不是说它们是同一个样本的五种切法**。

```
诚实的效应量:约 +14 ~ +16 点,不是 +26.5
```

> **"GC 逐条钉死"这一格差点变成一个错误的否定结论,记录在案。** 首轮 40 靶标上它只有 **+6.0 [−1.6, +13.7],p=0.18(29 个层)** —— 区间跨零,而这条要求的预注册里第三种死法正是"**塌回 GC**"。
> 没有直接报为 null,是因为**零结果必须带检验力陈述**:层内 trap_fraction 对比度是完好的(中位 0.27 对不钉时的 0.31,检验不空),而在观测到的效应量上要到 80% 检验力需要约 **96** 个层,当时只有 29 个。**报为"未确立",不报为"已否定"。**
> 样本扩到 79 个层之后:**+13.6 [+8.2, +18.9],p=2.0e-06 —— 确立。**
> **"我们看了,不在那里" 和 "就算在那里我们也看不见" 是两回事,而它们长得一模一样。**

**而且它不是"一个阈值恰好切得好"** —— 五个分档单调:

```
trap_fraction  [0.00,0.05)  88.8%     n=244
               [0.05,0.10)  75.3%     n=45
               [0.10,0.20)  70.3%     n=149
               [0.20,0.40)  65.0%     n=369
               [0.40,1.01)  49.4%     n=789

Spearman rho = -0.469,  p = 5e-88        (负相关 = 陷阱越多、到达越少,方向正确)
```

#### 4.1c 两个对抗零假设 —— 第一把有的,第二把本来一个都没有

假结那把尺子带三种对抗零假设 + 移位诱饵。共转录这把,验证过一次就完了。**一把只有一条腿的尺子不是尺子。**

**零假设一 —— 同分异构体,决定性的那个。**

把靶标某个碱基对的两端**对调**:`G-C → C-G`,`A-U → U-A`。

> **碱基多重集是【构造上】不变的,不是配出来的。** 这个项目此前每一个组分控制都是**筛选**:先是 GC 带(带内仍漏 3.2 个点),后是逐条 GC 配对(只剩 29 个可用层)。**对调是一个置换,它不可能改变多重集。**
> 靶标不变、长度不变,每一条异构体**仍须验证折叠正确**才算数。**唯一不同的是碱基坐在哪** —— 而这正是"路径性质"该看见、"组分代理"不可能看见的东西。

```
59 个家族,881 条异构体
接受(低陷阱)减 拒绝(高陷阱)   +10.7% [+7.1%, +14.3%]
46 个家族接受更好 / 12 个更差 / 1 持平        Wilcoxon p=5.4e-07
全部 881 条上 Spearman rho=-0.401  p=2.1e-35
```

> **这是第二次跑,第一次的数字作废了 —— 原因是我自己的一个 bug。** 第一版用 `hash((靶标, seed))` 播种,而 **Python 对字符串的哈希是每个进程随机的** —— 看着是"有种子的",实际**每跑一次抽到的是另一批异构体,构造不可复现**。
> 改成 `zlib.crc32` 之后重跑:**+10.7 [+7.1, +14.3] 对第一次的 +9.6 [+5.8, +13.5]**,结论一致。**但第一次那组数字是从一个复现不出来的构造里出来的,所以不作数,只作为一致性的旁证。**
> 这个项目的证书本来就把**确定性复验**和**不可复现的搜索**分开写 —— 而这个 bug 正好踩在那条线上。

**这一格的损耗必须一并报出来,因为哪些家族活下来是一次选择:**

```
178 条靶标  ->  46 条出错(45 条是 12 秒预算内没有一个折对的母序列)
            ->  73 个家族只有单侧,进不了配对检验
                  其中 64 个是【全高陷阱】 —— 判据对这个靶标一条都不接受
                  其中  9 个是【全低陷阱】 —— 判据全接受
            ->  59 个家族可用
参与检验的家族  长度中位 55  GC 中位 52.7
被丢弃的家族    长度中位 60  GC 中位 56.9
```

**配对检验在它用到的家族内部是无偏的,但"哪些家族用得上"不是随机的** —— 能用的那批更短、GC 更低。**所以这条结论只对"同时存在低陷阱与高陷阱异构体"的家族成立**,而那正是更容易的一批。

> **单侧那 73 个里 64 个是【判据一条都不接受】,这个数字本身是个结论,而首版脚本把它抹掉了。** 它把所有单侧家族记成同一个字符串,分不出"判据全接受"和"判据一条不接受" —— **而这两件事说的是关于判据的两个相反的事实。**
> 分开记录之后它说的是:**在 178 条靶标里,有 64 条我们的判据对该靶标的任何一个异构体都不放行。** 这不是判据错了,是**判据严** —— 但它划定了这条要求实际能覆盖多大范围,而这正是 §4.1d 里"适用范围"那一行该有的内容。

**测试钉住了那条承重的不变量**:如果哪次重构破坏了多重集保持,这个零假设会**静悄悄地退化回一个组分比较**,而且**照样给出一个看着很合理的数字**。

**零假设二 —— 判据是不是被调到某一个转录速度上的?**

`--grow 20` 是我拍的,不是量出来的。**而这个项目的整个论点就是"判决是模型相对的" —— 我们自己的判据必须先过这一关。** 同一批序列,转录速度拉开 16 倍重判:

| grow | 接受 | 拒绝 | 差 | p | Spearman |
|---|---|---|---|---|---|
| 5 | 88.4% | 71.6% | **+16.8%** | 4.9e-05 | −0.407 |
| 20 | 88.6% | 74.1% | **+14.4%** | 2.6e-04 | −0.351 |
| 80 | 90.0% | 72.3% | **+17.7%** | 4.0e-05 | −0.464 |

**同号、同显著性、三个速度上都单调。这把尺子不是被调到一个我们编出来的数字上的。**

> **这三个数字本身仍带长度混杂**(这一格是从存档里按 trap_fraction 等距抽的 120 条,没有做配对或分层)。**这一格要说的是"不变性",不是效应量** —— 效应量看 §4.1b 的五重控制。三个速度上的混杂是同一个,所以它不影响不变性这个结论。

#### 4.1d 这把尺子仍然比第一把弱在哪 —— 必须写清楚

| | 假结(第一把) | 共转录(第二把) |
|---|---|---|
| 正样本 | 天然序列(野生型确实形成该结构) | **没有** —— ViennaRNA 复现天然自身结构的比例太低 |
| **绝对灵敏度** | **78.5% [68.8, 86.3]** | **不可测** |
| 相对效度(与独立裁判一致) | ✅ 第四裁判 RNAPKplex | ✅ 外部模拟器 Kinfold |
| 对抗零假设 | 三种 + 移位诱饵,最难的 0/183 | ✅ **同分异构体 + 转录速度不变性**(本期补上) |
| 裁判之间的一致性 | ✅ 逐对 kappa 已实测公布 | ❌ **未测** —— Kinfold / findpath / 前缀 MFE 三者的一致性从没量过 |
| 适用范围诚实 | ✅ 按拓扑路由,写进代码与测试 | 25–70 nt,固定模拟预算;更长的没测 |
| 出厂操作点 | ✅ `knot_confirmed`,错误率已公布 | ❌ **尚不够格发证书** |

> **第二把尺子证明的是"我们的判据和一个机制上无关的模拟器看到同一件事",不是"我们的判据对"。**
> 这是**相对效度**,不是绝对灵敏度。它够格支撑"方法可迁移"这条子命题,**不够格支撑一张像假结那样的出厂证书。**

### 4.2 移位诱饵扩到全部三类拓扑:0/386

上期这条只在 kissing 上做过(0/79)。**一个判据如果是位置特异的,它应该在它被用到的每个地方都是。**

```
kissing / chain    0/79  = 0.0%  [0.0%, 4.6%]      (上期)
higher-order       0/9   = 0.0%  [0.0%, 33.6%]     位移1 可构造 8/9,位移2 可构造 3/9
H-type             0/298 = 0.0%  [0.0%, 1.2%]      位移1 可构造 180/187,位移2 可构造 118/187

合计 0/386
```

> **H-type 这一格必须标注读法,否则会被误读。** `shift_decoy` 直接调 `_knot_recall`,测的是**标定规则本身** —— 而产品在 H-type 上已改走严格规则。所以这一格回答的是:**标定规则在 H-type 上位置特异吗?**
> 它此前在 H-type 上的问题是**对外部裁判过松**(29.9% vs 71.1%),那是**另一种**失效。**这一格把两种失效分开了:标定规则在 H-type 上过松,但不是"随便哪个结都认"。**
> 而 n=298 是三类里样本最大的一格,把合计区间从 4.6% 压到了 1.2% 以下。

### 4.3 第一次和【测量】对照 —— 结果不确定,以及三个被自己抓出来的 bug

**这是本期真正碰到的边界。** ④ 现在的全部证据都是"我们的尺子和另一个模型看到同一件事":假结那把由 pKiss/ProbKnot/ShapeKnots 判、再由 RNAPKplex 复核;共转录那把由 Kinfold 判。**全是模型。判据缺失的终点是判据的判据,而那只能是物理。**

共转录 SHAPE-seq 恰好探测我们判据数的那个东西 —— **真实转录中间体,逐个转录长度**。RMDB 上有,网络可达。

```
9 个分子 / 4805 个已测转录长度
参照结构 = RNAstructure 用【全长实测反应性】定向折叠(独立代码库、独立参数、数据说了算)
           用我们自己的模型折就循环了
```

#### 预注册的检验没通过,然后被它自己的分段检查否掉

第一轮:陷阱前缀上 `MFE(前缀)` 比"靶标截断"更**不**贴合测量。看着像判据被推翻。但按转录进度分段:

```
[0.0,0.4)  +0.007      [0.4,0.7)  -0.022      [0.7,1.0)  -0.041
```

**优势在接近全长时最大、早期为零。** 而接近全长时前缀几乎就是整条分子 —— 这一比退化成"MFE 对 SHAPE 定向折叠,在 SHAPE 数据上比",**后者按构造必胜**。伪影出现的位置正好是所谓效应出现的位置。**这是我写的设计有问题,不是关于判据的发现。**

#### 替代检验是对称的,但它是**事后**设计的,而且修完 bug 后不显著

只比:在 MFE 的越界配对里、而参照说未配对的位点,对上同样是参照未配对的其他位点。**两组都是参照未配对,参照拟合得好不好因此抵消。**

```
修 bug 之前   8/9 个分子 >0.5   均值 0.576   p=0.0488
修 bug 之后   6/7 个分子 >0.5   均值 0.556   p=0.109     <- 不显著
```

#### 三个 bug,都真实存在,而且第二个直接改变了结论

| bug | 后果 |
|---|---|
| `ct2dot` 写"表头+序列+结构"三行,我把非表头行拼起来 | 长度变两倍 → **每一条都被报成"RNAstructure 没跑起来"**,一个从未发生过的工具失败 |
| **没有参照质量门槛** | 5 个构建体的参照连**它自己被拟合的那份全长数据**都解释不了(最低 **0.507** = 抛硬币),却和 0.78 的参照并列当同一种证据。加上门槛后被剔除的 5 个里,**PFLZTP(0.635)与 CRCBFL(0.773)恰恰是支持我们的** |
| 假定全局一个对齐,而 `OFFSET` 在文件间取 10 / 0 / −3,`SEQPOS` 有的从 −9 编号,FLUORSW 与 SRPECLI 每条只给 k−1 个值 | 差一位就整条分子偏移 |

> **对齐这一条,我先前的判断方式本身是错的,一并记录。** 我一开始用"哪个偏移让 `MFE(前缀)` 的 AUROC 最高"来定对齐 —— **那是让被测的模型自己挑对它有利的对齐**,和"看过两臂再选阈值"是同一类错误。
> 改成由**参照结构在全长数据上**定(与前缀 MFE 无关)之后,22 个构建体**全部** shift=0。**所以对齐本来就是对的,FLUORSW 那个反例不是伪影** —— 它的参照质量 0.724 合格,shift=0 明确。

#### 阶段性判断:不确定,既不是通过也不是否定

```
方向     一致(6/7 个分子 >0.5)
效应     0.556,很弱
显著性   没有(n=7,p=0.109;n=7 时全正的最小可能 p 是 0.0078,样本量本身就是天花板)
性质     事后设计,只能当假设
反例     FLUORSW 0.337(A 位点 0.207),参照合格、对齐明确,不是伪影
```

**一条独立于以上全部、仍然成立的**:判据把 **96.4%** 的天然转录中间体判成【陷阱】。这个数字不受设计缺陷影响 —— **在天然核糖开关上,"陷阱"这个词几乎对所有中间体都成立,规则写得极其宽松。**

> **这一节该怎么读:今天没有证明第二把尺子对得上物理,也没有证明它对不上。**
> 值得记的是**流程**:一个已经跑出 p=0.0488 的"通过",在复核里被自己的三个 bug 打回 p=0.109,**而它一次都没有进过对外的数字。**

### 4.4 借来的两把方法,两把都被自己的预注册否掉 —— 而这正是借得对的证据

**动机是 §4.3 里唯一稳健的负面事实:判据把 91.7%(该批 22 个构建体上)的天然转录中间体判成陷阱。** 一个几乎对所有东西都成立的词不干活。

`trap_fraction` 的定义是**逐前缀、等权、只数个数**。两个外来的方法形状,从不同方向说同一句话:**你数错了对象。** 先立规矩:**借哲学如果不能产出一个"不借就不会做的、可证伪的实验",那就是装饰。** 所以两条都先写死杀死条件。

| 借的形状 | 落到 RNA 上是什么 | 预注册 | 杀死条件 |
|---|---|---|---|
| **黏性/非黏性二分**(Kakeya 一路的做法:要么构型高度结构化、单独分类处理,要么计数论证赢,**两支都要赢**) | 越界配对若是目标真实螺旋的**竞争寄存器**(\|i−a\|≤3 且 \|j−b\|≤3)= 黏性;否则 = 偶然 | 黏性比非黏性**更能**预测 Kinfold | 分不开就报 null,**不去找第三种切法** |
| **尺度归纳**(不在单一尺度看对象) | 只在单个 k 出现的陷阱是抖动;跨 L 个核苷酸延伸仍在的才是结构 | L≥5 的持续性**强过** L=1(= 今天的规则) | L=1 最强就是否证 |

#### 结果:一个被反向否掉,一个通过但幅度小到没用

```
Spearman(定义, Kinfold 到达率),1596 条候选 / 133 个靶标,折叠调用完全共用

trap_fraction        -0.469     <- 今天的规则
nonsticky_fraction   -0.481     <- 信号几乎全在这里
sticky_fraction      +0.014  p=0.58   <- 竞争寄存器什么也预测不了
```

**|rho(黏性)| − |rho(非黏性)| = −0.445,95% [−0.519, −0.357]。** 不是"分不开",是**反着的**。

> **而且方向反得有物理含义。** 设计序列里,今天规则数进去的那些陷阱,**黏性占比中位数是 0.0%**。抽出来看实例就明白了:
> ```
> 靶标 925  k=14   越界配对 (0,9)(1,8)(2,7)
> ```
> 这不是"滑了一格的同一根螺旋",而是**只因为分子的另一半还没被转录出来,5' 端自己折回去形成的临时结构**。
> **共转录陷阱不是竞争寄存器,是"伙伴还没来"。** 这与 Kakeya 那个情形正好相反 —— 那里结构化的一支是敌人,这里**不结构化的那一支才是**。

**尺度这一条:通过了,但幅度小到不解决问题。**

```
最强尺度 L=5     rho=-0.487   对 L=1 的 -0.469
|rho(L=5)|-|rho(L=1)| = +0.018   95% [+0.003, +0.033]   p=0.006
```

统计上显著,**改进 0.018**。而且它**没有解决那个 91.7%**:

```
天然 RNA 上,各定义的触发率(22 个参照合格的构建体,构建体平均)
  今天的规则  91.7%
  L=5         88.6%      L=10  85.1%      L=20  78.2%     <- 几乎没动
  黏性         9.8%                                        <- 唯一压下去的
```

#### 所以真正学到的是一个张力,而不是一个修复

> **能把触发率从 91.7% 压到 9.8% 的那个定义(黏性),在预测上等于零(rho=+0.014)。**
> **能预测的那个(非黏性),正是造成 91.7% 的那一部分。**
>
> 于是 91.7% 这个数字**不是"我们数错了对象"**。它更像是在说:**天然核糖开关在转录过程中确实充满一过性的越界配对,而那恰恰是在设计序列上预测折叠失败的那一类。** 这是个可以继续追的假设,不是本期的结论。

**记账**:两次预注册,一次被反向否证,一次通过但幅度不足以改判据。**④ 不加分。** 借方法形状作为**方法论**是有效的 —— 它逼出了两个我们本来不会做的、能证伪的实验,并且两个都真的被证伪了。**它没有提升 ④ 的能力。**

> 顺带核过:黏性检测器在人造样例上正确(整体移位 1 的螺旋 8/8 判中,远处偶然配对 0 判中),**所以这个否证不是检测器坏了。**

### 4.5 两条并行的收尾:第三个领域被自己的入场规则挡在门外,天然一致性检验被【裁判】挡住

#### 4.5a 第三个领域(RNA–RNA 相互作用):入场检查不通过

装上 IntaRNA 3.4.1(独立环境)之后,协议标出的阻塞点没了 —— 三个代码库而不是一个包的四个二进制。**但它启动就打出 `using Vienna RNA package 2.7.0`** —— 自有算法、共享能量参数,**按协议它不能靠声明当第三个独立源,只有 kappa 说了算。**

总体在跑之前定死:120 条已归档设计 + 其内部 12 nt 窗口的**完美反向互补**触发链(**= 我们开关能力真正用的那个**)。

```
P1  四家全部 120/120 能跑                                    通过
P2  逐对 kappa 0.804–0.955,六对【全部】>= 0.80              不过
P3  四家给出完全相同的相互作用:55/120 = 45.8%               不过
```

> **不进入。门槛不放宽,换领域。** 规则写在数据存在之前,执行它而不是跟它讲价。
>
> **而这对产品是正面结论**:在开关能力实际使用的总体上,**RNA–RNA 相互作用不是判据缺失的领域** —— 四家一致、严格判据已交付近一半。**那里不需要标定过的尺子,直接用严格面板。**

**两个 parser bug 在下结论之前被抓出来,而它们都会把 P2 从"不过"翻成"通过":**

| bug | 后果 |
|---|---|
| `RNAduplex` / `IntaRNA` 的括号我配成"最后一个闭配最后一个开" | 产出**物理上不可能的平行双链**,与 RNAcofold(正确的反平行)零重合 —— **伪造出一个"它们不一致"** |
| `bifold` 把 ~20 个次优结构写进同一个 ct,我把所有数字行都收了 | 推出的 linker 长度 1143 → **每一对都返回空集**,而空集对所有人给出 kappa 恰好 0.000,读起来像"完全不一致" |

修完后四家在冒烟例上完全一致,并用碱基核对过是反平行(A[15]=G 配 B[11]=C)。

**协议因此找到了自己的第二个洞 —— 这正是它该交付的东西。** P2 只说"测它们一不一致",**从没说在哪个总体上测**,而答案完全由总体决定。完美互补是这个领域最容易的一档。v2 补上:**入场检查的总体必须是判据将来要签字的那个总体,并在跑之前写下来;事后换更难的总体重测是选择性报告。**

#### 4.5b 天然一致性检验:回答不了,而原因不是样本不足

要关掉的是 §4.4 留下的那个假设:**91.7% 是生物学还是数错?** 检验方式:`trap_fraction` 在**天然序列**上是否也预测 Kinfold 到达率。

结果是 22 个构建体里只有 5 个能算出相关。**第一眼我判成"分子不够",这是错的** —— 逐条查完是:

```
裁判(Kinfold 到达率)在构建体内无变化:17/22
判据(trap_fraction)在构建体内无变化: 0/22
```

**常数的是【结果变量】,不是判据。** Kinfold 在 17 个天然构建体上**一次都没到达过目标**。

而且这不是预算问题 —— 实测把模拟时间放大 100 倍:

```
CRCBFL 前缀 100nt   时间 8000 -> 0/10    80000 -> 1/10    800000 -> 1/10
BSUGLY 前缀 100nt   时间 8000 -> 1/10    80000 -> 0/10    800000 -> 0/10
```

> **`Kinfold --stop` 要求命中【那一个精确结构】。** 25–70 nt(设计那一侧的总体)上到达率 50–90%;**≥100 nt 上几乎恒为 0,加 100 倍时间也救不回来。**
> **所以第二把尺子的外部验证无法越过约 70 nt —— 这是量出来的,不是假设的。** 此前"作用域 25–70 nt"是一句声明,现在它有了机制:**裁判在那之外没有动态范围。**

**有动态范围的那 4 个分子,方向全部正确**(BSUGLY −0.133 / CRCBFL −0.314 / ECOSRP −0.521 / FLUORSW −0.658)—— **但它们是被"Kinfold 恰好能跑"选出来的子集,n=4,低于跑前声明的 6。按规则报【裁判无动态范围】,不报 null,也不当证据。**

**所以 §4.4 那个假设仍然开着。** 关掉它需要一个在 ≥100 nt 上还有动态范围的动力学裁判,而 Kinfold 不是。

### 4.6 穿越点:把判据从【一个结构】搬到【一个分布】—— 一半成立,一半被否

**先说诊断。** 把这一段的全部失败摆在一起,它们有同一个祖先,而且是我们自己选的:**所有判据都定义在【精确结构相等】上。**

```
trap_fraction     前缀 MFE 含目标之外的配对        -> 精确配对集比较
knot_confirmed    交叉茎【完全】复现,τ=1.0        -> 精确
Kinfold --stop    到达【那一个】结构               -> 精确
P3 严格规则       四家给出【完全相同】的相互作用    -> 精确
```

精确性是**第一把尺子成立的原因**(移位诱饵 0/386,差一个碱基也不认),也是**其余一切被卡住的原因**。所以穿越点是:**把判据从一个结构搬到一个分布。** 第一步换裁判 —— 问"走到多近",不问"是否命中那一个"。

#### 4.6a 意外的收获:我们的裁判一直在【低估】

预注册的第一道关是"d=0 必须复现老判决"。**它没通过 —— 而查下去发现错的是老判决,不是解析器。**

```
某条 60 nt:20 条轨迹全部在全长时打印过【精确的目标结构】
            却只有 11 条被标 X1,另外 9 条走过之后继续走,以 O 收场
            其中一条访问目标后又跑到 ...(....)... 才结束
```

**`--stop` 在 `--grow` 下不会在每次访问停止结构时触发。** 于是:

```
访问式 vs 标记式,700 条候选
  访问式 0.711   标记式 0.646   平均低估 +0.065
  访问式更高的 399/700   更低的 0/700     <- 方向完全一致
```

> **本项目此前每一个 Kinfold 数字都是标记式,也就是每一个都低估了。**

**所以必须重判,而且重判可能把结论推翻。** 低估若两臂对称则不影响缺口,若偏向接受臂则会缩小它 —— **这只能测,不能论证。**

```
                  旧口径(标记)              新口径(访问)
同 target 内配对   +15.4%  p=9.1e-07  n=54    +17.5%  p=3.4e-08  n=54
GC 逐条钉死        +12.5%  p=0.011    n=21    +14.6%  p=0.021    n=21
Spearman           -0.472                     -0.509
```

**两个控制同号、都更强。结论不变,而且更干净。**(这里 n 较小是因为重判只取了 700 条 / 133 个靶标的子集;§4.1b 的 79 个层来自全部 1596 条。)

#### 4.6b 穿越失败的那一半:长序列上不是判决太严,是根本没走近过

邻域判决在 ≥100 nt 的 17 个天然构建体上,**d 从 0 放宽到 12,一格都没救回来**:

```
d= 0..12   严格介于 0 与 1 之间的构建体   1/17   (门槛 5)   全部不可用
这些长序列实际走到的最近距离:中位 100 个碱基对(最小 40,最大 155)
```

> **d 取到 12 也够不着。** 这不是"我们的判决太严",是 **Kinfold 模拟这些天然核糖开关的共转录折叠,最后停在离实验导出结构约 100 个碱基对的地方。**
> 要么 Kinfold 在这个尺寸上不对,要么 SHAPE 导出的参照不对,要么都不对。**无论哪种,第二把尺子的外部验证越不过约 70 nt 这件事没有改变** —— 换裁判的口径救不了它。

> **一个我自己的判定 bug 一并记录**:第一版的"可用邻域"条件只要求"不全为 0",于是 17 个里有 1 个非零就给出标准差 0.059,**报出"动态范围恢复"** —— 一个假阳性。改成"严格介于 0 与 1 之间的构建体数 ≥ n/3"之后,没有一个 d 可用。

**记账**:穿越点在**裁判口径**上成立(低估被发现并修正,结论更强),在**长序列作用域**上不成立。**④ 不加分** —— 它修正了一个此前所有 Kinfold 数字都带的偏差,但没有扩大任何能力。

### 4.7 穿越点的另一半:把【判据】也搬到分布上 —— 本期第一个真正的改进

§4.6 只换了裁判。判据本身仍然是**逐点、二值**的:`MFE(前缀)` 有没有**任何一个**目标之外的配对。**MFE 是系综里的一个结构,而"有没有"是对一个连续量下的 0/1 判决。**

系综版问的是**越界配对占多少概率质量**(每个前缀一次配分函数):

```
off_mass(k) = Σ_{(i,j) ∉ 目标} p_ij(seq[:k])
ens_mean / ens_max / ens_frac_θ
```

**为什么它可能有效,而前两次尝试没有**:一个 MFE 里带一个边缘越界配对(p=0.05)的前缀,和一个 p=0.9 的前缀,**今天算同一件事**。在一条真实设计上直接看到过:**k=20 时 MFE 报"无越界",而仍有 1.34 个配对当量的概率质量在越界。**

#### 三条预注册条件,少一条都不算改进

| # | 条件 | 结果 |
|---|---|---|
| 1 | 某个系综变体比 `trap_fraction` **更能预测**访问式 Kinfold 到达率(按靶标自助) | ✅ **通过** |
| 2 | 在天然构建体上触发率**显著低于** 91.7% | ❌ **不过** |
| 3 | **同分异构体零假设仍成立**(家族内碱基多重集构造上相同,组分代理不可能分开) | ✅ **通过,而且更强** |

```
[条件1]  628 条候选 / 133 个靶标
  trap_fraction   rho=-0.470     <- 今天的规则
  ens_max         rho=-0.617
  |rho(ens_max)| - |rho(trap)| = +0.147   95% [+0.081, +0.216]   单侧 p≈0

  对比:尺度那条(§4.4)只买到 +0.018。这次是它的【八倍】。

[条件3]  59 个异构体家族,家族内组分完全相同
  trap_fraction   +10.7%   更好 46/59   p=5.4e-07
  ens_mean        +20.2%   更好 52/59   p=1.2e-10      <- 接近翻倍

  -> 系综版不是靠放松买到范围的。在【组分被构造钉死】的那个零假设上,它比二值版强得多。
```

#### 不过的那条:声明的阈值网格差了一个数量级,而这本身是答案

```
天然构建体上,各定义的触发率(构建体平均)
  trap_fraction   0.917    <- 今天的规则
  ens_frac_2.0    0.911    <- 声明网格里最高的阈值
  ens_mean       18.266    <- 越界概率质量,不是比例
```

**我声明 θ ∈ {0.1 … 2.0} 时并不知道量纲**,而天然前缀的越界质量均值是 **18.3**。所以声明的网格整体偏低一个数量级。**这是预注册没写好,和 §4.5a 里 P2 漏写总体是同一类错误 —— 事后把 θ 调高再宣布条件 2 通过,就是选择性报告,不做。**

> **`ens_mean = 18.3` 我第一次报的时候没有分母,复核时补上了。** 单独一个"18.3 个配对当量"说不出大小 —— 必须对上**目标配对上的质量**:
> ```
> 8 个 BSUGLY 构建体   目标上质量 13.7–20.1   越界质量 18.1–24.3   越界占比 47.4%–64.0%,中位 55.8%
> 目标本身有 86–92 对
> ```
> **越界占了总配对概率质量的一半以上。** 这才是那句"越界结构实打实且大量"的依据;只报 18.3 是个没有分母的数字。

> **而它回答了 §4.4 悬着的那个问题。**
> 那里的假设是:**91.7% 是生物学,不是我们数错。**
> 现在有了独立证据:**天然核糖开关的转录中间体,平均携带约 18 个碱基对当量的越界概率质量。** 那不是"MFE 里恰好多了一个边缘配对"被二值化放大 —— **越界结构是实打实的、大量的。**
> **所以判据在天然 RNA 上触发 91.7% 是对的,不是缺陷。**

**记账**:这是本期**第一个真正改进判据**的结果(前两次借来的方法一次反向否证、一次幅度不足)。**但它改进的是仪器,不是范围**,所以 **④ 仍是 13/18**。

**要不要换成出厂规则,是另一件事,不在本期做**:换判据要重跑 §3.2 的缺口基准、重新声明阈值、并让移位诱饵与嵌套诱饵那两个零假设原样再过一遍。**在那之前 `ens_max` 只是一个更好的度量,不是一条新的出厂判据。**

### 4.8 本期最重要的一条,而它不是任何一个实验的结果

把今天抓出来的东西列齐 —— **它们全都不是假设错了,是【测量】错了:**

```
ct2dot 三行拼接              -> 伪造出"每一条工具都没跑起来"
没有参照质量门槛              -> p=0.049 变 p=0.109(5 个参照连自己被拟合的数据都解释不了,最低 0.507)
用被测模型自己挑对齐          -> 让被告挑陪审团
RNAduplex/IntaRNA 平行双链    -> 物理上不可能;与正确答案零重合   <- 会把 P2 翻成"通过"
bifold 多结构 ct 读成一整块    -> 每对返回空集;空集对所有人 kappa 恰好 0.000  <- 会把 P2 翻成"通过"
Kinfold 标记低估 6.5 个点     -> 覆盖本项目【每一个】Kinfold 数字
"可用邻域"只要求不全为 0       -> 1/17 非零就打印"动态范围恢复"      <- 会翻掉一个判决
θ 网格差一个数量级            -> 预注册条件因与假设无关的理由失败
记分表比自己的表少一行         -> 连续两期
hash() 播种                  -> 最锋利的零假设不可复现
```

> **十个仪器缺陷,一天。其中三个会直接产出我们本会发布的假阳性。**
> **假设层面的失败率,远低于仪器层面的失败率 —— 所以 ④ 的约束不是想法不够,是测量的可信度。**
> 推论:**后面每一个新方向都会带同样的缺陷率。** 按今天的比例,再跑六个方向而不改流程,大约会再产出两个假结论。

#### 落到代码:`rna_harness/instrument.py` + 12 个回归测试

**每一个检查都能追溯到今天真实发生过的一个缺陷。追溯不到的不写进去** —— 追溯不到的检查是对未来的猜测,追溯得到的才是"它不会再悄悄回来"的保证。

| 缺陷类 | 检查 |
|---|---|
| 解析出**物理上不可能**的东西 | `check_pair_set`(必须是匹配、在界内)· `check_duplex_antiparallel` |
| 工具返回**退化值**被当成发现 | `run_controls`(**每次运行**都跑正负对照,不是开发时验一次) |
| 分不清哪一边是常数 | `constancy`(判据无变化 vs 裁判无变化是**相反的结论**) |
| "不全为 0"当成有动态范围 | `has_dynamic_range`(要求 ≥n/3 严格介于两端之间) |
| 统计做在**错误的重复层级** | `Clustered`(数据自带聚类单位,`honest_n()` 报簇数不报观测数) |
| **不知道量纲就声明阈值** | `scale_then_threshold`(网格不跨过实测尺度就拒绝) |
| 参照被拟合在**它要评分的数据**上 | `Reference.assert_independent_of`(循环打分直接报错) |
| 二值门槛压在**噪声里** | `gate_margin`(见下) |
| 播种不可复现 | `stable_seed`(crc32,并**钉住数值**,退回 hash() 会测试失败) |
| 分数与自己的表不符 | `tally`(从表里数,不由作者数) |

#### 接进真实 runner 之后,判决一字未变 —— 这才是它成立的证明

第三领域入场检查接入仪器层后重跑 120 对:

```
kappa 0.955 / 0.944 / 0.819 / 0.810 / 0.804 / 0.804    严格判据 55/120 = 45.8%
与接入前【完全一致】。仪器层不改变结果,它只让那几类缺陷【不可能发生】。
```

#### 而这次重跑本身又抓出第十一个缺陷

**同一个入场检查,n=60 和 n=120 给出相反的 P2 判决:**

```
n=60    IntaRNA~bifold  kappa = 0.799   -> 6 对里只有 5 对 ≥0.80 -> P2【通过】
n=120   同一个量        kappa = 0.804   -> 6 对全部 ≥0.80        -> P2【不过】
```

**领域没有变,变的是样本量。** 总判决没受影响只是因为 P3 两边都不过 —— **那是运气,不是设计。**

> **一个压在连续统计量上的二值杀死门槛,如果余量小于抽样误差,它就不是判决。**
> 已加入 `gate_margin`:自助出区间,跨过阈值就报成**"骑在刀刃上"**,而不是报成一个决定。

**记账**:④ 不加分。**它加的是【后面所有方向的可信度】** —— 而这一天证明了,我们最容易犯的错不是想错,是量错,而量错会让想对的那些也不算数。

### 4.9 方向 B 第一阶段:两个候选裁判 P1 直接不过,第三个能用但要带一道新检查

70 nt 上限要靠**换裁判**突破(加预算已证无效)。方向文档点名 `kinwalker`,后备 BarMap。逐个验:

| 候选 | P1「能不能跑」 | 证据 |
|---|---|---|
| `kinwalker` | ❌ **构建是坏的** | 任何输入只读 2 个碱基(输出 `.. 0`);裸序列 core dump;`--transcribed 30` → `free(): invalid pointer` + core dump |
| `treekin` | ❌ **依赖无法满足** | 全部构建都要 `libgfortran.so.3`,系统只有 `.so.5`;软链过去**响亮报错**(`GFORTRAN_1.0 not found`)—— **没有静默算错,这是好事** |
| `barriers` + 自解主方程 | ✅ **可用** | 它吐出宏观态速率矩阵;主方程我自己用 `expm` 解,数值我自己控 |

> **第三条路比原计划更好**:不依赖一个坏掉的二进制,而且它天然就是**"分布而不是点"的裁判** —— 返回的是**目标宏观态的布居**,不是"有没有命中那一个微观态"。方法论上与 Kinfold 也真正不同(确定性主方程 vs 随机模拟)。

#### 但在能用之前,数值对照抓出三件事

```
[1] 方向        rates.out 是 [来源][目标];我读反了
                细致平衡判定:正向对数偏差中位 0.019,反向 8.792 —— 不是判断题
[2] 对角线      barriers 在对角写了自速率,不清零就指数化会得到"看着合理但错的"布居
[3] 不连通      --max 12 下矩阵分成【两个分量】,开链在一个、基态在另一个
                长时极限是【起点所在分量内】的 Boltzmann,不是全局的
```

**我第一次的对照拿全局 Boltzmann 去比,报出"求解器不能用"——那是对照写错了。** 按分量限制后重比:

```
长时布居   [0.8388, 0.1164, 0.0170, 0.0190, 0.0064, 0.0024]
分量内 Boltzmann [0.8396, 0.1198, 0.0171, 0.0145, 0.0065, 0.0024]
最大偏差 0.0045   -> 求解器正确
```

> **不连通这一条对判据是致命的**:如果目标宏观态落在另一个分量,布居**恒为 0** —— 那是截断造成的,不是动力学。**不检查连通性就用它,会把"我们截断得太狠"报成"这条序列折不到目标"。**

#### 两条新检查进 `instrument.py`

`check_generator` —— 一个速率矩阵要当主方程生成元,必须**方向正确(细致平衡实测判定)+ 不可约**;可约时返回起点所在分量并写明"分量外为零是构造造成的,不是动力学"。

> **第十三个缺陷,在检查器自己身上:** `orientation_ok` 我写成 `bool(db == db or db <= db_flipped)`,而 `db == db` 对任何非 NaN 恒为真,**整个方向检查从来没有生效过**。它自己的测试第一次跑就抓到了 —— **这正是"检查必须有回归测试"的意义。**

#### 4.9b 第二阶段:我先报了"P1 不过",复核之后**那个判决是错的**

第二阶段第一次跑,正对照给出布居 0.000、13 个宏观态里 **9 个分量**,我据此写了"这个裁判不参与判决"。**复核推翻了它,而且推翻的方式是同一类缺陷的重犯。**

**① 归因错了 —— 不是 `--max` 截断,是能量窗口太窄。** 6 条设计上扫参数:

```
--minh 2  --max 50     4/6 根本不产出 rates.out
--minh 1  无 max        6/6 产出,但 2–7 个分量 / 3–7 个态(7 态 7 分量 = 一条连接都没有)
```

再扫能量窗口(两条设计,`--minh 1`):

```
-e  8    4 态 / 3 分量     <- 我声明的值
-e 12   10 态 / 7 分量
-e 16   12 态 / 1 分量     <- 不可约,而且 0.3 秒
-e 20   22 态 / 9 分量     <- 更宽【不是】更好,非单调
```

> **我声明 `SUBOPT_E = 8.0` 时没有量过"连通需要多宽的窗口"。这与 θ 网格差一个数量级是同一类缺陷 —— 而 `instrument.scale_then_threshold` 正是为它写的,我自己没用。**
> 现已改成**逐序列搜索窗口**,直到 `check_generator` 报不可约;每个窗口都不可约就返回"不可打分",不返回布居。

**② 负对照两次都是"因为无关的理由通过"。**

```
第一次  poly-A:RNAsubopt 只出 1 个结构,barriers 找到 0 个鞍点,不写 rates.out -> 返回 None
        而我的谓词把 None 当通过 —— 一个彻底装坏的 barriers 会同样"通过"
        None 是"流水线没跑起来",不是关于折叠的证据。这正是本项目一直在别人结果里抓的那个混淆
第二次  换"外来序列+外来靶标":得分 0.88,因为我挑的靶标恰好就是那条序列自己的 MFE
```

**改成"同一条序列的次高能宏观态"** —— 直接测这个裁判会不会对什么都说是:

```
正对照  布居 0.9558   不可约 True   e=16
负对照  靶标能量 -7.50(基态 -14.00)   布居 0.0000
P1 通过
```

> **所以方向 B 第二阶段的正确结论是:P1【通过】,而我第一次报的"不过"是参数没量 + 对照没设计好造成的。**
> 下一步仍是长度可行性曲线(`-e 16` 下 28 nt 用 0.3 秒、1287 条次优;284 nt 上枚举几乎肯定爆炸)——**它区分 70 nt 上限是"物理"还是"枚举"。**

## 8. 不主张什么(本期新增三条)

沿用 2026-07-30 §9 全部条目,新增:

- **不主张共转录判据有绝对灵敏度。** 它没有可用的正样本集(§4.1d),证明的是**相对效度** —— 和一个机制上无关的模拟器看到同一件事。它**不够格**支撑一张像假结那样的出厂证书。
- **不主张 Kinfold 的到达率等同于真实转录动力学。** 它是固定生长速率、固定模拟预算下的随机模拟,不含聚合酶暂停、不含体内因子;结论只对 25–70 nt 成立。
- **不主张共转录这一侧的裁判彼此独立。** 假结那边逐对 kappa 已实测(并因此把"三个独立预测器"改口为两个有效独立源);**这边的 Kinfold / findpath / 前缀 MFE 从没量过一致性**,所以"外部裁判"这个说法目前只靠机制不同,没有数字。
- **不主张文献关键词计数等于用户需求。** §3.2 那张表说的是"这个词在 1676 篇设计文献里被提及多少次",不是"多少用户要这个"。
- **不主张五个目标的分数彼此独立。** `primitive_choice` 同时记在 ①(可达性)与 ④(要求能被真的要到);`external_requirements` 同时记在 ③ 与 ④。**同一份证据在两张记分表上各记一次** —— 五个目标是关于同一个系统的五个问题,不是五个互斥的实验集合,合计不可相加。
- **不主张同分异构体这条结论覆盖全部靶标。** 178 条里 46 条连折对的母序列都没有、64 条判据一条都不放行,**结论只对同时存在低陷阱与高陷阱异构体的 59 个家族成立**,而那批更短、GC 更低。
