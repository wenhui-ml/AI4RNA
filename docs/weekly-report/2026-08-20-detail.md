| **`mean3` 的判官集是否两臂一致**(Knotty 91 条里失败 27 条) | **两臂不一致的靶标 0/51** —— Knotty 按靶标成对失败(同靶标两臂同长)。我怀疑的"3 判官均值减 2 判官均值"**不存在**;改动仍保留,因为下一批数据不保证这么干净 |

| 两个来源文件的选择是否一致(`_f1.json` vs `_all.json`) | 51 靶标 **0 处不同** ✓ 源文件选对了 |
| **`_all` 的臂均值差 +0.0283 与我的配对均值 +0.0322 不等** | **真缺陷,新发现** —— 见下 |

> **`mean3` 不是一个可复现量。** 两个文件的选择逐条相同、靶标数相同,那么"臂均值之差"与"配对差之均值"**必须相等**。它们差 0.0039。原因:**Knotty 由墙钟界定,同一批序列两次运行的可用性不同** —— `_all` 那次两臂都成功的靶标 37 个,我这次 36 个,一个靶标翻了面。于是 `mean3`(对可用判官取平均)在两次运行里就是**两个不同的量**。
>
> 这是 §四"求解器从来就不可复现"的同一条教训,**打在判官身上**,而此前没人查过。**杀伤范围是那张表里每一个 `mean3` 数字**,包括它自己的主比较 `rnet_gated − screen_first` p=0.0044。它对上面第 11 格的结论方向没有影响(只会让一个已经过不了 Bonferroni 的 p 更不可靠),但**必须记进限制**,而且下次 `mean3` 要定义在**固定的判官集**上(或要求 Knotty 在一个靶标的所有臂上都成功,并报 n)。已列入 §八。


## 三之四、④ 的第三个造判据领域:**验证器仲裁**(8-18/8-19 新增,过了预注册确认)

**这一节是 TL;DR 里那个悬空引用应该指向的地方。** ④ 记的不是"实例更难",而是**判据缺失**的领域数。前两个领域是假结面板和共转录 Kinfold 判官。第三个一直被两头堵死:凡有大规模物理测量的地方,已经有人训过预测器,判据就不算缺失。

**8-18 掉出来的缺口不是一个新的生物领域,而是【判官之间的仲裁】,而且三个条件同时满足:**

| 条件 | 事实 |
|---|---|
| 判据缺失 | 两家判官在**同一批 51 靶标、同一次运行**上把选择规则排名整个倒过来:RNet 说 `screen_first` 最好(0.826 → 0.955),IPknot/Knotty/RNAPKplex 说它是十三臂里最差、还差于出厂(−0.037,p=0.026)。**"该信哪一家"没有公认判据** —— 姊妹论文立住"solved 是验证器的选择"就停了 |

### 三之四之二、A9:绝对灵敏度测了两次没拿到,但查出一条适用范围限制

A8 之后又跑了 A9,**跑之前把它的混杂也声明了**:难零假设人群是每格 1 条野生型 + 7 条**嵌套诱饵**(对去掉假结的骨架做 `inverse_fold`,再拿完整靶标判;严格档历史上对 183 条这类诱饵接受 0 条)。249/250 格成格,1976 条序列,只有 1 个靶标整格丢弃 —— 难例基本没缺。

```

  底档 n= 24 单位16   跟学习型 6.2% [0.0, 18.8]  ✓ 下越 0.5
  中档 n=142 单位78   跟学习型 3.8% [0.0,  9.0]  ✓ 下越 0.5

### 三之四之三、A10:判据改不动一个决定,而且原因是可测的

判据成立(观测列)之后还剩最硬的一问:**它能不能改变一个决定,而且由物理测量说改好了?** 这是 ④ 真正记的东西 —— 判据 + 大规模物理测量。

**跑之前的审查砍掉了三个备选方案,这一点必须记下来:**

| 原打算做的 | 为什么不能做 |
|---|---|
| 在**自有池**上加一个 `arbitrated` 臂 | **没有有效判官**:判据是对着试管标定的,自有设计没有试管分;RNet 在选择回路里(循环);三个热力学判官正是判据要推翻的那一家 |
| 把判据当**选择器**(ranking) | 判据是**逐对**、单侧的,**不诱导全序**(逐对规则可以不传递),"当 ranking 用"没有定义 |
| 第四个领域「下一个跑哪个神谕」 | **撞兄弟论文**:verifier-economics 拥有 sound cascade,oracle-residue 拥有 "verifier economy",collision map 明文禁止重新 originate |
| `panel_f1` vs `shipped` | **推进不了 ④** —— 那一行要赢的是**现成模型**,不是自己的出厂规则。归类为 ③⑤ |

**实际做的:第三批互斥样本 + 两候选对决。** 剩余 19,977 条里取 80/靶标 = 4,526 条,与探索样本(80/靶标)和确认样本(160/靶标)**同时**互斥(`replay_third` 断言交集为 0;`replay_fresh` 只排除一批,所以必须新写)。每格一个对决:**面板头名 vs 学习型头名** —— 单一配对,判据直接适用,不需要全序,而且这正是产品的真实决定形态。判官是**实测试管分**,从未进任何回路,切点从未在这批上拟合。

```
可用格 228,两头名相同的格 34,判据【真正改变了决定】的格 54(声明门槛 30,先于任何区间打印)✓
arbitrated − panel_only  【主检验】 +0.159 分  聚类 CI [−0.302, +0.614]  跨过 0   ✗
arbitrated − learned_only 【次1】   +0.389 分  聚类 CI [−0.202, +0.988]  跨过 0   ✗
【次2】许可组 50.0% [37.0, 63.0]   不许可组 48.6% [40.0, 56.4]   两个都跨 0.5
```

**许可组 50.0% —— 正好抛硬币。** 按声明,④ 的「判据能改变一个决定」记 ❌(测过、未拿到)。

### 为什么失败,是量出来的,不是讲出来的

A10 决定的不是随机一个相悖配对,而是**一个非常特殊的配对**:两个候选各自处在自己尺子的**顶端**。而这个项目已经五次测到**有界验证器在自己的天花板上没有梯度**(面板的秩相关随自身分数上升而衰减 +0.279 / +0.158 / +0.040;36.1% 的设计坐在 RNet 交叉配对 F1 = 1.000 上)。

把相悖配对按**它在两把尺子里坐得多高**分层,同一个冻结切点:

```
                    出厂列              观测列
低位对            59.8% ✓            59.6% ✓
中位对            55.9% 跨           64.8% ✓
高位对            53.3% 跨           53.7% 跨
A10 的头名对决    56.5% 跨           53.1% 跨
```

**两列同一形状:判据在尺子还有梯度的地方成立,在顶端消失 —— 而产品的每一个决定都在顶端做。**

> **这是本周最有信息量的一句话,而它是个坏消息:仲裁信号是真的,但它坐在【不做决定】的地方。**

这也把选择问题重新框了一次:开着的不是"该信哪把尺子",而是**两把尺子在顶端都是瞎的**。这是验证器饱和在本项目的第六次出现,也是最锋利的一次。

## 三之五、这两天撤回的不是数据,是**估计量的权重**

同一个错误类别在本项目里出现了**四次**,8-19 一天占两次:

| 出现 | 错误的权重 | 修正前 → 后 |
|---|---|---|
| 方法构成混淆(8-17 前) | 各方法的样本量 | +4.75 → +1.90 分 |
| `filter_stack` 汇总(8-18) | 跨格汇总 | 7.6 → 2.9 分 |
| 仲裁 A1(8-19) | 配对数(格大小) | 57.6% → 53.8% |
| 单侧判据 A5b(8-19) | 1/σ_cell(格内方差) | 75.1% → 64% |

**通用形式:证据单位是嵌套的时候,任何不显式固定权重的估计量,量到的是嵌套的几何而不是证据。**

**"按格聚类"只修了「依赖」,没修「加权」——这是两次不同的修正,我此前只做了第一次。**

**已经查过的账(这条教训的适用范围):**

```
+1.90(唯一的湿实验背书)  格内中位差 → 格中位,Wilcoxon 按格   → 不受影响,本来就是每格一票
ruler_gradient G5          格内差 → 跨格 Wilcoxon              → 不受影响
仲裁 A1                    配对加权                            → 中招,已撤回
仲裁 A5b                   1/σ_cell 加权                       → 中招,已改正
```

**旗舰的 +1.90 干净。** 中招的只有仲裁那两处,而且两处都在同一天被同一次审计抓到。

**审计的一个时序细节值得记:** `arbitration_audit.py` 的第一件事是 **C0 复现已发表的 A1**(57.6% / 7,858 配对 / 184 格,一致),复现不上就不许读下面任何一行。这一条把"我改了估计量所以数变了"和"我改了数据所以数变了"分开。

## 三之六、A11:尺子的顶端读不出东西,而所有决定都在顶端做

A10 之后剩下最后一问,而它是下游一切的前提:**顶端还有没有【任何】可读的信号?** 如果没有,那么 §三之三 那条"改选择就能从 0.826 升到 0.955"的线有一个**与选哪把尺子无关**的天花板。

**量在跑之前就被指定,不是事后从四个里挑的。** `certify.py` 出厂的打平器已经在按**集合熵**挑同档候选,并且抬高了外部一致率(IPknot 21.8% → 27.0%,29 胜 16 负,符号 p=0.036);而**纯按熵挑是 34-34(零)**、按 GC 挑显著更差(14-32)。**熵只在平局上有用、全程无用 —— 而平局就是饱和的顶端。** 这是先验,所以主检验的量和**方向**(预测正相关)都在跑前钉死。它从未对着物理测量测过 —— 当年是 IPknot/Knotty/RNAPKplex 在我们自己的设计上判的。

人群:每个 (靶标 × 方法) 格里 **RNet f1c 的顶端并列块**(块内 ≥4 条、试管值 ≥3 种)。**该块覆盖 42.7%(样本2)/ 45.7%(样本3)的设计** —— 尺子分不开将近一半它要挑的东西,这不是角落情形。判官是实测试管分,而熵来自 ViennaRNA,**没有共享误差路径**,是这条链上最干净的一组预测量/结局关系。

## 三之九、A13→A16:换方向去问「梯度在哪一层」,四个实验,一条复现、三条关闭、三处声明缺陷(8-19 夜 / 8-20)

顶端找信号试了三次(A11 熵、A12 打平器、第 11 格)全为零,所以停止在那里找,改问**梯度在哪一层**。
分解是三项**严格相加**、用**均值不用 max**(max 会被集合大小凭空抬高,本项目自测约 +3.67;均值不会),
所以不需要任何选择偏差校正、也不需要 oracle:

```
A = mean(质量|confirmed) − mean(质量|整池)      「有没有被确认」买到什么(k>=1)
B = mean(质量|顶端块)   − mean(质量|confirmed)  「等级取最高」买到什么(k=max)
C = 质量(交付那条)      − mean(质量|顶端块)     打平器买到什么
A + B + C ≡ 交付 − 池均值      逐单位恒等,代码断言,违例 0
```

A 是**阳性对照**,C 是**A12 的复现**,只有 B 是新问题,**方向故意不声明**。

## 三之十、借一位数学家的方法去挖极限:一根真列,和三个被否掉的预测(8-20)

用户提出参考邓煜(2026 菲尔兹奖)的方法。**先把界线划清:他的定理不能借。** DHM 从牛顿粒子动力学推出玻尔兹曼
方程,靠的是【只追踪单粒子分布、把关联丢掉】,而技术障碍是重碰撞带来的关联;那是一个**截断**结果——环可
忽略,所以树方程成立。照搬到 RNA 就是断言**假结不形成**,这是假的,而且恰恰是嵌套模型在我们靶标上系统性
失败的原因。他们的小因子是**几何的、渐近趋零的**;RNA 的交叉罚项是**能量的、O(1) 的**。**我们这里没有小
参数,树截断不是渐近有效的。**

能借的只有论证的**架构**:①指认粗粒化 ②指认它丢掉哪种关联 ③找阈值 ④在阈值下工作或去追踪被丢掉的对象。

而有一个对应是**精确的、不是类比**:固定结构 S 时 Turner 模型下的能量是序列 one-hot 的二次形式,
配分函数是对指数多个"图"求和;**嵌套结构就是树状图**(所以 O(L³) DP 可精确求和),**交叉配对就是环**
(所以一般情形 NP-hard、我们三个神谕全是启发式)。ViennaRNA 的配分函数就是结构上的玻尔兹曼分布——同一个
对象。

8-18 测出"面板 vs RNet 在匹配覆盖率下打平(+0.0000,p=0.40)",我当时读成"两把尺子一样好"。**现在看清了:
那测的是【在顶端做选择】,这测的是【整体知道多少】。两者都对,而它们的差就是这一周所有结果的共同解释:**

> **RNet 确实知道得多(0.164 对 0.103),但它多知道的那部分坐在我们【不做决定】的那段量程里。**

这正是 A13/A14/A15 量到的"信息在 k>=1 边界上、顶端饱和",也正是 A10 量到的"信号在低位 59.6–59.8%、
在顶端掉到 53.3–53.7%"。**所以真正的缺口不是"该信哪把尺子",是"我们在错误的位置榨取信息"** ——
决定放在顶端,而两把尺子在顶端都平;RNet 的优势在中低段,而我们在那里只用它做资格判定、不用它做排序。

### 这改变了下一步的排序

- **降级:** R2 那根列的留出确认(原 §九 第 10 项)—— 它被 RNet 吞掉了。
- **升为第一:** **把 RNet 接在【中低段】而不是顶端。** 最锐的一个切口是:**面板没有任何 confirmed 候选
  的那些靶标** —— 51 个里有 15 个是这样,加上 9 个被拓扑闸门挡掉的 H-type。**在那里面板的 k 恒为 0,
  它提供的梯度是【零】**,而产品当前的兜底是"取通过宽筛的第一条"(求解器顺序),那 5 个交付 0.000 的靶标
  就在这一档里。**RNet 整体知道得更多,而这一档是它唯一不与面板争顶端的地方。**
- **注意这一档的判官是【偏向面板的】:** IPknot/Knotty/RNAPKplex 与面板共用能量模型族、与 RNet 不共用。
  所以若 RNet 在这些判官下仍然胜出,**那是一个保守检验下的胜出**,可信度更高。

### D1:那位数学家的公式死了,但他的旋钮活了 —— 判读见 §零「8-20 夜」

**而那个"几何小量"在 pKiss 里是一个命令行参数** —— `--Hpenalty`(默认 9)、`--Kpenalty`(默认 12),

⇒ **位置对不上不算反证、对上了也不算证据**);**安慰剂内建**(两个旋钮分开,拧 H 必须只动 H-type);

**判定:作废(设计混杂)。** 详见 §零「8-20 夜」与 `d1_audit.md`。这里只记一句最有用的:

### D4S:第四个领域拿到了环外校准物,而我给它写的 caveat 写反了

**为什么这是第四个领域的第一步。** ④ 真正记的是**造判据的领域范围**,而 §三之七 A 节只有 3 行,
每一行都是靠一个**从未入环的外部裁判**挣到的:领域一是试管、领域二是 Kinfold、领域三是留出的逐对
判断。**所以第四个领域动手之前必须先有校准物**,否则它就是第 5 个"引不到出处"的行,而现有的 4 个
已经在分母里压着分数。

**IntaRNA 当不了这个校准物。** 它在 `inta` 环境里(3.4.1),是不同算法族(可及性 + 种子延伸),但它
自报 `using Vienna RNA package 2.7.0` —— **与 RNAcofold 共用同一套 Turner 参数。算法独立,能量模型
不独立。** 这正是本周一直在追的共用误差路径:pKiss / IPknot / RNAPKplex 全是热力学家族,所以领域一
非要试管不可。

**剩下唯一候选是 RibonanzaNet 打在加 linker 的串联构造上**(学习型,没有能量模型),而这个技巧
**从未验证过**。所以这一夜验的是**校准物**,不是开关。按 §八 第 29 条,真侧是 RNAcofold 判 `held`
的 58 行,并**断言真链间对非空**。

```
真侧链间召回      均值 0.8264   中位 1.0000
假侧(trigger 打乱)  均值 0.0000   中位 0.0000
配对差 真−假       +0.8264  CI [+0.7371, +0.9061]   正/负 55/0
```

**判定 `calibrator_exists`。**

**而我第一时间给它写的 caveat 写反了,方向对结论有利。** 我写"负对照太容易 —— 打乱等于换掉整条
trigger,所以 0.0000 不奇怪"。查 15 个案例:

```

**假侧不是"不配对了",是"配错了位置"。** 这个观察量区分的是**配准(register)**,不只是"到底有没有
配对" —— **负对照比我以为的更有信息,不是更平凡。**

负对照**(另一条真实 trigger,或单点错配),而不是直接去造判据。

## 三之十三、借来的方法:结账 —— 三个定量预测全灭,而它仍然付清了成本(8-20 汇总)

§三之十 / §三之十一 / §三之十二 是这条线的三段过程,这一节把账算完。**结论对我自己不利,所以先说结论:**

> **借到的东西没有一样是他的【结论】,全部是他的【动作】。而我自己在第一天就写下的那条界线,
> 当天下午被我自己违反了一次。**

### 一、界线是第一天就写清的,而我违反了它

§三之十 开头(8-20 上午)原话:

> "他们的小因子是**几何的、渐近趋零的**;RNA 的交叉罚项是**能量的、O(1) 的**。
> **我们这里没有小参数,树截断不是渐近有效的。**"

**然后当天下午我推了 `ln L* = ΔG_pk/(3RT)`** —— 这条式子的成立【要求】把 ΔG_pk 当成一个和熵增
`3 ln L` 赛跑的小参数。**它和我上午写的那句话直接冲突,而我在写它的时候没有回头看那句话。**

这是本周所有错误里最应该避免的一个:**界线不是没画,是画完没有被执行。** 与 §零 那条
"`audit_week.py` 早就写了要求、报告三周没执行"同一性质。

### 二、三个定量预测,全部被否

| 预测 | 结局 | 怎么死的 |
|---|---|---|
| "L 里存在一个不可逆阈值" | **否** | 我自己做 REM 计数:竞争者地板与目标能量**两边都是 L 的广延量**,胜负由系数决定,L 里没有阈值 |
| "每核苷酸间隙是真正的驱动量,`coef_g` 应随 L 稳定" | **否** | 数据:`coef_g` 单调下降(样本2 −69.7→−64.6→−30.6;样本3 −88.2→−60.8→−28.6) |
| `ln L* = ΔG_pk/(3RT)`,斜率 0.5408 | **作废 + 反向** | 检验被我自己的扫描设计混杂(`P_drop` 恒等于被固定的 K 值);而顺带得到的独立信息是 `Spearman(P_drop, ln L) = −0.302`,**符号与推导相反** |

**0/3。** 这条线**没有产出任何一条成立的定量定律。**

### 三、为什么定量层失败 —— 这一节是这条线真正的知识产出

不是"类比不严谨"这种空话,失败点可以指到具体位置:

| | DHM(玻尔兹曼) | 我们(RNA) |
|---|---|---|
| 小量 | 几何的 ε^(d−1),**渐近趋零** | 假结罚项,**能量的、O(1)、而且是拟合出来的**(pKiss 的 `--help` 自己说"从未在湿实验里测过") |
| 多重性增长 | **阶乘** | **多项式** L^(3g−3/2)(Vernizzi–Orland–Zee / Bon) |
| 竞争的结果 | 一个**渐近趋零的小量**对一个**发散的计数** ⇒ **存在锐利的交叉点** | 一个 **O(1) 的拟合常数**对一个**多项式** ⇒ **没有锐利交叉点** |
| 实测到的实际机制 | — | **两个拟合参数【谁更小】决定的离散类别切换**(H 罚项追上 K 罚项 ⇒ pKiss 把 H-type 换成 K-type,`P_drop` 51% 落在被固定的那个 K 值及其上一格) |

**所以界线可以写成一句可复用的话:**

> **这个类比在【结构层】成立(嵌套=树图 / 交叉=环图,这是精确对应),在【技术层】成立
> (问"和稳不稳",而不是逐项算),在【定量定律层】不成立 —— 因为我们没有一个渐近趋零的小参数。**

### 四、收益(具体的,可归因的)

**1. 它让我去拧了一个没人拧过的旋钮。这是最大的一笔,而且它不在任何公式里。**

- **查出 pKiss 在 H 罚项追上 K 罚项时【换假结类别】,而我们出厂的配置 H9/K12 离那条边界只有 3 kcal/mol。**
  这是一件关于**我们每天在用的那个判官**的事实,此前没人查过。
- **D3 由此测到一个方向与我预期相反的正面证据**:出厂点 ±1 kcal 邻域里,**35.8%** 的分子交叉集会变,
  但只有 **6.6%** 改变对出厂档位 k 的贡献,真交叉召回极差中位 **0.000**。
  **不稳定在判官的【输出】里,不在它的【判决】里 —— "满召回"处那次阈值化把参数不确定性大部分吸收了。**
  我出发时要证明出厂点很脆、需要弃权规则;回来的是"k 对我正在传播的那个不确定性是稳的"。
- 顺带(**事后,需单独预注册**):`--Kpenalty` 的默认 12 已接近好端;`--Hpenalty` 的默认 9

**2. 一个可迁移的提问形式。** 他的证明不逐项评估那些个别不可控的环图项,**他问的是这个和稳不稳**。

**3. R2 那根 gap 列**(同一条线的能量间隙框架)是这条线唯一的**实物列**:在 F2 之上 +0.024~0.043。
**但它在 F2∪f1c 之上只剩 +0.0012 —— 基本被 RibonanzaNet 吞掉。**

## 四、求解器从来就不可复现,已修

追查经过三个假设,**前两个是我的,都错**:

1. ~~seed 是装饰品~~ —— 错。但查出 **`-seed 0` 是 DesiRNA 的「请随机」哨兵值,而 0 是我们全项目默认值**:每个 benchmark、每次阶梯、每个"三个 seed 的对比",都在请求随机化
2. ~~墙钟主循环~~ —— 也错。设了步数上限后仍 Jaccard 0.003
3. **`PYTHONHASHSEED`** —— DesiRNA 遍历字符串键的 dict/set,Python 默认每进程随机化哈希,迭代顺序变 → 尝试的突变变

```
PYTHONHASHSEED=0 + 墙钟 -t 20,无步数上限   三次完全相同,Jaccard 1.000
步数上限 -s 40,哈希种子放任              Jaccard 0.000
```

**修复是一个环境变量,产品的秒预算完全不动。** 同一个问题问两次现在能拿到同一份证书 —— 直接补 ⑤。

**不夸大:** 墙钟下步数仍随负载漂移,是**改善不是保证**(三靶标里答案两个复现、池无一完全复现);加上步数预算才彻底闭合(三靶标全部返回逐字节相同的 200 条池)。所以 `-s` 也接上了,只给需要受控对比的实验用。

**追溯影响:** 8-06 的 `agent_ladder_lottery` 曾发现长档的解"像彩票",归因为**不同 seed 之间**的差异 —— 实际上**同一 seed 重跑也会给出第四个答案**。结论(彩票)不受影响甚至更强,但"seed 是受控变量"这个前提一直不成立。

## 五之二、⑤ 的新一格:证书第一次说出**自己能被骗的频率**(8-19,已进产品)

`knot_screened` 是最弱的一档,自它上线以来只报**分离度** —— 清了这一档的设计在试管里比没清的高 +3.37 分。它从来没报过一件用户更该知道的事:**这一档有多容易被骗**。严格档从建成起就有这个数(84.0% / 0.4%),弱档没有。

knot_screened  90.4% [86.1, 93.8]           4.0% [1.9, 7.2]   ← 10/250
knot_confirmed 84.0% [78.9, 88.3]           0.4% [0.0, 2.2]   ← 1/250

**这一格记 ✅(用户可见、对着真值测的),那个 0.000 记 ❌(产品里确实存在、确实不成立)。** ⑤ 因此 9/12 → 10/14。

## 八、诚实的限制

1. **+1.90 主要在 Eterna/M2 两个臂内测到**(58 个格子),外推到我们自己的设计**没有直接证据** —— 我们的设计没有、也不可能有湿实验对照。
2. **新筛在它救回的 11 个靶标里,有 4 个根本分不开质量**(P01/P06/Q04 两边都是 0.000,P16 是 0.533 vs 0.536)。中位是被 W13/W03/P11/W04 撑起来的。
3. **生成缺口的量级是上界**:拿他们**已挑选提交**的设计比我们**未挑选的原始池**。
4. **墙钟下不保证复现**;严格复现需步数预算,而产品卖的是秒。
5. **L1 仍为负、仍不通过** —— 我们没有超过同行。变的是每道题都给答案,且答案是真的。
6. **交付的 0.826 仍远低于池中最好的 ~0.95** —— "面板决定『答不答』远比决定『答哪个』准",本周第四次独立出现,8-17 拿到了它最极端的实例:P14 的池中位 0.889,我们交 0.000。
7. **出厂阶梯是墙钟限时的,运行间本底噪声约 3.5%**(两次全量运行:36 个共同确认靶标里 1 个换了序列、1 个掉档)。所有小效应必须带这个底噪读。
8. **9 个 H-type 靶标被拓扑闸门挡在 `knot_confirmed` 之外**,交付走筛通道的第一条 —— 仅 P06/P11 两个靶标上就有 209 条已被面板完全确认的候选按设计被跳过。拒发标签是诚实的,把这 209 条的信息一起扔掉是浪费,尚未量化。
9. **选择器的收益全部由 RibonanzaNet 裁定,不是湿实验。** 唯一的湿实验背书(+1.90)关于**判据**,不关于**选择器** —— 换了选择器之后那条性质还成不成立,**没测**,这是下一步第一件事。
