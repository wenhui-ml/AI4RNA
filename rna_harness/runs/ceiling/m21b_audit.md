# M21b 审计:M21 的裁定选错了路线,而两条路线的分歧原来就在它自己的产物里

## 为什么要做 M21b

M21 的头条是「模型的最近邻局部自由能一点都没中介身份效应」,靠的是留存量
`retention = CDE / base_same_population`。m26r3 的标定证明:在本语料真实的效应
尺度上(中介物把两臂分开约 0.05 SD),这个估计量与真值的相关是 **−0.70**
(RibonanzaNet)/ **+0.70**(ViennaRNA),而 ViennaRNA 在真值 100% 中介时给出
**−842.5%**。同一个估计量已在 NM 论文 §8 撤稿。M21 用的是同一个,必须一起撤。

M21b 不重新实现任何东西:它调用 `M21.build_with_dg()`,把 M26 的 P_model 按
`(design, pt, round(rf,6))` 连上,只报**直接量** —— 配平后的对比与层内斜率。

## 对拍:矛盾不是 M21b 制造的,是 M21 已经量出来但没有采信的

`m21_thermo_mediator.json` 自己同时装着两个数:

```
B2.mediated_fraction              = 0.7311   ← 乘积路线
P3.mediated_fraction              = −0.0188  ← 条件路线(留存)
B2.b1_implied_mediated_fraction   = −0.0188  ← 它把两者并排写下来了
B2.monotone                       = false
staked.2_mediated_fraction_in_20_60 = false
```

**两条路线相差 75 个百分点。** M21 的 `verdict` 字段
(`identity_beyond_NN_local_energy__mediated_fraction_indistinguishable_from_zero`)
把裁定交给了条件路线,而**没有给出任何采信它的理由**。m26r3 之后我们知道那正是
不可信的一条。M21b 用独立的层内斜率把乘积路线重算了一遍,得 58.6%,与 M21 的
73.1% 同一量级同一符号 —— 分歧不在实现上,在**两条路线之间**。

## 因此可以说什么、不可以说什么

**不可以说**「局部自由能没有中介身份效应」。撤下。

**不可以说**「局部自由能中介了 58.6%(或 73.1%)」。逐箱条件均值非单调
(−0.0085 / +0.0214 / +0.0122 / −0.0019 / −0.0222),按 R4 乘积路线只能读作**上界**。

**可以说的两句,都是直接量:**

1. 两类配对之间的**局部自由能差 1.72 kcal/mol,区间又紧又远离 0**;而**同一个
   模型给出的成对概率只差 0.030,且区间含 0**。模型自己的流水线把一个大的局部
   能量差吸收成了一个分不出来的概率差。
2. 因此**能量项最多可以承担 58.6% 的身份效应,而集成概率项最多只能承担 6.8%** ——
   两个上界差了近一个数量级,这条比较不依赖任何中介估计量。
