## 三、三件正向的事

**1. 出厂判据第一次有了被测出来的产品价值。**
n=10 上捕获率 **16.6% [11.3%, 22.0%]**,排除 0,**三个复现人群全部复现**。
在此之前,这条线上关于出厂判据只有净 R² 与成对准确率 —— 两个**全序**度量,
而产品做的是 **top-1-of-n**。**十五个实验没有一个测过这件事。**

**2. 两根 GC 列几乎把捕获率翻倍**:16.6% → 27.1%,增量 **+10.45 点 [+6.2,+14.8]**。
四个 n 上全部排除 0,种子全部 50/50。

**3. `ensemble_defect` 在产品货币下也是正的**,+6.06 点 [+1.1,+10.9] (n=10) 与 +6.27 (n=20)。
`p_all`(M1c 那根新列,声明后补的臂,不进任何判据)给 +6.15 / +6.50 —— **与 ed 又一次不可分辨**,
和 M1c 的次要对比量一致。

## 四、这是"GC 就是我们全部家当"的**第四次**独立出现,而且这次最难看

**`GC_only` 只有两根列,在 n=2 / n=20 上的捕获率(24.6% / 21.0%)比整套 22 列出厂面板(14.9% / 7.9%)还高,
而且 `GC_only − A` 在四个 n 里三个排除 0。**

前三次分别是:C1 的分解(G 携带 +0.030 里的 74.6~83.5%)、γ*−GC 区间、天花板复核里两根 GC 列占 12.2%
而整套面板占 20.1%。**这一次是在产品货币上,并且是"两根列打赢二十二根列"。**

**必须写清的边界:本实验【没有】做 GC 相消。** M3 在 GC 精确配平的对上测到 ensemble_defect 仍有
+0.0140,那条独立成立。这里的 `A_ed − A` = +6.06 是**未相消**的口径,两者不可混引。

## 五、K3 这道闸门的形状写错了 —— 记录,不改裁定

冻结的 K3 是「捕获率随 n **单调不增** ⇒『top-1-of-n 会放大小优势』不成立」。
实测 **14.9% → 17.5% → 16.6% → 7.9%**:**先升后崩**,不是单调不增,所以 K3 不触发。

**但数据显然也不支持"放大"。** 那道闸门只能区分"单调不增"与"其余一切",
**区分不了"放大"与"先升后崩"**。裁定按冻结判据照写(K3 不触发),
**但不许把"K3 不触发"读成"放大成立"。** 实际形状是:

> **捕获率在 n≈5 见顶,到 n=20 掉到 7.9% —— 候选池越大,判据能拿到的"可得增益"份额越小。**

原因是分母:n 越大 oracle 越强,而模型选中的那条跟不上。**这与我事先的猜测相反。**

**未测项(诚实写明)**:本实验只报了**比值**(捕获率),**没有单独记录绝对增益 `model − random`**。
绝对增益完全可能随 n 上升而比值下降。**要判"n 该开多大"必须先测绝对增益,本实验判不了。**

## 六、移动四只做了一半

**做了的**:单轮 top-1-of-n 的选择价值。
**没做的**:误差跨轮相关。多轮设计里同一靶标上判据的错误是**相关**的(同一失败模式),
不会像独立噪声那样被平均掉。**声明里就写明是未测项,现在照旧写明。
不许说本实验覆盖了移动四的全部。**

## 七、边界

1. **没有盲人群。** 只用骨架可形成子集。仍在 Turner 族内。**只量信息量,不判上线** ——
   要改出厂决定,先过那三张表的重新校准。
2. `A_pall` 是声明冻结后补的臂(M1c 比 M4 声明晚),**不进入 K1/K2/K3/K4 任何一条**,只作报出。
3. 蒙特卡洛换成闭式精确期望(修正案 A)会**缩窄**区间 —— 危险方向,理由纯逻辑:
   精确期望就是那 200 次抽样在 R→∞ 的极限,已与全枚举对到 1e-14。
4. 退化格(oracle == random)作废并计数:主人群 61 个;格内数 < n 跳过 35,518 次。
5. 预测并列按**均匀随机取一条**精确计入(`GC_only` 的 `gc_cross` 是整数,并列很常见,这一条对它必需)。
