## 四、脚本自己打印的那行反解是错的 —— 必须以梯级为准

程序打印:

```
要让本臂有裁决力,每对需要共同靶标 >= 28(按 1.96/sqrt(n−3) = 0.4 反解);实测共同靶标 30~47
```

**这行自相矛盾:它说需要 28、我们有 30~47,而梯级明明显示 0.4 那一档只有 2/6。**

解析式低估了三件事:
1. **bootstrap 区间比 Fisher-z 近似宽**;
2. **要求是"六对里中 5 对"(含 n=30/31 的小对),比"某一对排除 0"严得多**;
3. **Spearman 相对名义 Pearson 系统性衰减**(0.4 → 实测 0.337,0.6 → 0.460,0.8 → 0.691)。

**按实测半宽(n=46 约 0.31,n=30 约 0.37)与实测点估计(0.24~0.46)反推:
要在 rho_true = 0.4 上拿到 5/6,每对约需共同靶标 70~90,而且仍属勉强;要稳,约需 100~140。
实测 30~47 ⇒ 大约还差 2~3 倍。**
