### 而复核查出一项严重问题:符号一致性很弱,均值是被少数靶标抬起来的

**声明里【没有】冻符号检验,所以这是复核的事后观察量,按第 41 条的同一条纪律标注清楚。**

| 人群 | 对比 | 均值 | 区间 | 正号靶标 | **符号检验 p** |
|---|---|---|---|---|---|
| **样本2(主)** | A_ed | +0.0140 | **排除 0** | 30/56 = **53.6%** | **0.689** |
| 样本2(主) | A_E5 | +0.0155 | 排除 0 | 35/57 = 61.4% | 0.111 |
| 样本3 | A_ed | +0.0164 | 含 0 | 29/47 = 61.7% | 0.144 |
| 第四批 | A_ed | +0.0207 | 排除 0 | 24/35 = 68.6% | 0.041 |
| **内建对照** A_G(配平) | | +0.0006 | 含 0 | 27/56 | **0.894 干净的零** |
| **探针** A_G(不配平,GC 在场) | | +0.0251 | 排除 0 | 39/57 = 68.4% | **0.0075 强** |

**主人群的 bootstrap 均值区间排除 0,而符号检验 p = 0.689 —— 56 个靶标里 26 个为负。
那 +0.0140 不是一致的逐靶标效应,是被少数靶标的大正值抬起来的均值。**

**而机器本身没问题:内建对照给出干净的零(p=0.894),GC 在场的探针给出强符号(p=0.0075)。
⇒ 这台仪器在效应真实且普遍时能产出强符号一致性;`ensemble_defect` 产不出。**

**两种读法,本实验分不开:** (a) 重尾噪声,"排除 0"脆弱;(b) **效应真实但集中在少数靶标上**
—— 而 (b) 正是移动二说的主项/余项结构。**均值区间与符号检验背离,本身就是"该切开而不是该平均"的信号。**

## 四、诚实读法

**这不是"第一个正向发现"。按冻结判据它是 `underreplicated`,两臂效应/MDE 只有 1.03 / 1.24,

**但它确实是新的一件事,而且是构造性的:GC 作为解释【被排除了】,不是被统计控制,是被相消。**

我照写;**但这个形状(效应≈1×MDE、下界擦零)正是第 43/48 条说的『仪器边界』,不是『效应不存在』。**
