## 二、E_free 那一侧:**等宽对照说,位置类边际的增量不是假结特异的**

E_free 是**干净的等宽比较**(BCE 与 BCR 各 29 列,同人群、同格结构、同一次 bootstrap 配对)。而它说:

> **+0.0119 ~ +0.0153 的增量里,随机位置能拿到 35% ~ 88%,配对差四人群全部含 0。**
> **交叉臂的可及性,相对随机位置,没有可证的额外贡献。**

**而 E1 缺的正是这一问。** E1 只问了"E 有没有增量",没问"增量是不是假结特异的"。
`acc_arms_vs_bg`(减去全分子平均可及性)是我做的**调整**,不是**对照** —— 它答不了
"把同样的统计量算到别的位置上会不会一样好"。**现在答了:会。**

**所以我上一条说的"今天第一个正向结果"必须削弱:** K1/K2 的 16/16 排除 0 **作为测量成立**,
但它测的东西**大部分是"这条分子的集合松散"** —— 一个与假结无关的通用柔性度量。

## 三、E_full 那一侧:信号在,**但我一开始把它的位置猜错了**

先更正我自己一小时前的一句话。**我说 E_full 有"宽度混杂"(31 列 vs 29 列)—— 说得不准:**
每个块都减掉了**自己的**格内置换零,而置换零正是"这个宽度的块在打乱的 y 上能买到多少 R²"
——**宽度已被校正,这是这个估计量本来就为它建的。**

**真正的不对称是【内容】:安慰剂块里没有任何 skeleton 基的对应物。**
所以 E_full 的 K3new 回答的是"**臂 + 骨架** 是否胜过随机位置",不是"**臂** 是否胜过随机位置"。

**而把四人群摆在一起,能读出一条相当强的推断:**

```
加上那 2 根 skeleton 列之后:
  处理组(E)   +0.0119 -> +0.0274    +0.0153 -> +0.0335    +0.0141 -> +0.0311    +0.0147 -> +0.0267
                          【四人群全部约翻倍】
  安慰剂      +0.0077 -> +0.0034    +0.0134 -> +0.0117    +0.0049 -> +0.0060    +0.0123 -> +0.0071
                          【没有系统性变化,两升两降】
```

**处理组翻倍、安慰剂不动 ⇒ 最简约的读法是:特异信号在 `ensemble_defect(骨架)` 与 `pr_structure(骨架)`
这两根【指向靶标结构】的列上,不在交叉臂的可及性上。**

**这在物理上讲得通,而且它结构性地不是 GC 代理:** `ensemble_defect(骨架)` 是
"相对预定结构、期望有多少个位置配错了"——一个**引用了靶标**的量,而一个随机位置块**在构造上无法模仿它**。

**但这是推断,不是测量。** 要确证必须给安慰剂配一个**引用骨架但被打乱**的对应物
(例如对打乱后的骨架算 `ensemble_defect`,或对同配对数的随机嵌套结构算 `pr_structure`),
**并把处理组缩到只有那 2 根列、与之等宽对比。那是第三份声明,我现在不改口径、不宣布通过。**
