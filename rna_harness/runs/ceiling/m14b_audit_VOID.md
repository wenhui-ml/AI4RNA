## 五、我梯级代码里的错 —— 第 71 条,**第五次**

partner_G 那一层的梯级在 **δ=0.01 就已经 100% 达标**,而该层 bootstrap 半宽是 0.079。**不可能。**

看代码:

```python
A2 = [A[q] for q in ia]                       # 强对臂,本身就带着 +0.24 的真实差
B2 = [(B[q][0] - dd, B[q][1]) for q in ib]    # 弱对臂减去 δ
hit += diff_boot(A2, B2, ...)["excl_pos"]
```

**我把 δ 注在了【已经存在的真实效应】之上,而不是注在零上。** 于是梯级量的是「真实差 + δ」能不能被检出,
当然 δ=0.01 就 100%。**partner_U 那一层因为真实差 ≈ 0,梯级碰巧是对的(阈值 0.20),这也解释了两层为何差这么多。**

> **第 79 条:梯级必须建在【零】上,不能建在主臂效应之上。
> 自检:把 δ 设为 0,达标比例必须回落到名义水平(≈0.05);若 δ=0 时就接近 1,梯级就是错的。**
> 第 71 条至此连续第五次被违反,前四次是量程,这一次是**基准点**。
