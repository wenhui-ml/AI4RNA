# 外部建议里三条承重文献的核实(2026-08-05)

> 一份外部综述给了四个方向,其中方向三(用 2025 年新的共转录 SHAPE-seq 数据突破 70 nt)和方向四(可设计性预测)各自压在一条我无法凭记忆核实的文献上。
> **在按它们立项之前先查。** 下面是查的结果,以及它们如何改变立项资格。

---

## 1. Szyjka et al. 2025 —— **文献为真,但它不是"新分子",是"同样几条分子的更好方法"**

[Sequential structure probing of cotranscriptional RNA folding intermediates, *Nature Communications* 16:5085 (2025)](https://www.nature.com/articles/s41467-025-60425-w) · [PMC 全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12126503/)

方法叫 TECprobe-LM,探测的构建体是:

```
E. coli SRP RNA                     161 nt
C. beijerinckii pfl ZTP 适配体      120 nt
C. beijerinckii pfl ZTP 表达平台    143 nt
B. cereus crcB 氟核糖开关 适配体     71 nt
B. cereus crcB 氟核糖开关 表达平台   95 nt
```

**这四个分子系统,我们 `rmdb_cache/` 里全都有**(`ECOSRP` / `SRPECLI` / `SRP21CR` / `SRPU21C` / `PFLZTP` / `CRCBFL`)。

> **它是同一批分子上的更好方法,不是一批新分子。**
> 唯一还有价值的可能性:TECprobe-LM 的数据质量更高,也许能让**参照质量门槛**放行更多构建体(我们这边 12 个非 BSUGLY 构建体里有 5 个的参照连自己被拟合的数据都解释不了,最低 0.507)。
> **但 PMC 页面在 Methods 中段被截断,没能读到 Data Availability,accession 未知。** 这是一封邮件的事,不是一个项目。

## 2. RMDB 已经见底 —— 这是本地直接查的,不靠文献

```
清单里共转录 2D 沉积 76 条  ->  去重后 27 个构建体
我们已抓                    27 个
未抓的                       0 个
```

**RMDB 上这种数据类型的构建体,我们一条不落全在手上。**

## 3. RASP v2.0 —— **文献为真,但数据类型不对**

[RASP v2.0: an updated atlas for RNA structure probing data, *NAR* 53:D211 (2025)](https://academic.oup.com/nar/article/53/D1/D211/7901281)

它的扩充是:转录组级探测数据集 154 → 216、新增 141 个靶向探测数据集、新增 81 个 RNA–RNA 相互作用数据集。

> **这些是平衡态探测与相互作用数据。我们需要的是【逐转录长度】的反应性 —— 一个非常窄的数据类型。RASP v2.0 的扩充不在这条线上。**

### 方向三的立项判定:**不立**

```
不是工具问题(§4.9 已证)
不是我们没去找(RMDB 27/27 全在手)
是【全世界用这种方法探过的分子系统大约就是 7 个】
```

**所以"第二把尺子的外部验证越不过 ~70 nt"这句话,现在有了第三个、也是最终的成因:**
**不是裁判、不是预算、不是数据可得性 —— 是这种测量在全世界的存量。**

**唯一剩下的动作**:去要 TECprobe-LM 的处理后数据,看它能不能让参照质量门槛多放行几个构建体。**一封邮件,不占项目位。**

## 4. "Probabilistic RNA designability" 2026 —— **文献为真,而且必须重新定位我们的方向四**

[Probabilistic RNA Designability via Interpretable Ensemble Approximation and Dynamic Decomposition (Zhou, Mathews, Huang, arXiv 2602.13610)](https://arxiv.org/html/2602.13610)

它做的是:

```
给出 p_bound(y*) >= max_x p(y*|x)
   —— 在 Turner 能量模型下,任何序列折成该靶标的平衡概率的【上界】
只处理【无假结】结构
不用任何实验数据,不涉及求解器,不预测任何流水线的成败
规模可到上千 nt(ArchiveII >200 nt、Eterna100)
```

### 与我们方向四的关系:**任务A 零重叠,任务B 有重叠且它是竞争特征**

| | 他们 | 我们 |
|---|---|---|
| 对象 | **靶标在能量模型下的性质** | **流水线 + 裁判的结果** |
| 假结 | **明确排除** | **任务A 全是假结** —— 零重叠 |
| 标签 | 无(理论上界) | 任务A:RNAPKplex(外部裁判);任务B:池里有无合格候选 |
| 验证 | 与既有设计方法的经验概率对照 | 留出集 + 置换对照 + 解析零假设 |

> **任务A(假结上预测外部裁判是否确认)与他们没有交集** —— 他们不碰假结。
> **任务B(池里有没有合格候选)与他们的问题相邻**:"这个靶标难不难"确实可能主要是能量模型下的性质。
> **这生出一个干净的后续检验:他们的 p_bound 能不能比我们的结构特征更好地预测任务B 的标签?** 那需要拿到他们的代码。

### 方向四的立项判定:**继续,但主张要改口**

```
不能说   "没有人做可设计性"        —— 错,2026 年有理论工作
可以说   "可设计性的【理论上界】有人做;
          而【某条具体流水线 + 某个外部裁判会不会通过】是另一个对象,
          我们在留出集上把它预测到了 AUC 0.945 / 0.929,且任务A 落在他们明确排除的假结上"
```

## 5. 对那份外部综述本身的评价

| 它的说法 | 核实结果 |
|---|---|
| 2025 年有新的共转录 SHAPE-seq 数据 | ✅ 真,**但是同一批分子** —— 它没说这一点,而这一点否掉了它的立项理由 |
| RASP v2.0 可提供更多合格构建体 | ❌ 数据类型不对 |
| "没有人把可设计性做成面向非专业用户的工具" | 部分真:**理论工作 2026 年已有**,产品化没有 |
| 它写"244 个测试" | 我们当时是 248 —— 它读的是稍旧的快照 |

> **它的诊断(类型不匹配)是对的且与我们独立收敛;它的四个药方里,两个的事实前提经核实是错的或不完整的。**
> **这不降低它的价值 —— 它给了 conformal 这个我们自己不会想到的精确工具。但按它给的理由立项之前,必须先查。**
