## 二、M2b:先问有没有东西可找 —— **g_t 是靶标的性质,这一点六对全部排除 0**

四个人群的设计**分子级零重叠**(闸门 V1,六对全部 = 0),靶标共享。
所以跨人群的 g_t 相关是真正的交叉验证。

|---|---|---|---|---|
| 样本2 × 基准4560 | 56 | **+0.4945** | [+0.2405, +0.6981] | 50/50 |
| 样本2 × 样本3 | 56 | **+0.4713** | [+0.2045, +0.6792] | 50/50 |
| 样本2 × 第四批 | 52 | **+0.4905** | [+0.2309, +0.6999] | 50/50 |

| 样本3 × 第四批 | 52 | **+0.3659** | [+0.0954, +0.5981] | 50/50 |

**六对均值 +0.4355,置换零分布 95 分位 +0.0954 ⇒ 远超零点。六个区间全部排除 0,
50/50 个 bootstrap 种子下裁定不翻(第 51 条)。**

**这就是"存在一个不变量"的直接证据:一个只要换一批设计就消失的量,不可能跨四个不相交人群
稳定到 rho ≈ 0.44。M2 找不到它,只说明它不在那十列里。**

### 2.1 但 arm1 的裁定按我自己冻结的话是 **VOID,不是通过**

声明里 V2 写的是:「rel_cell 的区间必须排除 0,否则本仪器连信度都测不出,arm1 的分母无意义 ⇒ 作废,不写裁定」。

| 人群 | rel_MC(奇偶划分,必响输入) | rel_cell(格半分,设计抽样) |
|---|---|---|
| 样本2 | **+0.9894** [+0.9711,+0.9956] 响 ✓ | +0.1219 [−0.2057,+0.4159] **含 0** |
| 基准4560 | +0.9900 响 ✓ | −0.0636 [−0.5241,+0.4559] **含 0** |
| 样本3 | +0.9822 响 ✓ | **算不出**(两半的公共靶标 < 15) |
| 第四批 | +0.9827 响 ✓ | +0.1487 [−0.2187,+0.4653] **含 0** |

**V2 失败 ⇒ arm1 作废。我照写,不改。**
这和 H1 是同一件事:**冻结的作废闸门就是冻结的作废闸门,在数字对我有利的时候重新解释它,
和在数字对我不利的时候重新解释它一样不合法。** 那 +0.4355 不会因为作废而消失,
但它**在仪器修好之前不能拿去下裁定**。

**为什么 rel_cell 测不出来,是知道的,不是含糊的:**
1. **机械原因**:每个靶标平均 5.9 个格,对半分只剩 ~3 个,半长 g_t 的噪声远大于全长 g_t。
   区间 [−0.21,+0.42] 与 rel 高达 0.42(S-B 校正到 0.59)完全相容 —— 它不是"信度低",是**测不动**。
2. **概念原因,更要紧**:四个人群之间**只差在抽了哪批设计**。那么"设计抽样信度"与
   "跨人群 rho"在这个设计下**是同一个被估量**。V2 要求我用一个功效更差的估计量,
   去单独测 arm1 已经在测的那个量 —— **这是个规格写错的闸门,不是一次失败的测量。**
   (第 47 条的反面:我造了一个它的输入根本抬不动的闸门。)

**修法照 H1→H2 的老路:另开声明,把信度估计量换成【格内设计级 bootstrap 复本】
(保持格数不变,只扰动抽到哪些设计),重跑 arm1。作废只有配上重测才算数,否则就是洗失败。**

K4 方向为负               : 不触发

### 3.1 K2 触发的准确内容:**1.93 对 2.00**

效应/MDE = |均值| / (1.96·sd/√n) = **t/1.96**。1.93 ⇒ **t = 3.78**(双侧 p ≈ 0.0004)。
我冻结的 2.00 这个门槛等价于要求 **t ≥ 3.92**。**我们差 0.07。**

**裁定不改:`main_part_below_resolution`。** 同时,以下四件事全部是冻结判据下测到的:
主项区间排除 0、种子 50/50 稳定、K3 不触发(不是随机切分能做到的)、K4 不触发(方向对)。
**"低于分辨率"这个标签指的是我设的那条更严的线,不是指效应没测到。**

### 3.2 诊断(`m2b_review_split.py`):K3 的比较量选弱了,该比的是**半间差**

冻结的 K3 拿【被选中那半的 效应/MDE】去比【随机切分下两半的最大值】。
这个零点按构造就偏高(1.71):汇总均值为正,随机切分的两半**都**为正。
在随机切分下期望为 0 的统计量是**半间差**。测了:

* **半间差 +0.0344**
* 置换零分布(20,000 次)中位 −0.0002,95% **[−0.0200, +0.0201]**
* **双侧置换 p = 0.00020**
* 靶标 cluster bootstrap 95% **[+0.0177, +0.0543] 排除 0**,**种子翻转 50/50 稳定**

**这是诊断,不是改判。** M2b 的裁定仍是 `main_part_below_resolution`。
它的位置是**下一份声明的判据设计**:K3 该用半间差,不该用最大半的 效应/MDE。

## 四、把三件事放到一个维度上看

| 层 | 之前的说法 | 现在测到的 |
|---|---|---|
| 汇总 | "57 个靶标锁死一切低于 +0.02 的效应" | **对【平均】成立,对【选对的子集】不成立**:主项 +0.0330,余项 −0.0014 |
| 靶标间离散 | 当噪声平均掉(sd 0.039 是效应的 2.5 倍) | **不是噪声。跨四个不相交人群 rho ≈ 0.44,六对全排除 0** |
| 不变量 | T1 试了拓扑,失败 ⇒ 收工 | **结构族十列全部 unresolved;经验 g_t 切得动,半间差 p = 0.0002** |

**统一的一句话:这个库的信号不是均匀铺在 57 个靶标上的,它坐在其中一半里。
我一整天把它平均掉,然后从那个平均值推出了一条关于整个库的普遍定理。
那条定理("+0.0096 的地板锁死一切")现在有了它的边界:它是汇总估计量的性质,不是库的性质。**

而**表示的瓶颈也在同一句话里**:能切开库的那个不变量,**不在靶标的预测配对集合这个族里**
(十列全部 unresolved),却**能从另一批设计的湿实验读数里读出来**。
这正是 20.1% 天花板复核指认的那件事的第二次独立出现 —— **缺的是表示,不是数据量。**
