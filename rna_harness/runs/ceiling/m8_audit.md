机制假设原文:**"两根 GC 列只能靠设计之间 GC 的差别排序;设计们 gc_cross 几乎不变的靶标,GC 判据没有信息可用。"**

**四个人群全部为负,量级 0.28~0.35,均值 −0.3065。** 而它按冻结判据记 **0/4**。

原因在我自己的代码里:

```python
rep += 1 if ci[0] > 0 else 0        # V5: same side (positive)
```

> **我把"同侧"硬编码成了"正向"。** 主臂 `spread_gc` 有方向假设(正),那样写没错;
> **但次要不变量我根本没有预设方向,用一个只数正向的计数器去数它们,
> 就把一整行一致的负相关数成了 0/4。**

**这是第 53 条那个错误的第四件外衣:**
M1 把双侧计数用在噪声臂(撤回 #26)、M1d 把双侧条件用在探针(第 56 条)、
M4c 把对照写成主臂(第 59 条)、**M8 把单侧计数用在没有预设方向的量上**。

### 第 60 条

> **"同侧"只对【预先声明了方向】的量有定义。没有预设方向的量,复现计数必须双侧,
> 并且【方向一致性】本身要单独报出(四个人群同号 = 一个独立于区间的证据)。**
> 一份声明里若同时存在有方向与无方向的量,**计数器必须逐量指定,不许全表共用一个。**

**按冻结判据,`target_len` 在本份裁定里就是 0/4,本审计不改它(第 42 条)。**
那四个负号进下一份声明,方向预设为负、按它自己的检出力设计 —— **不是回头改这一份。**

## 四、归属臂给了那条线索一个不错的对照

同一个 `target_len` 跑在**面板** capture_t^A 上:**−0.458 / +0.261 / −0.152 / −0.200 —— 不一致,有一个翻正。**
而在 GC_only 上是四个全负、量级接近。

> **靶标越长、GC 判据拿到的可得增益份额越低** 这件事,在 GC 上一致、在面板上不一致。
> **它不像一个"任何判据在长靶标上都变差"的通用效应。** 这是 M8b 值得开的理由,不是结论。

## 五、这次负向结果的真实位置

`capture_t^GC` 是一个**被确证稳定**的量(M4d:六对全中、等宽纯噪声 −0.01、信度 0.9997),
但**五根靶标级不变量在 |rho| ≳ 0.34 的分辨力下都没说出它是靶标的什么性质。**

这与前五个族的结论是同一句话的第六次出现:
**我们能测到"存在一个稳定的靶标量",却测不出"它是靶标的哪个性质"。**
区别在于:前五次被解释的量本身可复现性存疑,**这一次被解释的量是干净的,而解释仍然没有。**

**所以这不是"又一个空族",这是一个更强的负向陈述:
干净的量 + 五根不变量 + 0/12 噪声 ⇒ 空。而且这次的筛是最粗的一次(0.34)。**
