## 一、哲学(按记忆里写死的原文,不是按我此刻的印象)

1. **科研是正向发现大于负向分析。** 杀不是产品。
2. **"区间含 0"永远不是证伪** —— 它是关于仪器的陈述。标 `unresolved`,线保持开着,写清什么能定它。
3. **对称条款**:事后判据**杀掉自己的正结果**,和事后判据**救活自己的负结果**,一样不合法。
   怀疑不是天然安全的方向。**未冻结的观察量可以驱动下一个实验,永远不能下调一个冻结裁定。**
4. **不点名邓煜四步里哪一步没用过,就不许关一条线。**
5. **主因子要按构造相消,不要统计控制。**
6. **问正向形式的问题**(不是"GC 还配上了什么",而是"GC 配平之后什么还在排序")。
7. 方法论规则 38–52(见下表逐条对照)。
8. 边界纪律:先报成本再花钱;离线要明说;冻结的判据以那一行代码为准。

## 三、三个缺口,三次测量

### 缺口一:**M3 从来没有安慰剂臂** —— 测了,归属**站得住**

M3 的内建对照 `A_G−A` 证明的是"相消生效",噪声零点证明的是"废列没用"。
**两者都没测归属**:一根真实的、依赖设计的、**与骨架无关**的集合集中度列,会不会在同一批配平对上
也排出同样的名次?R6 已经证明在**不配平**的构造上安慰剂 `ed_mfe` 复现到 ρ=+0.397。
所以必须把同一个问题放到 M3 自己的配平对上。`m3b_placebo_on_matched.py`,同一批划分,同一批配平对:

| 人群 | `A_G−A`(必须为零) | **`A_ed−A` 真列** | **`A_mfe−A` 安慰剂** | `A_pair` 相消后 |
|---|---|---|---|---|
| **样本2(主)** | +0.0006 含 0 | **+0.0140 排除 0**(种子 50/50) | **+0.0018 含 0**(种子 0/50) | **+0.0122 排除 0**(50/50) |
| 基准4560 | +0.0005 含 0 | +0.0027 含 0 | −0.0033 含 0 | +0.0060 含 0 |
| 样本3 | −0.0003 含 0 | +0.0164 含 0 | +0.0092 含 0 | +0.0071 含 0 |
| 第四批 | −0.0011 含 0 | **+0.0207 排除 0** | +0.0040 含 0 | +0.0168 含 0 |

**主人群上安慰剂 +0.0018,只占真列的 13%,区间含 0,50 个种子里 0 次排除 0。
把一般集合集中度按构造相消之后(`A_pair`)仍是 +0.0122 且排除 0。**

**⇒ M3 的归属经受住了这次对照。GC 相消之后还在排序的那个量,是骨架特异的,不是一般集合集中度。**
(`A_G−A` = +0.0006 与 M3 原跑完全一致,构造复现。)

**为什么这和 R6 不矛盾。** 两处测的不是同一件事:
* **量级**:安慰剂的**平均增益**到处都接近 0(配平上 +0.0018 = 13%,不配平上 +0.00087 = 5%)。
* **名次**:安慰剂的**逐靶标模式**是可复现的(人群内 ρ(ed,mfe)=+0.37~+0.54,跨人群 +0.397)。

⇒ **统一说法:"效应有多大"是 `ensemble_defect` 特有的;"帮到哪些靶标"是集合集中度类列共有的。**
M3 问的是前者(站得住),M2b arm1 问的是后者(我把它讲成了前者,已撤回 #25)。

### 缺口二:**判决用的那个检验,它自己的假阳率随人群变** —— 测了,**M3 的复现计数不可信**

12 根噪声列,与主臂同批划分,看有几根的区间排除 0(标称 5%):

| 人群 | 噪声零点中心 | **区间排除 0 的噪声根数** |
|---|---|---|
| **样本2(主)** | −0.00037 | **0/12** |
| 基准4560 | −0.00126 | 1/12 |
| **样本3** | −0.00077 | **3/12 = 25%** |
| 第四批 | −0.00043 | **0/12** |

**样本3 上这个检验的双侧假阳率是 25%。**

> **更正(撤回 #26,2026-08-25 晚,见 `m1_audit.md` 第四节):上面这句话我写成了『正向假阳率』。
> 3/12 是【双侧】计数;【正向侧】是 1/12 ≈ 8%。加废列会可靠地伤害排序,区间检出它是正确的,不是假阳。
> 第 53 条据此改写为『只数与被宣称效应同侧的触发根数』。
> 结论不变 —— 『M3 的复现计数不可信』靠的是种子翻转 119/200,与本更正无关 —— 但支持它的假阳数被我夸大了 3 倍。**

而 `m3_boot_stability` 早已测出
**样本3 的裁定在 200 个种子里只有 119 次排除 0(59.5%)**。两条独立证据指同一件事:

> **M3 的 K3(复现 1/3)是用一个在样本3 上既不稳、假阳率又高 5 倍的仪器数出来的。
> 那个计数在两个方向上都不可信 —— 它既不能证明复现,也不能证明不复现。**

主人群相反:噪声 **0/12**、种子 **50/50**、BCa 与百分位一致。**主人群的裁定是干净的。**

### 缺口三:**M2 的必响探针没响 —— 按它自己的声明,M2 是作废,不是发现**

M2 的作废闸门 1 原文:
> 「探针:把 `mean(wet)` 当成第 11 个候选塞进去,**它必须在 step1 里显著 —— 若不显著说明筛选流程本身没有检出力。**」

实测 ρ = −0.0199,p = 0.891,**没响**。
我当时的做法是:**事后补了一根构造性探针**(g_t+噪声,ρ=+0.535,p=0.0002),用它宣布"筛选有检出力"。

**那是一次事后判据。** 而且方向是**救活我自己的一个负结论** —— 与我在 M3 上犯的那次
(事后判据打折自己的正结果)是同一个错误的镜像。对称条款两边都管。

**⇒ 更正:`no_invariant_found_among_these_ten` 记为 **VOID by void gate 1**,不是一个结论。
十个结构不变量这条线【重新打开】,不是关着的。**

(补加的探针确实说明这套筛选在 ρ≈0.5 上有检出力 —— 那是**重跑时该冻进声明的东西**,
不是**给这一跑背书的东西**。)

## 五、这次校准长出来的规则

> **53(已于同日改写,见 `m1_audit.md` 第四节)。一个闸门的假阳率是【逐人群】的性质,不是流程的性质。
> 任何靠该闸门数出来的复现计数,必须报每个人群上 R≥12 根**宽度配平**噪声臂里
> **与被宣称效应同侧**的触发根数。双侧计数会把『正确检出废列的过拟合代价』误记成假阳,
> 并因此错误地作废人群 —— M1 里它确实误作废了基准4560。同侧根数不一致的人群,其计数作废。**

> **54. 必响探针没响 = 本次运行作废。事后再补一根会响的探针,只能写进下一份声明,
> 不能给这一跑背书 —— 无论这一跑的结论是正的还是负的。**
