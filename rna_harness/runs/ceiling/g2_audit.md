## 二、审计发现的第一件事:**226 条里有一半根本形不成靶标骨架**

先说一个**恒等式**,它不是测出来的:`F_nested` 是嵌套集合的**集合**自由能,而 `_round_only(target)`
就是这个集合的一个成员,所以

```
F_nested <= E(嵌套集合的任一成员) <= E_skeleton      =>      M1 = F_nested − E_skeleton <= 0  恒成立
```

实测 **66/4560 条违反了它**。查下去:

| | |
|---|---|
| 骨架里含**非标准配对**(不是 GC/AU/GU)的设计 | **1027/4560 = 22.5%** —— 这些设计**根本形不成靶标骨架**,`E_skeleton` 无意义 |
| M1 > 0 的 66 条里骨架含非标准配对的 | **66/66 = 100%** |
| 骨架干净的 3533 条里 M1 > 0 的 | **0 条** |

**违例被完全解释,恒等式在"骨架可形成"的设计上无一例外成立。** 而后果是致命的:
非标准配对被 ViennaRNA 按罚项求值 ⇒ `E_skeleton` 被抬高 ⇒ `γ* = F − E − dG` 被压低。**所以这类设计会被系统性地推进"可证否决"那一栏。** 实测:

> **γ\* < 0 的 828 条里,骨架含非标准配对的占 50.0%,而全体基线是 22.5%。**
> **也就是说,那批"可证否决"里有一半只是【连碱基都配不上】的设计 —— 查互补性就能看出来,
> 一点热力学都不需要。**

**这是我漏掉的一道闸门:γ\* 只对骨架可形成的设计有定义。** 限制到干净子集后:

## 三、审计发现的第二件事(更要紧):**这批分子里三分之二在试管里【通过】**

| 子集 | n | 试管通过率(通过线 80.0) |
|---|---|---|
| confirmed & γ\*<0(全体) | 226 | **0.619** |
| confirmed & γ\*<0(骨架干净) | 123 | **0.675** |
| 其中 k=3 | 9 | 0.667 |
| 对照:confirmed & γ\*>=0(骨架干净) | 2076 | 0.830 |

**如果 γ\*<0 是"可证明这条设计折不出预期结构",这一列应该接近 0。它是 0.675。**

### 为什么不是证明 —— 一个我本该在写下那句话之前就看出来的结构问题

γ\* 把一个**集合自由能**(`F_nested`,对**所有**嵌套结构求和,含整个集合的熵)去比一个**单结构能量**
(`E_skeleton + dG_stack`)。由上一节的恒等式,`M1 <= 0` 永远成立,于是

> **γ\* < 0 的含义是:嵌套集合【作为一个整体】相对骨架的优势,超过了交叉茎的堆叠增益。**
> **输给一个【集合】不等于输给其中【任何一个】竞争者。** 而化学探针测的是**群体平均**,
> 在那个平均里,靶标结构完全可以仍然是**单个占比最高**的构象。

**所以 γ\*<0 证明的是"在这套记账下处于热力学劣势",不是"面板判错了"。**
自由能不等式说的是相对布居,不是不可能:37 °C 下 1 kcal/mol 的差距约是 5:1 的赔率,不是 0。

### 必须撤回的原话

分析文档第七节第 2 项:"**一批不需湿实验即可确证的面板误收**"。
**"确证"和"面板误收"两个词都要撤。** 能站住的说法是:

> **123 条骨架可形成、被出厂面板确认、而在精确嵌套记账下处于热力学劣势的设计。
> 它们的试管通过率(0.675)显著低于对照(0.830),但多数仍然通过 —— 所以这是一个【富集信号】,
> 不是一个【否决证明】。而这个富集,一个交叉茎 GC 计数就能做到同样好。**
