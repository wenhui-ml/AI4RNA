## A16:主检验其实可读,是我的作废门槛写错了

打印的判定是 `flag_does_nothing`,依据是「GC 的配对差不排除 0」。但那个门槛用错了代理:

```
两臂序列【完全相同】的运行对:0 / 171      ← 这才是「标志生效了吗」的正确代理
GC 差非零的运行对:152 / 171;GC 配对差中位 +0.0256,符号 31正/16负,CI [+0.0000,+0.0423]
```

区间下界**恰好落在 0.0000** 上,于是「不排除 0」触发作废。**标志确实传到了 DesiRNA 并改变了搜索。**
(顺带:3 靶标 smoke 当时看到 GC 【下降】0.03–0.22,57 靶标上是【上升】中位 +0.026 —— smoke 的 n=3
不具代表性,这也是为什么 smoke 只能用来判「管线通不通」,不能用来判方向。)

门槛修正后,适用的是主检验与次检验:

```
主检验 k(on − off),单位=靶标,三种子取中位:中位 +0.0000  0正/1负  CI [+0.0000,+0.0000] 跨过 0
次检验 证书档位秩差(靶标级,每靶标三种子取最好档位,负=on 更强):
        中位 +0.000  on 更强 2 / on 更弱 1 / 相同 54  CI [+0.000,+0.000] 跨过 0
混杂可见性 screened(on − off):中位 0,47/57 个靶标恰好为 0 → 【ACGU 臂没有被系统性削弱】,这一关过了
          wall_s(on − off):中位 +0.9 秒,跨过 0
```

**结论:干净的 null。约束打开确实改变了搜索,但买不到等级、也买不到证书档位。** 按新口径这**不进分数**,
进「已关闭的路」。

### 硬性否决那条门槛也用错了地方

丢档位的靶标 1/57 = 1.8%(pseudobase:34,certified → cannot_certify)。而本项目自测:**同配置重复
(完全不经过被改动的代码)的判决翻转率 22.9%**(16/70,对称)。「零回退」这条绝对门槛是从
`grade_max_bench` 的 P2 抄来的,而那里两臂是**同一个候选池上跑两种策略**,回退是确定性的。这里两臂是
**两次独立的求解器调用**,1/57 完全落在噪声里。**抄门槛的时候没抄它成立的条件。**

## 这三天第三次同一类声明缺陷,记死一条规矩

| 实验 | 门槛设在了什么上 | 应该设在什么上 |
|---|---|---|
| A9 | 总相悖配对 ≥ 100 | 分档后每一档的样本量 |
| A13 | 可用单位 ≥ 20 | **三层能分开**的单位 ≥ 20 |
| A16 | GC 的区间排除 0(作废门槛) | **序列变了没有**(而这个量我记录了、且毫无歧义) |

**规矩:门槛必须设在【真正进入检验的那个量】上,而且如果有一个毫无歧义的直接观测(序列变没变),
就不许用一个统计量去代理它。** 另外:**抄一条门槛时必须一起抄它成立的条件。**
