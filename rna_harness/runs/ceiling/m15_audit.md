## 二、**必须写在最前面的限制:B 臂没有功率,所以判别方向是空的**

B 互补臂的配对数是 **1、9、10、13、13、56**。**这不是一条能判别的臂。**

**⇒ 能说的只有一句:「把筛子加上之后,效应原样还在。」**
**⇒ 不能说:「所以效应不是由『剖面对而结构错』的设计撑起来的。」** 那需要 B 臂有功率,而它没有。

**这个区别不是措辞讲究 —— 它是本轮唯一想回答的那个问题,而本轮没能回答。**

## 三、置换 p 与 bootstrap 区间在第四批上分道扬镳,这一条要解释清楚

第四批 A 臂:效应 **+1.9896**,**置换 p = 0.0005**(零 SD 0.4074 ⇒ 约 4.9 个零 SD),
但**靶标 cluster bootstrap 区间 [−0.97, +4.73] 含 0**。第六批 A 臂同样(16 对)。

**两者不矛盾,它们回答的不是同一个问题:**
* **置换检验**问:「在这批靶标上,gc_paired 与湿读数的这个关联,能不能由偶然产生?」—— 不能(p=0.0005)。
* **靶标 cluster bootstrap** 问:「这个效应量推广到**新靶标**上是多少?」—— 靶标间异质性大,区间就宽。

**两个都必须报。第 76 条讲的是【不许只报窄的那个】,不是【bootstrap 一律不可信】。**

## 五、我又一次**声明了却没实现**一根探针 —— 已补做

声明的 P2 原文要求「**刻度实测**」且「**顶档下限取 4.0**」。
`m15_structure_filter.py` 只记录了**逐 ρ 的检出比例**,**从未量过 ρ → E[效应] 的映射**,
因此「顶档 >= 4.0」这一条**根本没被检验过**。

**这与 M10b 的 `shape_2`、M11 的 complete-cases 臂是同一类错误:声明里有,代码里没有。**
补做见 `m15_ladder_scale.py` / `.json`:
