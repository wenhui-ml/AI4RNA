## 0. 现状盘点：④ 是什么，13/18 卡在哪

④ 的主张从来不是"我们解决了某个难题"，而是：

> **在一个没有公认判据的领域里，我们能造一把标定过的、经外部验证的、适用范围诚实的尺子。**

18 条子命题，13 ✅ / 5 ❌。五个 ❌ 的性质必须先分清，因为它们决定了"提升"往哪走：

| ❌ | 子命题 | 性质 | 还能做什么 |
|---|---|---|---|
| #9 | 判据适用于全部假结拓扑 | **已关闭**：限制适用范围就是正确答案 | 无（注定 ❌，是诚实不是缺陷） |
| #16 | 更难实例上有净恢复 | **已关闭**：7 条轴 0 恢复，轴已关闭 | 无 |
| #15 | 同预算下搜索能力更强 | **0，从未改变**：三臂 62/61/60；M6 有反证 | 给一个**关闭判决**，而不是继续挂着 |
| #17 | 请求措辞来自真实用户 | **开放**：唯一还能推翻整张表的 | 方向 E |
| #18 | 第二把尺子的物理对应经测量检验 | **开放**：不确定（6/7 >0.5，p=0.109，事后设计） | 方向 C |

**所以提升 ④ 只有两条路，都要走：**

1. **把开放的 ❌ 变成 ✅ 或变成已关闭**（#17、#18；#15 给关闭判决）；
2. **往分子分母同时加新的可失败子命题**（新的尺子、新的领域、新的零假设）——只往分子加不往分母加，是最常见的一种自我欺骗。

另有两件**不直接加分但承重**的事：把 `ens_max` 走完出厂流程（方向 A）、突破第二把尺子量出来的 ~70 nt 硬边界（方向 B）。它们决定 ④ 的下一格有没有资格被写出来。

## 1. 六个方向的定义

### 方向 A —— `ens_max` 出厂：把第二把尺子从"更好的度量"升级为"出厂判据"

**定义**：让系综版共转录判据（`ens_max`/`ens_mean`）走完**换判据的全流程**，通过则成为第二把尺子的出厂操作点，不通过则永远只是度量。

**为什么能提升 ④**：这是本期**唯一测出来的真改进**——预测 +0.147（尺度那条的八倍）、在组分被构造钉死的零假设上 +20.2% 对 +10.7%。它本身不加分（改进的是仪器不是范围），但它是第二把尺子**够格发证书**的前置条件，而"第二把尺子出厂证书"是一条新的可失败子命题。

**流程（少一步都不算出厂）**：
1. 代码迁移：`ensemble_trap.py` 从 `runs/ceiling/` 迁入 `rna_harness/benchmarks/`，加测试；
2. **先测量纲再声明阈值**：天然前缀 `ens_mean ≈ 18.3`，本期声明的 θ∈{0.1…2.0} 差了一个数量级。新网格必须在任何判决之前写死；
3. 重跑缺口基准（10 种子，口径与 §3.1 一致）；
4. 移位诱饵（0/386）与嵌套诱饵在新判据下**原样再过**；
5. 同分异构体零假设必须仍成立（且不许比 +10.7 弱）。

**杀死条件**：3、4、5 任何一条不过，`ens_max` 留在度量层，不出厂。**不做"调一调阈值再过"。**

**成本**：CPU 为主。Kinfold 重判是大头；凡能用 `kinetic_calibrate.py --reanalyze` 在存档测量上重算的，不重跑模拟。

**依赖**：无。可立即开始。

### 方向 B —— 突破 ~70 nt 硬边界：换动力学裁判

**定义**：第二把尺子的外部验证有一个**量出来**的边界：Kinfold `--stop` 在 ≥100 nt 上几乎恒为 0，加 100 倍时间无效。越过它必须**换裁判**，不是加预算。本方向定义新裁判的入场检查。

**候选**：`kinwalker` —— **已装在 vpk 环境（与 Kinfold 同环境），且从未进入本项目任何回路**。BarMap 未安装，作为后备。

**为什么排最前**：它同时卡住 §4.3（测量对照）与 §4.5b（天然一致性）。边界不突破，这两条永远在 25–70 nt 之外无话可说。

**入场检查（照标定协议的形状，跑前写死）**：
1. **能跑**：版本号、冒烟例、正对照（已知折对的短序列应到达）+ 负对照（poly-A 应不到达）；工具跑不起来返回 None，不返回 0；
2. **一致性**：在 25–70 nt（两裁判都有动态范围的重叠区）测 kinwalker 到达率 vs Kinfold 访问式到达率的 kappa/Spearman。**顺带把 Kinfold / findpath / 前缀 MFE 三者的逐对 kappa 一起测了**——这是协议 P2 的欠账，假结那次"三个独立预测器"实测只有两个的教训；
3. **动态范围**：在 ≥100 nt 的 17 个天然构建体上，kinwalker 是否给出**严格介于 0 与 1 之间**的到达率（不是"不全为 0"，本期邻域判决那个假阳性的判定 bug 已修成"≥ n/3 个构建体严格介于"）。

**必须写在前面的一条**：kinwalker 与 Kinfold 共用 ViennaRNA 能量参数——按协议 v1 补写的独立性口径，**它们算一个源，直到 kappa 说不是**。所以即使 kinwalker 有动态范围，它给出的仍是**相对效度的延伸**，不是一个独立裁判的验证。这一条不写清楚，方向 B 会制造一个它本想消灭的错误。

**杀死条件**：kinwalker 在 ≥100 nt 上也恒为 0 → 边界不是裁判问题，是物理/参照问题，照实报，转方向 C 的参照路线。

**依赖**：无（工具已装）。可立即开始。

### 方向 C —— 和物理对照做到确定：测量检验从"不确定"到"通过或否定"

**定义**：④ 的证据链终点是物理，不是另一个模型。共转录 SHAPE-seq（RMDB）探测的正是判据数的那个量。本期结果是**不确定**（6/7 >0.5，均值 0.556，p=0.109，且检验是事后设计的）。本方向把它做到**二值**：通过或否定，不允许第三个状态。

**两条路（补参照质量合格的分子数）**：
- (a) 同一分子的另一种修饰剂（BzCN/DMS 互为验证）交叉导出参照；
- (b) 改用 Rfam 共识结构作参照，完全不依赖这批数据。

**预注册（跑前写死）**：
1. **先算检验力**：n=7 时全正的最小可能 p 是 0.0078，样本量本身就是天花板。要检测均值 0.55 量级的效应，80% 检验力需要多少个合格分子？**先算这个数并声明**，再收集；
2. 检验 3（对称检验）写成预注册，**在没跑过的分子上确认**——它现在是事后的；
3. 参照质量门槛（本期抓出的 bug：5 个参照连自己被拟合的数据都解释不了，最低 0.507）作为入场条件，不合格的分子不进分母。

**杀死条件**：参照质量门槛之后合格分子数 < 预注册所需 n → 报"样本/参照不足"，**不报 null，也不当证据**（零结果必须带检验力陈述）。

**依赖**：部分与方向 B 共享参照质量工作；短分子部分可独立跑。

### 方向 D —— 第三个判据缺失的领域：协议 v2 的检验

**定义**：④ 的核心主张是"方法可迁移"。两个领域做成（假结、共转录），第三个做成才是"任何人照这个做都能成"。RNA–RNA 相互作用已被入场规则挡掉（kappa 全 ≥0.80、严格判据已交付 45.8%）——**那是协议的胜利，不是失败**，但它意味着第三领域要重选。

**本方向的第一步不是实验，是领域选择调研**：枚举候选领域，逐个跑 P1–P3 入场检查，选第一个通过的。候选的入选要求：
1. **≥3 个真正独立的预测器**（不同代码库 + 不同参数集，按协议 v1 补写的口径）；
2. **天然正样本存在**（能拿回绝对灵敏度——这是第二把尺子缺的东西，第三把有机会比第二把更强）；
3. **需求证据**（P4：外部工具供给 / 文献计数）。

**跑完后唯一要回答的问题**（协议 §4 原文）：**这份协议在第三个领域里，哪一步没说清楚？** 那份清单就是 v2。三个已知的洞（"近似正确"诱饵怎么构造、相对效度多强才够、三种死法依赖想象力）写在前面。

**杀死条件**：候选领域全部入场不过 → 报"当前不存在我们可进入的第三判据缺失领域"。这本身是结论，不是失败。

**成本**：调研便宜（安装 + kappa 冒烟）；完整标定贵。先调研，后立项。

**依赖**：无。可与 A/B 并行做调研。

### 方向 E —— 真实用户的措辞：唯一还能推翻整张表的开放项

**定义**：③ 与 ④ 共同的空洞。要求清单现在来自外部，但**措辞**全部是我们写的（含 §1.1 那 8 种）。这一格不关掉，"通用易用"和"要求能被真的要到"都悬着。

**三档，从便宜到贵**：
1. **外部语料改写**：从已发表的 RNA 设计请求（文献、Eterna 玩家提问、论坛）收集，由**没见过本系统提示词的人**改写成自然语言——仍不是真实用户，但不再是"我们"；

3. **生产遥测**：MCP/CLI 放出后收集真实请求（隐私处理）。

**预注册**：真实用户措辞的可达率（该选而选中、不误选、证书守住）低于声明阈值（建议 80%，与本期 60/60 的口径一致）→ ①④ 相应子命题降级。**这是预期中可能发生的结局，不是灾难。**

**杀死条件**：无真实用户愿意/能够提供请求 → 报"该子命题不可测"，而不是继续挂"未测"。

**依赖**：需要人。招募立即开始，与实验方向并行。

### 方向 F（探索性，非主线）—— 91.7% 的生物学假设与黏性张力

**定义**：追 §4.4 留下的假设——**天然核糖开关在转录过程中确实充满一过性越界配对，而那恰恰是在设计序列上预测折叠失败的那一类**。`ens_mean = 18.3` 已独立佐证 91.7% 是生物学不是数错。

**为什么值得**：若成立，第二把尺子的含义改变——不是"判据太严"，而是"天然与设计序列对陷阱的耐受不同"。这会生出一条新子命题（判据的天然参照标定），属于"往分子分母同时加"。

**便宜入口**：Kinfold 有动态范围的 4 个天然分子（BSUGLY/CRCBFL/ECOSRP/FLUORSW）上，天然序列的 trap_fraction 与到达率的相关——§4.5b 已做，n=4 低于声明的 6。结合方向 C 的参照工作扩分子数。

**依赖**：方向 C / B 的参照与裁判工作。排后。

## 4. 本方向集不主张什么

- **不主张 kinwalker 是独立裁判**：它与 Kinfold 共用能量参数，按协议口径算一个源，直到 kappa 说不是；

- **不主张这些方向彼此独立**：B/C 共享参照工作，C/F 共享天然分子，合计不可简单相加。

**下一步(便宜、决定性)**:长度可行性曲线 + 与 Kinfold 访问式的相关。**低相关是预期,不是判据失效** —— 两者刻画不同的过程。

```
天然前缀:目标上质量 13.7–20.1,越界质量 18.1–24.3
越界【占比】47.4%–64.0%,中位 55.8%
```

> **应该在【占比】(0–1)上声明阈值,不在原始质量上。** 原始质量随分子长度和配对数漂移(86–92 对时是 18–24,短分子上完全不是这个量级),`ens_frac_θ` 用原始质量做阈值本来就注定要么全触发要么全不触发。
> 这是今天唯一一个**从失败的预注册里长出来的设计改进**。

出厂流程其余五步不变,**少一步都不算出厂**。

## 3. 新增方向 H2:设计复核 —— `instrument.py` 只解决了一半

`instrument.py` 抓得住**实现错误**,抓不住**设计本身被做掉**。今天有四个实验是**跑之前就有问题的**:

```
AUROC 对照        参照被拟合在它要评分的数据上 -> 一臂按构造必胜
θ 网格            声明时不知量纲,低一个数量级
P2 总体           挑了这个领域最容易的一档(完美互补)
SUBOPT_E = 8      声明时没量过"连通需要多宽的窗口"
```

**其中三个,`instrument.py` 里已经有对应的检查了,是我没用。** 所以 H2 不是再写新检查,而是让它们**无法被绕过**:

| 措施 | 形态 |
|---|---|
| **对照必须能失败** | `assert_control_can_fail`:拿一个刻意退化的输入喂给对照谓词,**必须返回 False**。今天我的负对照两次都是"因为无关的理由通过"——poly-A 让流水线返回 `None` 而谓词把 `None` 当过;换外来靶标又恰好挑到该序列自己的 MFE。**一个不能失败的对照不是对照。** |
| **阈值必须由量纲构造** | 一个 `Declared` 对象,不经 `scale_then_threshold` 就**拒绝被使用** —— 把"应该先量"变成"不量就用不了" |
| **总体必须声明为部署总体** | 入场检查的总体与部署总体不一致时报错(协议 v2 已写进文档,还没写进代码) |
| **对照臂不得按构造必胜** | 这一条**目前无法自动化**,只能靠跑前问一句:"有没有一臂是用被评分的那份数据拟出来的?" 照实记为**未自动化的缺口** |
