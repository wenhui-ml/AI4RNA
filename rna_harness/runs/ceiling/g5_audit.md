## 三、机制查清了 —— 这是本次真正的产出

`共享` 列 = 嵌套 MFE 与靶标骨架**共享的配对数** / 骨架配对总数。在 γ†<0 那 82 条上:

| | |
|---|---|

> **所以 γ†<0 通常【不是】"这条设计折成了别的东西"。**
> **它是"嵌套 MFE = 靶标骨架 + 一两个额外的嵌套配对,而这就足以赢过 骨架 + 交叉茎"。**

`skel` 与 `mfe` 两行几乎逐字符相同,只是 MFE 多闭合了几个配对。

**竞争者几乎就是预期结构本身,所以化学探针照样把它读成靶标。**
一个"赢家"和"输家"只差一两个外围配对的比较,本来就不可能预测探针读数。

## 五、给下一步的两条实话

1. **不要再往这个方向加强了。** 从"输给集合"加强到"输给一个具体结构"已经做完,
   而加强的结果是**指控散掉**,不是变硬。再往下(比如枚举次优结构)只会让竞争者更像靶标。
2. **真正没被测过的是"多闭合一两个外围配对"这件事本身对探针读数的影响。**
   如果那个影响接近 0(第三节的证据指向这一点),那么**任何以"嵌套世界赢"为判据的构造都注定与试管无关**
   —— 这比"γ\* 是个 GC 计数"是一个更根本的结论,而且它可以被单独检验。**这条要另开声明,不在本实验射程内。**
