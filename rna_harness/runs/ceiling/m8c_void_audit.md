## 二、错在哪

```python
def partial_spearman(xv, yv, zv):
    rx, ry, rz = _ranks(xv), _ranks(yv), _ranks(zv)
    ex, ey = resid(rx, rz), resid(ry, rz)
    return spearman(ex, ey), ex, ey        # <-- 这一步对残差【重新排秩】
```

最小二乘残差化保证的是**残差与 z 的 Pearson 相关为零**。
我在最后一步对残差取 **Spearman**,那要**重新排秩**,而重排之后与 z 的秩相关**不再为零**。

> **标准的"偏 Spearman"就是【转秩之后算 Pearson 偏相关】。我在最后一步用错了相关系数,
> 于是我算出来的东西既不是偏 Spearman,也不是任何有名字的量 —— 它是一个残差被重排过的混合物。**

**探针没响是正确的。** P1 要求的正交性,与我打算报出的那个统计量在同一个度量下 —— 它测的正是这件事。
