## 二、K3 触发了。按冻结定义,它触发;而我认为这条定义写错了

冻结的 K3:"E 单独【不】胜过 C 单独 ⇒ 增量是骑在基线上的"。实测:

```
E_free  主人群:  E 单独 0.0243  vs  C 单独 0.1001   差 −0.0758 [−0.1199,−0.0244]  排除0 ⇒ 触发
E_full  主人群:  E 单独 0.0543  vs  C 单独 0.0750   差 −0.0208 [−0.0628,+0.0282]  含0  ⇒ 按定义(不严格胜)仍触发
```

**为什么我认为它写错了:** K3 问的是"E 作为【独立预测器】是否比一个平凡计数强";
而本实验的目的是"E 是否携带那个平凡计数【没有的】信息",**那是 K2 问的**。
一个单独很弱、但在 B+C 之上仍有增量的块,是**互补信息**的标准形态,不是"骑在基线上"——
**骑在基线上的块在 B+C 之上加不出东西,而 E 在四个人群上都加出了。**

**但我不据此改判。** 理由:今天已经有三次"我的打死条件测错了东西"(G4 的 K2、G5 的 K2、现在 E1 的 K3),
**而每次我都是在结果对我有利的时候才发现的。** 所以诚实的状态是:

> **K2 的测量成立;而这个实验【声明的闸门触发了】。要把它读成"通过",必须另开一份把闸门写对的声明
> —— 不能由我事后改口径。E1 的地位是:【结果强,但它自己的声明判它不过】。**

**第 41 条(候补):打死条件必须与实验【声明的目的】对齐。** E1 的目的写的是"加一根不在现有族里的列",
那是**增量**问题;而 K3 测的是**单独强度**。**目的与闸门错配,是今天第四次同型缺陷。**

## 三、审计发现的两条与 E 无关、但更值钱的东西

### 3.1 **两根平凡的组成列拿到了 0.196 那根杆的一半以上**

```
主人群:B(F2 ∪ f1c,22 列)净 R² = 0.1651
        C(交叉茎 GC 计数 + 整体 GC 比例,【2 列】)净 R² = 0.1001
        净ΔR²(B+C − B) = +0.0492 [+0.0293,+0.0806]  排除0
```

**两根不需要任何判官、任何折叠、任何配分函数的列,拿到 0.10;而整套 16 列面板机器拿到 0.165。**
**而且它在 B 之上还能再加 +0.049。** 这是对出厂判据的一个独立指控,四人群一致(+0.049/+0.051/+0.056/+0.048)。

### 3.2 **限制到"骨架可形成"的设计,面板的净 R² 掉了一半**

```
B 在 E_free 人群(n=4354)= 0.1651
B 在 E_full 人群(n=3335,只留骨架可形成)= 0.0814
```

**面板的信息量有一半集中在【连靶标骨架都形不成】的那 23.4% 分子上。**
也就是说:**面板很大一部分本事是在区分"这条设计根本没配上"——而那件事查碱基互补性就能做到,不需要判官。**
**这一条不在声明的观测量里,所以只作为观察记录,不作为结论。** 它值得单独预注册。
