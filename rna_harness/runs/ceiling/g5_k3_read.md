## 二、第 3 条:三家判官一致确认了一个**它们自己一个交叉配对都没预测的**分子

**`panel_k = 3`,而 `n_pred_cross = 0`、精度 0.000、召回 0.000。** 这不是噪声,是一个逻辑上不可能的判定。

**机制在出厂列的定义里,不需要任何热力学就能看出来:**
出厂的 `recall_product` 把"靶标的某个交叉配对被找回"定义成"判官预测了**那个配对**",
**而不管该配对在预测里还交不交叉。** 于是一个判官可以把靶标的每一个交叉配对
**都以纯嵌套的方式**预测出来,`recall_product` 照样给 1.000。

**全体量了一遍:**

```
panel_k=0 : n=1925   n_pred_cross==0 ->  87 = 4.52%
panel_k=1 : n=1141                       0 = 0.00%
panel_k=2 : n=1105                       0 = 0.00%
panel_k=3 : n= 389                       7 = 1.80%     试管通过率 0.571(k=3 全体是 0.848)
```

> **7 条。全部落在 k=3,k=1 与 k=2 各 0 条。**

**为什么只在 k=3:** `n_pred_cross == 0` 要求**三家都**没预测出任何交叉,
而三家都 `recall_product = 1.0` 又要求三家都把靶标的交叉配对全预测出来 —— 只有"全部以嵌套方式预测"
这一种退化情形能同时满足。**k=1/2 时另外那几家会贡献交叉预测,所以这个组合只能出现在最高档。**

### 更正一:我把这条说过头了

我上一条说这是"今天最尖锐的东西"。**它是 7 条,占 confirmed 的 0.27%,不是系统性缺陷。**
准确的说法是:**罕见,但是【范畴性错误】,而且全部集中在证书对外展示为最强证据的那一档。**
它的价值不在数量,在于它是一个**不需要湿实验、不需要热力学、只看两列定义就能确证**的错误。

## 三、更正二:我从 9 条推到 82 条,推错了

九条里 **8/9 抢位 > 0**(7 条是 100% 抢位),于是我说"竞争者确实在跟假结争碱基"。
**把 82 条全量一遍,不是这样:**

```
抢位比例:中位 0.375
  = 1.0(全抢):15/82
  >= 0.5     :32/82
  = 0(完全不抢):30/82   <- 37%
```

**所以 82 条要分开看,不能当成一批:**

| | 条数 | 含义 |
|---|---|---|
| 抢位 >= 0.5 | **32** | 嵌套 MFE 拿走了假结需要的碱基 ⇒ 它**就是"把假结吃掉的那个嵌套替代品"**,γ†<0 是真竞争 |
| 抢位 = 0 | **30** | 竞争者在**别处**多闭合配对,根本不跟假结争 ⇒ γ†<0 只是**拿大结构比小结构,应当剔除** |
| 0 < 抢位 < 0.5 | 20 | 部分重叠,单条看 |

**k=3 那九条不代表 82 条**(九条里 8/9 抢位>0,82 条里只有 52/82)。这是从小子集外推的老毛病,
`抢位` 列已经加进 `g5_the_123.md`,以后按它筛。

**而这也修正了 `g5_audit.md` 第三节的重点:** 那节说"共享 85% ⇒ 竞争者几乎就是靶标本身"。
**共享高与抢位高可以同时成立** —— MFE 保留大部分骨架,**同时**把假结的两条臂改成嵌套配对。
那正是假结与嵌套竞争的经典形态。**所以第三节的机制解释对"抢位=0"那 30 条成立,对"抢位>=0.5"那 32 条不成立。**

## 五、下一步该做什么(和不该做什么)

**不该做:** 再去加强 γ\*。抢位那一列已经说明,连"谁是竞争者"这个问题在 82 条里都有 37% 是伪的。

**该做:** 那 **7 条 `panel_k=3` 且 `n_pred_cross=0`** 是一个**完全独立于 γ\* 的**、只靠出厂两列定义
就能确证的判定错误。它不需要任何新实验,只需要一个决定:**出厂的 `k` 要不要改成用交叉一致的 `recall`
而不是 `recall_product` 来数。** 那是一个会改动决定的口径变更,按项目惯例要单独预注册。
