## 二、必须先说破:逐列归因里有一处**我的设计错误**

四个人群里,`spur_max` / `spur_margin` / `loop_max` / `helix_min` 的 drop-one 贡献**全部恰好 +0.00000**。
原因不是它们没用,是**逐格去均值把它们杀掉或变成同一列**:

* `loop_max`、`helix_min` **只依赖靶标** ⇒ 在 (puzzle, method) 格内是常数 ⇒ 去均值后**恒等于 0**;
* `spur_margin = spur_max − max(靶标螺旋长)`,减掉的是靶标常数 ⇒ **去均值后与 `spur_max` 完全共线**
  ⇒ 去掉任何一根,另一根原样顶上,**drop-one 对这一对是瞎的**。

> **⇒ S1 名义 7 列,有效只有 4 列:{spur_max ≡ spur_margin, spur_cnt, gc_paired, gc_unpaired}。**
> **⇒ 伪螺旋族的单列贡献在本实验里【不可识别】,不许说它有用,也不许说它没用。**

**可识别的驱动列(全块 drop-one):**

| 列 | 样本2 | 基准4560 | 样本3 | 第四批 |
|---|---|---|---|---|
| **ed_full**(对完整靶标的系综缺陷) | **+0.0199** | **+0.0204** | **+0.0229** | **+0.0214** |
| **gc_paired**(配对位置的 GC 比例) | **+0.0136** | **+0.0125** | **+0.0113** | **+0.0051** |
| spur_cnt | +0.0009 | −0.0001 | +0.0012 | +0.0015 |
| gc_unpaired / egap / dG_gap | ≈0 或**负** | | | |

### 第 73 条

> **做 drop-one 归因之前,必须先检查【逐格去均值之后】哪些列变成 0、哪些彼此共线。
> 否则 drop-one 会把"看不见"报成"贡献为 0"。**
> 检验方法:去均值后逐列算方差与两两相关,方差 0 或 |r|=1 的列先报出来,再做归因。

## 三、因此,这个正向结果**准确的**内容是什么

**成立的:**
1. **出厂 22 列 + 两根 GC 列不是天花板。** 一族序列内在的列在它之上仍有 **+0.06 ~ +0.075** 的**留出**增量,**四人群全部排除 0**,四根探针全清,梯级余量 4.7 倍。
2. **它换算得出产品货币**:10 选 1 上多拿 **+0.15 ~ +0.73** 个 wet 单位(基线自身是 +2.04 ~ +2.57)。
3. **S1(完全不调用任何折叠 oracle)单独就在 4/4 上排除 0**(+0.040 ~ +0.049)。

**不成立 / 不许说的:**
4. **不能说"伪螺旋这一族有用"** —— 第二节,不可识别。
5. **可识别的两个驱动列都落在【已知的族】里**:`ed_full` 属于 M3/M7 早就点名的**系综集中度族**;
   `gc_paired` 属于 **GC 族**(这是 GC 在本条线上的第七次出现)。
   **⇒ 这不是"发现了一种新信号",是"两个已知族的更细分量仍然加得动"。**
6. 不主张任何列是机制;不主张跨语料外推;不判上线。

## 六、边界

1. **单一语料**(OpenKnotBench v4.5.1);跨语料外推未测。
2. **wet 是化学探测读数**,不是"它折没折成"。
3. `ed_full` 与 `dG_gap` 用**靶标的嵌套投影**做 ViennaRNA 计算(ViennaRNA 的 `ensemble_defect` 不接受交叉配对);
   `ed_full` 的交叉配对项概率≈0 因而每条贡献≈1。**这与声明里"对完整靶标"的字面意思有偏差,照记。**
4. 观察性数据,**无因果主张**。
5. capture@10 的口径是**留出**的,与 M4/M4b 的样本内口径不可混引(尽管基线臂两者对到 1.4%)。
