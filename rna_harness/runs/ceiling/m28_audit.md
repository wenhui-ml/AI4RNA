## 三件必须写进论文、而不是藏起来的事

### 一、K1 只在四个沉积-探针里的**一个**上触发

**挖掘步骤在所有沉积上都迁移了**(A 臂逐条排除理由干净,`not_orientation_flip` 与调查
独立算出的翻转数逐位对上:M3SARS 15759 双突变 − 11805 非翻转 = **3954**)。
**记分步骤只在 `M2SL5_DMS` 上迁移。** 论文必须按这个写,不许写成"迁移成立"。

### 二、两个探针**同号但差 3~4 倍**,而这是 OK7a 没有的轴

```
M2SL5 上 rescue 的两探针相关   Pearson 0.5075 / Spearman 0.5003(n=139 条共享干预)
ViennaRNA     DMS +0.18523   vs   2A3 +0.04943    同号
RibonanzaNet  DMS +0.21009   vs   2A3 +0.06771    同号
```

**同一批干预、两次独立测量,斜率同号但相差 3~4 倍。** 不是符号翻转,是量级。
n 几乎相同(143 vs 152),层数相同(3),所以这不是样本量差异。
**照报,不解释掉** —— 2A3 读全部四种碱基的骨架、DMS 只读 A/C,先验上 2A3 该更好,而它更差。

### 三、M3SARS_2A3 的 E 臂在**梯级说测不出来的区间里**报出了 p=0.030

```
身份对比 −0.08923,置换 p = 0.030   ← 名义显著,且与 OK7a 反号
构造性梯级的检出阈值 = 0.2         ← |−0.089| 远在阈值以下
```

**按第 66 条(解析检出与构造性梯级不一致时以梯级为准),这一条没有裁决力。**
K4 本来就预先禁止拿 E 臂否证 OK7a;这里再加一条独立理由。**不许引用为"天然 RNA 上方向相反"。**

## 与声明里的调查数不一致的一处,原因已查明

调查(`m27` 之后的设计侧盘点)写的是 M3SARS 在 SN>1 下可用翻转 **47 / 193**;本次是 **0 / 75**。
差别是判据不是数据:**本实验要求双突变、野生型、两个单突变【四条】的 SN 都 ≥1.0**,
因为四条都进入 rescue 的计算式;调查只看了翻转构建体自己。**更严的那个是对的**,
差异记录在此,调查的数不再引用。
