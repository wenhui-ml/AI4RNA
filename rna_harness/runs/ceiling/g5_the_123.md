# G5:那 123 条,逐条列出(2026-08-21)

声明 `g5_named_competitor_declaration.json`。数据 `g5_named_competitor.json`。$0,离线。

**这是什么:** G2 那批骨架可形成、被出厂面板确认(`panel_k >= 1`)、而 `γ* < 0` 的设计。
**这不是什么:** 不是面板误收的证明(`g2_audit.md` 已撤回那个说法),也不是对 G1 那个 NULL 的翻案。
自由能差说的是**相对布居**,不是不可能;整条线的排序信息已被测出可由交叉茎 GC 计数复现。

**γ† = E_MFE_nested − E_skeleton − dG_stack** —— 把 γ\* 里的【嵌套集合】换成【嵌套 MFE 这一个
能打印出来的结构】。`E_MFE >= F_nested` 是恒等式,所以 `γ† >= γ*`,**γ†<0 是更强的条件**:
满足它的分子输给的是一个具体结构,不是一个总和。逐条自检违反 0 处。

| | 条数 | 试管通过率 | k=1/2/3 |
|---|---|---|---|
| γ\* < 0(G2 那批) | 123 | 0.6748 | 79/35/9 |
| **γ† < 0**(输给一个可点名的结构) | **82** | 0.6463 | 55/19/8 |
| γ† < +2.4(按 dG_stack 偏差修正) | 120 | 0.6750 | 77/34/9 |

列的含义:`k` 面板确认数;`确认者` 哪几家判官;`γ*` 对集合;`γ†` 对单个 MFE 结构;
`GC` 交叉茎里的 G-C 配对数(G1 测出它单独就能复现整条线的排序信息,放在这里供对照);
`共享` = 嵌套 MFE 与靶标骨架共享的配对数 / 骨架配对总数 —— 竞争者离预期结构有多远;
**`抢位` = 嵌套 MFE 用掉了【交叉茎需要、而骨架里本来空着】的核苷酸数 / 交叉茎需要的总数。**
**抢位 = 0 ⇒ 这个『竞争者』根本不跟假结争碱基,γ†<0 只是拿大结构比小结构,应当剔除。**
抢位越接近 1 ⇒ 它就是『把假结吃掉的那个嵌套替代品』,即真正的竞争者。见 `g5_k3_read.md`。
