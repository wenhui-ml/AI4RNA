## 三、实现与声明不一致 —— 两处,其中一处决定了裁定

### 缺陷 1(决定性):K1/K2 用的区间不是声明里写的那个量

声明 K1 原文:「200 次划分上 [排序准确率(BC_ed) − 排序准确率(BC)] 的**均值区间**含 0 ⇒ 不外推」。

代码算的是(第 146-148 行):

```python
def q(v):
    s2 = sorted(v)
    return [round(s2[int(0.025*len(s2))], 4), round(s2[min(len(s2)-1, int(0.975*len(s2)))], 4)]
```

这是**200 个划分值本身的 2.5/97.5 分位**,即"随机抽一次划分,增量大概落在哪"的**单次划分预测区间**;
它的宽度里包含了"**哪些靶标落进留出集**"这一项方差。**均值的不确定区间不是这个东西**,而且要窄得多
——本项目其余地方用的是对**格/靶标**做 cluster bootstrap。

所以:**我冻的 K1 从来没有被计算过。** 打印出来的 `FIRES` 是另一个量的 FIRES。

**这不是"实验失败",是"实验没执行自己的声明" ⇒ K1/K2 作废,不是未通过。**
而"看到不利数字之后宣布作废"正是可以用来洗失败的动作,所以它**必须**配一次
在我没看过的人群上、用写对的区间的重测,否则这条作废不算数。见 §五。

### 缺陷 2(非决定性):声明的次要指标根本没实现

声明写了「留出格内去均值的 R² 也报,但明确标注它用了每格一个 y 均值,故只作次要」。
`grep -n "R2\|r2\|次要"` 在运行脚本里**零命中**。次要指标从未计算,也从未报出。
不影响裁定,但**必须记下来,不许静默丢掉**。
