# R2 的如实重读(2026-08-20)

## 站得住的:第一层,三个人群复现

```
人群        F2 样本内 R²   F2∪{gap}   ΔR²        对格聚类 CI          置换零均值
第四批(主)   0.1112       0.1366     +0.0254   [+0.0049, +0.0663]   +0.0010
样本2        0.0888       0.1320     +0.0432   [+0.0163, +0.0824]   +0.0002
样本3        0.0924       0.1164     +0.0240   [+0.0075, +0.0487]   +0.0004
```

三个人群全部排除 0,嵌套单调性自检全部通过。**一个用两次 ViennaRNA 调用算出、回路里零个假结预测器的量,
在三个启发式神谕的全部 21 列之上还能再加 R²。** 这是这条思路第一次产出一根新列。

`gap = E(目标的嵌套骨架) − E(MFE)`,两个原语都只在**嵌套**结构上求值,不碰交叉,不存在
`hc_add_bp` 那种静默丢弃约束的余地。

## 空的:第二层,而且是我设计空的

判定打印 `cannot_distinguish`。**那不是自然的性质,是我的设计问题。** 档内 L 近乎常数,于是
`g = gap/L` 与 `gap` 近乎成比例,**两个回归是同一个回归、只差一个缩放**。数值上:

```
              coef_g      coef_gap × L_中位    比值
样本2 短      -69.71        -70.69           0.986
      中      -64.61        -64.58           1.000
      长      -30.64        -29.48           1.040
样本3 短      -88.18        -88.02           1.002
      中      -60.84        -60.78           1.001
      长      -28.64        -26.35           1.087
```

比值恒为 1。所以「系数随长度档的签名」**在代数上不可能区分两种归一化**。我在声明里把它写成
"能打掉这个框架的判据",而它其实什么也判不了。

**这是同一类缺陷第四次出现**(A9 门槛设在总量上、A13 门槛设在单位数上、A16 门闸用了错的代理、
R2 第二层的检验在代数上是恒等式)。**新规矩:检验设计好之后,先问一句「在零假设和备择假设下,
这两个数会不同吗」——如果它们在代数上恒等,这个检验不存在。**

## 第二层确实显示了一件事,而它**否掉了我自己那步推导**

`coef_g` 随 L **单调下降**,两个人群都复现:

```
样本2:  -69.7 (L≈75)  →  -64.6 (L≈100)  →  -30.6 (L≈206)
样本3:  -88.2 (L≈75)  →  -60.8 (L≈100)  →  -28.6 (L≈206)
```

两个假设各自的预测:

| 假设 | 对 coef_g 的预测 | 观测 |
|---|---|---|
| 真正的驱动量是 **g**(REM 那步推导) | 随 L **稳定** | ✗ 下降 |
| 真正的驱动量是 **gap**(绝对) | 随 L **正比增长**(coef_g = coef_gap·L) | ✗ 下降 |

**两个都不成立。** 间隙的预测力随长度**衰减**,比任何一种归一化能解释的都快。

所以我从"嵌套结构数 ~2.6^L、竞争者地板广延、故胜负由每核苷酸系数决定"推出的那个预测
**没有被数据支持**。一个不需要新假设的解释是:长分子上试管分被其它失效模式主导(能出错的地方更多),
于是一个全局的「骨架 vs 地板」间隙作为代理自然变弱。但**这是事后解释,不是本次测过的东西**。
