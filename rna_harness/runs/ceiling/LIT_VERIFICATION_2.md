## 2. 必须修正的三处

### 修正一:Struct2SeQ 的战绩被外部分析**放大**了

外部分析写"**显著超过人类和其他自动化方法**"。仓库自己的 README 说的是:

```
OpenKnot Round 7  (100mer)   19/20 puzzles solved,【human-competitive】
OpenKnot Round 7b (240mer)   显著超过人类 (p=0.024)
```

> **不是全面超越,是"100mer 持平、240mer 更好"。** 这个区分对我们很重要 —— 我们的假结部署总体大多在 100 nt 以下,**恰好落在"持平"那一档**。
> 另外该仓库 **1 star、最后更新 2026-01-13**,几乎没有外部使用记录。这不是否定理由,但"经同行使用检验"这条不能算。

### 修正二:`wild_type_sequence` 是**必需输入列**,而我们的部署总体没有它

外部分析说"输入就是点括号"。实际的输入 CSV 是:

```csv
Title, Dot-bracket, wild_type_sequence
```

而 `generate.py` **无条件读取**这一列(第 139 行 `wildtype_sequence=test_df['wild_type_sequence'][i]`,第 263 行算 Hamming 距离)。`--up_bias 0.0` 只关掉偏置强度,**不让这一列变成可选**。

> **这是外部分析没有暴露的集成门槛,而且它改变总体定义。**
> pseudobase 里我们有天然序列的只有 **186/251**;而产品的真实场景是**用户给一个点括号、根本没有野生型**。
> 所以 #35 的总体必须写死为"**有天然序列的那 186 个**",或者先验证"喂占位序列 + up_bias=0"不改变输出 —— **后者是一个未经验证的改装,不能默认它无害。**

### 修正三:外部分析**漏掉了最重要的一篇**,而它给出一个与我们不同的答案

[**De novo design of RNA pseudoknots with deep learning**](https://www.biorxiv.org/content/10.64898/2026.05.21.726960v1)(Townley, Kladwang, Baker, Das 等,2026-05)

```
Eterna 竞赛,57 个假结,盲测
生成式 AI 方法【匹配】有经验的人类设计者
三重实验验证:单核苷酸分辨率化学 mapping + 补偿突变 + 冷冻电镜
成功由【RNet 基础模型】引导 —— 它训练在既往化学 mapping 数据上
结论:"有些困难的 RNA 设计任务,也许不必先解决 RNA 3D 结构预测"
```

> **这不只是又一条基准。它是对我们墙一的一个【竞争答案】。**

## 3. 这次核实真正的发现:领域对"没有绝对判据"的答案,和我们的不一样

我们墙一的处理是:**承认判据是模型相对的,把裁判依赖度量化并写进证书**(97.1%、三家 kappa 0.11–0.34、每级带天花板)。

而 Struct2SeQ 和 Das 那篇**用的是同一个、且不同于我们的**招法:

```
Struct2SeQ  ->  内部用 RibonanzaNet / RibonanzaNet-SS 评估    (训练在 Ribonanza 化学 mapping 数据上)
Das 2026    ->  用 RNet 基础模型引导                          (训练在既往化学 mapping 数据上)
```

> **领域的答案是:【把判据从实验数据里学出来】,然后对着它设计。**
> **我们的答案是:【承认没有绝对判据,把依赖度报出来】。**
>
> 两者不矛盾 —— 但我们**手上一条实验数据都没有**,整个面板是热力学预测器(pKiss / ProbKnot / ShapeKnots / RNAPKplex / Knotty / IPknot)。

## 4. 这直接推翻外部分析把 #35 与 #36 拆成两条独立预注册的做法

外部分析的 #35 是:**用我们的热力学面板去判 Struct2SeQ 的设计**。

**这个设计有一个承重缺陷**:Struct2SeQ 优化的目标是 RibonanzaNet(化学 mapping 学出来的),我们的面板是热力学的。

```
若结果是"Struct2SeQ 在我们面板下不占优" ->  无法区分以下两种解释
    (a) 它的设计确实不好
    (b) 它在优化【另一个判据】,而我们在用【我们的判据】打分
```

**而 (b) 恰恰是本项目自己的论点(判决是模型相对的)。** 用一个我们自己已经证明为模型相对的判据去裁决一个对着不同判据优化的生成器,**结论天然不可读**。

### 正确的做法:不是两条独立预注册,是**一个 2×2**

```
                     我们的热力学面板        实验锚点(OpenKnot SHAPE)
DesiRNA 的设计            A                        B
Struct2SeQ 的设计         C                        D
```

- **只有 A/C(外部分析的 #35)** → 被训练数据错配污染,不可读
- **只有 A/B(外部分析的 #36)** → 分不清"面板偏离实验"是**面板的错**还是**我们设计的错**
- **四格一起** → 生成器与裁判**正交分离**,而且它同时检验本项目的核心论点:
  - 若 C 低而 D 高 → **我们的面板系统性低估了对着实验判据优化出来的设计** —— 这是"判决模型相对"最强的一次实证,比 97.1% 强得多
  - 若 C 低且 D 也低 → Struct2SeQ 在我们的总体上确实不占优,轴可关闭
  - 若 C 高且 D 高 → 换生成器是真增益,两个判据都同意

> **这个 2×2 是两份分析都没有提出的,而它比任何一份单独的方案都强。**
> **它也是我们唯一一次能把"判据是模型相对的"从描述变成可操作的预测。**

## 5. 立项判定

| 方向 | 判定 |
|---|---|
| **Struct2SeQ 第三求解器臂** | **可立项,但必须并入 2×2**,且总体先写死为有天然序列的 186 个;单独跑 A/C 不可读 |
| **OpenKnot 实验锚点** | **前置动作先做**:确认能拿到"靶标 + 设计 + 实测 SHAPE/OpenKnot Score",且与我们总体的重叠度 ≥ 跑前声明的最小 n。拿不到就不立项 |
| **gRNAde 第二臂** | **暂缓**。README 声称支持二级结构输入,但文档未确认"仅二级结构"是否足够;等 2×2 有结果再说,不一次开两条生成器轴 |
| **SamplingDesign 系综生成** | **暂缓**,且要注意它只做无假结结构 |
| **共转录(StraD / TECprobe-VL)** | **不立项**,与 `LIT_VERIFICATION.md` 的结论一致:没有新的分子系统 |
| **Harness-Bench 的过程维度进记分表** | **可做,便宜**,但它是产品度量不是科学结论,单独记 |
