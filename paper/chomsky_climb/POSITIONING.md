### vs compounding-profile(family B;"compounding 是 profile";SAT/A*/TSP;correctness-pinned/gaming-proof/speed-only;transfer NULL)

## 外部定位(初判——从 deep-research `wf_eced9fc9-4c0` 缓存提取;完整带引用报告待 resume 综合)

**核查结论:未被预抢。旗插在"合取"上,不在任一部件。** 逐条:

- **FunSearch / AlphaEvolve / AlphaTensor(最尖对手)**:确为"AI 发明 + 精确 evaluator 验证的构造",AlphaEvolve 在 ~20% 问题上"discovers new, provably better constructions"。**但**:(a) 其发现框架是**标量改进**("better scalar value, NOT a Chomsky-hierarchy class ascent"),**不是类攀升**;(b) **无不可能证书**——AlphaTensor 只给上界、从不证 impossibility(Kauers & Moosbauer 一周内就 BEAT 了它 → 只是 upper-bound)。核查原话:它们"never framed as class ascent / Chomsky hierarchy with impossibility/pumping-lemma certificates"。→ **不撞;而且它们恰好缺我们的负向(不可能)侧。**
- **Delétang「NN 与乔姆斯基层级」**:是**静态**刻画(哪种架构=哪一 tier,"Chomsky class is a deterministic FUNCTION of the fixed memory architecture"),**不是** agent 的**动态可证类攀升**。→ 不撞。
- **grammar induction(Gold)**:是"identify in the limit"的**可学习性**,"never crosses into class-ascent"。→ 不撞。
- **RNA-SCFG/MCFG 经典**:"formal MCFG machinery exists but has never been repurposed as an AI agent's certified hierarchy-climb"(无 agent、无发现主张、无不可能证书)。→ 不撞;是我们的原材料。
- **AI-Hilbert / 派生证书**:给的是"validity-from-axioms"证书,**须显式区隔**(不是 grammar-class 对象)。
- **MIT 2606.01444**:未见其占 grammar-class 攀升 / 两侧 / 不可能(与前一轮一致)。

**幸存并插旗的合取**:动态**可证类攀升** + **两侧可判定(含泵引理/undesignability 不可能)** + **自主 agent** + **精确 RNA 底座**。**最干净的差异化 = 不可能侧**:DeepMind 那条线(FunSearch/AlphaEvolve/AlphaTensor)给更好的构造/上界,**从不证不可能**;我们的两侧证书里那张**可证不可能**正是他们结构上没有的。

**需盯的 2026 快速对手**:**ChomskyBench(arXiv 2604.02709)**——按 Chomsky tier 评 LLM 形式推理(静态评测,非 agent 攀升,但词汇在被占用,需区隔)。

**注意**:幸存是**合取级**(每个单独部件都在别处存在过);插旗务必押"动态类攀升 + 两侧含不可能 + 自主 + 精确 RNA"整套,不押任一部件。
