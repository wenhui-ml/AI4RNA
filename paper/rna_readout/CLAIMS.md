# 附二:2026-08-26 二次核查发现的两件事

## (i) 我自己实现里的一个口径分歧 —— 已测,结论不变

`OK7a` 数据集 README 写:**目标配对位 correct iff 反应性 < 0.25**;
`OpenKnotScoreMATLAB` 仓库描述写:**配对位反应性 > 0.5 才罚**。**两个阈值不一致。**
M14 的 Y2 用的是 **0.25**(README 口径,因为 `target_openknot_score` 这一列就是按 README 定义的)。

两个阈值都跑:

| 臂 | ΔECS @0.25 | ΔECS @0.5 |
|---|---|---|
| 拆 G-C 改 G→C | −4.411 [−5.38,−3.48] | −2.295 [−2.96,−1.73] |
| 拆 G-C 改 C→G | −5.160 [−6.17,−4.27] | −2.942 [−3.70,−2.33] |
| 拆 A-U 改 A→U | −3.740 [−4.63,−2.94] | −1.923 [−2.51,−1.40] |
| 拆 A-U 改 U→A | −4.951 [−5.87,−4.14] | −2.725 [−3.43,−2.16] |

**量级在 0.5 下腰斩,但【四臂全负、全部排除 0】不变 ⇒ D3 的符号检验对阈值选择稳健。**
**正文必须写出这个分歧和敏感性检验,并写明 Y2 只是 ECS 那一半,不是完整 OpenKnot Score。**

**完整定义(已查清,清掉未结清项 3):**
`OpenKnot Score = ½(Eterna Classic Score + Crossed Pair Quality)`;
CPQ 用同一套罚则,但**只算参与交叉配对的残基**(含被交叉的那些对,不只是 `[`/`]`);
singlet 对排除;伙伴落在未探测侧翼的残基权重降为 0.5;
**两个子分只在提交设计对应的残基上算,不含侧翼填充区**(我们的 `[sub_start-1, sub_end-1]` 限制与此一致)。
